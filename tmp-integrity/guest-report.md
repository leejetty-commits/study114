## 4. 확인 필요

1. **게스트 검색 시 '대치동' 고정 및 지역 변경 불가 정책**
   - 현재 비로그인 게스트가 공부방 검색 시 서버 검색 API(`SearchService.php`)에서 지역 필터가 무조건 '서울 강남구 대치동'으로 강제 치환되며, 프론트에서 `주소찾기` 버튼을 누르면 지역 선택창 대신 로그인 유도 팝업이 뜹니다.
   - 대치동에 등록된 실제 공부방이 0건이어서 게스트는 항상 "등록된 공부방 없음(샘플 카드 1개)"만 보게 됩니다.
   - 이것이 기획상 "비로그인은 맛보기로 대치동 샘플만 노출하고 전국 검색은 회원가입/로그인 유도" 의도인지, 아니면 게스트도 지역 변경 탐색은 허용해야 하는지 기획 확인이 필요합니다.

2. **운영 DB 내 실제 공부방(ID 6, ID 7) 대표 사진 정리**
   - ID 6("우동공과 민락점")과 ID 7("가능동베스트")의 대표 이미지 파일이 개발/테스트 당시 화면 캡처본(`/uploads/promo/rooms/6/28c2536cd7c1afe8_prime_1280.webp`, `rooms/7/ed0214b5c930c904_prime_1280.webp`)으로 등록되어 있습니다.
   - 이로 인해 일반 손님이 프로필을 볼 때 관리자 수정 화면이 겹쳐 보이는 착시가 발생하므로, 운영 DB 관리자 측에서 기본 이미지로 초기화하거나 실제 매장 사진으로 재업로드하는 조치가 필요합니다.

## 5. 점검 못 한 것과 이유

1. **회원가입의 역할 선택 3단계 화면 (`/auth/#/signup/role`의 실제 라디오/카드 선택)**
   - **이유**: 절대 규칙 1번(서버에 쓰기를 일으키는 폼 제출 금지)을 준수하기 위해 가입 1단계 약관 동의 및 2단계 계정 폼 제출(`POST /api/auth/signup.php`)을 수행하지 않았습니다. 프론트엔드 라우트 가드가 2단계 draft 데이터가 없을 경우 자동으로 2단계 가입폼으로 되돌리기 때문에, 폼 제출 없이 도달 가능한 1단계와 2단계 안내 화면까지만 점검했습니다.
2. **실제 공부방 쪽지/문의 발송 폼 내부 UI**
   - **이유**: 운영 사이트 절대 규칙 1번(쪽지/문의 보내기 금지 및 쓰기 동작 금지)에 따라, 비로그인 상태에서 쪽지 버튼 클릭 후 문의 전송 인터랙션을 유발하지 않고 손님 대상 안내 문구("현재 쪽지 가능", "현재는 잠시 쉬는 중입니다") 노출 상태까지만 확인했습니다.
3. **네이버 지도 확대/축소 및 마커 클릭 시의 상세 팝업**
   - **이유**: 대치동 기준 등록된 실제 공부방이 0건이어서 지도 위에 클릭 가능한 실제 공부방 마커가 생성되지 않았습니다.
