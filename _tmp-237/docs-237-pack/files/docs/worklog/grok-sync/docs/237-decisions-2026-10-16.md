# 237 종현 확정 기록 (2026-10-16)

## 1. 지도 핀 모양 (C2-small)
- 로고 아이콘만 쓰고, 세로로 약 1.3배 늘립니다.
- 크기는 기본 16×30, 선택하면 20×38입니다.

## 2. 지도 규칙 (235-5)
- 동네 중심에서 10km보다 먼 핀은 **지도에서만** 빼고, 카드 목록은 그대로 둡니다.
- 줌 하한: 동 14, 학생 구 12. (코드: `preview/shared/naver-map.js` MAP_PIN_RADIUS_KM·MAP_ZOOM_FLOOR_*, 커밋 c7ca4432·30aeea2b)

## 3. 핀과 카드의 기준
- 핀은 사업장주소를 따르고, 카드는 홍보지역을 따릅니다. 서로 모순되지 않습니다.
- 사업장주소는 법적 주소라 임의로 고칠 수 없습니다.
- 홍보지역1을 직접 고친 값은 유지합니다(지금 구조 그대로, `data-promo1-manual`).
- 민락점(id6) 등 테스트 데이터는 나중에 한꺼번에 지웁니다.

## 4. 홍보 채널 기획 (개발 지시 전, 논의 단계)
- 기존 「소셜홍보」 블록을 넓혀 「홍보 채널」로 만듭니다.
- 순서와 개수: 유튜브 최대 4개 → 블로그 1~2개 → 인스타그램 → 틱톡 → 네이버 클립.
- 페이스북은 화면에서만 숨깁니다(저장 칸은 둡니다).
- 주소는 해당 사이트 주소인지만 확인하고, 연락처(전화번호·카톡 아이디)는 막습니다.
- 누르면 새 탭으로 엽니다. 비회원에게는 보이지 않습니다.
- 확대카드에서는 아래쪽에 둡니다.
- 시안: `audits/sns-mockups/register-*.png`, `card-*.png`
- 확대카드 하단 배너는 「지금 필요한 안내」만 남깁니다. 어느 배너를 뺄지는 실제 화면에서 다시 확인해야 합니다.

## 5. 지시서 규칙 (t1844)
- 커서 지시서에는 항상 **작업 범위**(손대도 되는 파일, 손대면 안 되는 것, 범위 밖이면 멈추고 보고)를 적습니다.
