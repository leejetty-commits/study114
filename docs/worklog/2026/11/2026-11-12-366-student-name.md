# 366 학생 이름 표시 (2026-11-12)

브랜치: `work/366-student-name` (main `8d40397a`에서 생성). 머지하지 않음.

## 한 일

- 학생 기본정보(가입·수정·읽기)에서 「표시명」 칸을 없애고 「학생 이름」(`student_name`)을 보여 주고 수정할 수 있게 했다.
- 다른 사람에게 보이는 이름은 `StudentPublicName::mask` 한 곳에서 가린다. 검색·프라임 요약 제목, 고민방 작성자, 정보게시판 작성자는 그 값을 쓴다. 응답에 이름 원문 키를 넣지 않는다.
- 화면은 서버가 가린 값을 다시 가리지 않는다. 본인 기본정보·마이페이지 카드는 이름 전체.
- 「희망지역 추가값」 화면 라벨을 「희망지역 추가」로 바꿨다. 현재 `docs/ssot`에는 그 문구가 없었다.
- `public_display_name` 컬럼은 지우지 않는다. 이름을 저장할 때 같은 값을 넣어 둔다. 공개 API는 그 컬럼을 제목으로 쓰지 않는다.
- 과외쌤 표시명, 사이트 표시명, 관리자 화면, 공부방 이름은 수정하지 않았다.

## 가림

| 입력 | 결과 |
|---|---|
| 1자 | `*` |
| 2자 | 첫 글자 + `*` |
| 3자 | 첫 글자 + `*` + 끝 글자 |
| 4자 이상 | 첫 글자 + 가운데 글자 수만큼 `*` + 끝 글자 |
| 빈 값 | 빈 문자열. 검색 카드 제목만 `학생` |

「학생」 접미사는 붙이지 않는다. 1자 이름은 `*`로 보인다.

## 빈 이름·옛 표시명

- `students.student_name`은 NOT NULL이다. 가입 때 이름이 비면 완료로 보지 않고, 초안 행만 `학생`을 넣는다. 그 값은 2자라 공개되면 `학*`이다. 완료 전에는 노출되지 않는다.
- 예전에 표시명만 있고 `student_name`이 `학생`인 행이 있으면 공개 제목은 `학*`이다. 컬럼의 옛 표시명은 삭제하지 않았고, 공개 API는 읽지 않는다.
- 이름을 다시 저장하면 `public_display_name`도 그 이름으로 맞춘다. 관리자 코드는 그대로라 관리자 목록은 계속 그 컬럼을 본다.
