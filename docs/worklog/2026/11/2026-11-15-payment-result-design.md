# 2026-11-15 결제 결과 화면

지시 요지: `docs/payment-result-popup-2026-11-14`(98fbfb4e)의 결제 결과 지시서대로 `renderPlansResult` 성공·실패·취소·대기 본문만 다시 배치한다. 최신 main `90af5a73`에서 브랜치를 만들고 PR만 연다. 머지·force push·운영 SQL 없음.

추가: `auto_cancelled` 결과에서는 일반 환불 안내와 「다시 결제」를 숨기고, 자동취소 안내만 보여 준다.

이 세션은 자기 작업을 승인하지 않는다.

## 바꾼 것

- 결과 본문을 히어로(성공일 때만 체크), 주문번호 전체, 요약 카드, 환불 안내, 버튼 순으로 배치했다.
- 주문번호는 저장된 문자열 그대로다. `dev-`를 자르지 않는다.
- 값이 없는 줄은 생략한다. 「홍보 배지 없음」은 그리지 않는다.
- 상품 금액은 화면에서만 `결제금액 - 배지 소계`다. 음수면 그 줄을 뺀다. 이번 견본은 85,377원으로 음수가 아니었다.
- 홍보 배지는 지시서 견본과 같이 적용 프로필·지역과 같은 묶음에 둔다.
- 스타일은 `plans-store.css` 끝에 `.plans-result*`만 추가했다.
- 자동취소 결과만 `auto_cancelled: true`를 저장한다. 결제 API·주문번호 규칙·환불 문구·버튼 주소는 그대로다.
