# 18e 결제창·카드전표 상품명 한글화

- 기준: `origin/main` `f3a4d447` (PR #288)
- 2026-11-21. 카드전표 상품명에 영어 코드와 study114가 나오지 않게 한다.

## 지시

`PortOneCheckout::orderName()` 결과를 `우동공과 ` + `PaidCatalog::PRODUCT_NAMES` 화면 이름 + ` ` + variant로 바꾼다.

예: 우동공과 쪽지권 5회권 / 우동공과 쪽지권 1회 / 우동공과 Pick 노출 2주 / 우동공과 Prime 노출 6개월

카탈로그에 없는 productId는 `우동공과 상품` + variant. 함수 시그니처, 금액, 주문 생성, 환불, `ProviderCheckoutService.php`, `PRODUCT_NAMES`는 그대로 둔다.

허용 파일: `src/Paid/Pg/PortOneCheckout.php`, 이 worklog.

## 수정

- `orderName()`은 공개 카탈로그의 화면 이름을 읽어 앞에 `우동공과 `를 붙인다. 옵션이 있으면 한 칸 띄고 이어 붙인다.
- 카탈로그에 없는 코드는 `상품`으로 바꾼다. `study114`와 `memo_ticket` 같은 코드는 상품명에 넣지 않는다.
- `PRODUCT_NAMES` 배열은 수정하지 않는다.

운영 결제창 확인은 배포 뒤에 한다. 결제는 완료하지 않는다.
