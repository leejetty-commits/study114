## 한 일

운영 관리자(`isAdminApiMode()` true)에서는 회원 목록·상세·문자 주소록 동기화에 `A28_MEMBER_SEED`를 넣지 않는다.

- 목록: 캐시가 없으면 「목록을 불러오는 중…」. 캐시를 받은 뒤 0명이면 표를 그리지 않고 「조건에 맞는 회원이 없어요」. 칩·검색·일괄 막대는 유지.
- 상세: API 값이 있으면 유료 배열이 비어도 더미 결제로 채우지 않는다. API 값이 없으면 「불러오는 중…」만 보여 주고 `seed-dummy` / `empty-dummy`로 두지 않는다.
- 문자 주소록: API 모드에서 캐시가 없거나 0명이면 빈 배열로 동기화한다.
- 미리보기(`isAdminApiMode()` false)는 시드와 더미 보강을 그대로 둔다.
