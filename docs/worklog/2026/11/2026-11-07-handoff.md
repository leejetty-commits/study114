#### 왜 `<details>` 방식이 안 되는가

- `<details>` 태그는 **`open` 속성이 없으면** 브라우저가 `<summary>` 뒤 모든 자식에 `content-visibility: hidden`을 적용한다 (HTML 스펙).
- CSS `display: flex`, `visibility: visible`, `content-visibility: visible` 등을 아무리 지정해도, `<details>`가 닫힌 상태이면 브라우저가 강제로 숨긴다.
- 데스크톱(≥1024px)에서 summary를 `display:none`으로 숨기고 panel을 `display:flex`로 열려고 했지만, `<details>`의 `open` 속성이 없으면 panel 내용이 보이지 않는다.
- `<details open>`을 기본으로 하면 아코디언 "접기" 동작이 안 된다 (열린 상태가 기본이 되므로).

#### 재설계 방안 — JS 클래스 토글 방식

**원칙:** HTML `<details>` 를 쓰지 않는다. 일반 `<div>` + `<button>` + JS 토글 + CSS 전환.

**1. HTML 구조 변경 (`right-rail.js` 라인 211~218)**

현재 (`<details>` — 사용 금지):
```html
<details class="plans-rail-fold">
  <summary class="plans-rail-fold__summary"><strong>제목</strong></summary>
  <div class="plans-rail-fold__panel">...</div>
</details>
```

변경 후 (일반 div + button):
```html
<div class="rail-accordion" data-rail-accordion>
  <button type="button" class="rail-accordion__toggle" data-rail-accordion-toggle>
    <strong>제목</strong>
    <span class="rail-accordion__arrow" aria-hidden="true">▾</span>
  </button>
  <div class="rail-accordion__panel" data-rail-accordion-panel>...</div>
</div>
```

**2. JS 토글 로직 (right-rail.js에 추가)**

```js
// 모바일 감지
const mobileQuery = window.matchMedia('(max-width: 1023px)');

// 초기화: 모바일이면 접힘, 데스크톱이면 펼침
function initRailAccordions(root) {
  root.querySelectorAll('[data-rail-accordion]').forEach(el => {
    const toggle = el.querySelector('[data-rail-accordion-toggle]');
    const panel = el.querySelector('[data-rail-accordion-panel]');
    if (!toggle || !panel) return;

    // 모바일이면 접힘 상태로 시작
    if (mobileQuery.matches) {
      el.classList.add('is-collapsed');
      panel.hidden = true;
    }

    toggle.addEventListener('click', () => {
      if (!mobileQuery.matches) return; // 데스크톱에서는 무시
      const collapsed = el.classList.toggle('is-collapsed');
      panel.hidden = collapsed;
    });
  });

  // 리사이즈 대응: 데스크톱으로 가면 항상 펼침
  mobileQuery.addEventListener('change', (e) => {
    root.querySelectorAll('[data-rail-accordion]').forEach(el => {
      const panel = el.querySelector('[data-rail-accordion-panel]');
      if (!panel) return;
      if (!e.matches) {
        // 데스크톱: 항상 펼침
        el.classList.remove('is-collapsed');
        panel.hidden = false;
      } else {
        // 모바일: 접힘
        el.classList.add('is-collapsed');
        panel.hidden = true;
      }
    });
  });
}
```
