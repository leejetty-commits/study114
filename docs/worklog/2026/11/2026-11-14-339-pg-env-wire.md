**머지·배포·force push·운영 SQL:** 하지 않음. `STUDY114_PAYMENTS_ENABLED` 실값은 넣지 않음.

## 지시

`public/.htaccess`에 SetEnv 자리표시자: `PG_PROVIDER`, `PORTONE_STORE_ID`, `PORTONE_CHANNEL_KEY`, `PORTONE_API_SECRET`, `PORTONE_WEBHOOK_SECRET`, `STUDY114_PAYMENTS_ENABLED`.

`deploy.yml`은 OAuth와 같이 GitHub Secrets의 같은 이름을 주입. `STUDY114_PAYMENTS_ENABLED`와 `PG_PROVIDER`는 GitHub Variables. 값이 없으면 빈 값(결제 꺼짐). 값은 로그에 출력하지 않음.

## 한 일

- 저장소의 `.htaccess`는 `__이름__`만.
- 배포 시 Secrets 4개와 Variables 2개를 치환. 비어 있으면 빈 SetEnv. 배포를 막지 않음.
- 시크릿 검사에 이 키를 넣어 실값 커밋을 막음.
