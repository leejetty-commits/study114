# 찾기 화면 파일 분할

## 지시

이 파일을 우선해서 전체 사이트에 영향을 주지 않도록 효율적으로 분할. 필요하면 3분할. 화면 동작·함수 이름·출력 결과는 바꾸지 말고 파일만 나눈다. 검증 스크립트는 옮긴 함수를 따라가도록만 고친다. PR까지 만들고 머지 전 보고. 실시간 매칭 구현은 이 작업이 머지된 뒤 시작.

## 나눈 파일

| 파일 | 역할 |
|------|------|
| `preview/search-ui/src/search-find-place.js` | 지역·게스트·학생 피드·주소 복원 |
| `preview/search-ui/src/search-find-region.js` | 지역 라벨·검색 폼 필드 |
| `preview/search-ui/src/search-find-surface.js` | 결과·검색 실행·클릭. 기존 함수 이름을 그대로 내보냄 |

바깥 화면은 계속 `search-find-surface.js` 만 불러온다.

## 확인

- 함수 122개, 바깥으로 내보내던 이름 24개가 그대로다.
- Vite로 모듈을 불러 같은 24개 함수가 함수로 붙어 있는지 확인했다.
