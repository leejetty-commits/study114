## 승인자 가이드 (남은 2분)

에이전트가 못 한 것만 확인:

1. **시크릿 창**에서 `https://study114.net/auth/#/login` 연다.  
2. **카카오·네이버·구글 중 하나**로 실제 로그인 1회 → 홈/역할 화면까지 가는지.  
3. F12 → Application → Cookies → `study114.net` → 로그인 후 `PHPSESSID`(또는 세션 쿠키)에 **Secure · HttpOnly · SameSite=Lax** 유지되는지.  
4. (선택) 일반 계정으로 `https://study114.net/#/admin` → 여전히 「운영자 전용」인지.

이상이면 스크린샷/한 줄만 알려 주시면 4순위로 넘어감.
