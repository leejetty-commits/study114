# 카페24 뉴아우토반 비즈니스 1:1 문의 결과 (2026-10-16, leejetty 계정, AI 답변)

## 1차 답변 (11개 항목)

- 네임서버를 Cloudflare로 유지한 채 @와 www의 A 레코드를 카페24 서버 IP로 등록하면 된다.
- PHP는 신청할 때 8.4, 8.2, 7.4 중에서 고른다. 신청 후 PHP 8과 7 사이로 바꾸면 DATA와 DB가 초기화된다.
- DB는 MariaDB 10.6.x이고 UTF-8만 지원한다. MySQL 8 데이터는 직접 옮겨야 한다.
- 배포는 FTP, SFTP, SSH를 지원하고 FTPS는 지원하지 않는다. GitHub Actions 호스팅 러너는 해외 유동 IP라서 접속 IP 제한을 「제한없음」으로 둬야 한다.
- cron은 지원하지 않는다. 외부 스케줄러가 URL을 부르는 방식은 가능하다. study114 보고서 메일은 이미 GitHub Actions가 부르는 방식이라 영향이 없다.
- 트래픽은 하루 10GB이고 자정에 초기화된다. 넘으면 즉시 차단된다. 리셋, 자동 리셋, 증설 옵션이 있다.
- 메일은 한 번에 30통, 하루 500통까지 보낼 수 있고 한도를 올릴 수 없다. 무료 메일은 POP3/SMTP만 있고 웹메일 화면은 없다.
- 같은 아우토반 계열 안에서 윗단계로 바꾸면 IP가 유지된다. 한 번 올리면 되돌릴 수 없다. 자이언트플러스는 월 1,200GB 종량제다. (3차 문의로 보정: IP 유지는 퍼스트클래스·자이언트에만 해당. 자이언트플러스는 서버 이전·IP 변경.)
- 비용은 설치비 11,000원에 월 7,000원이다. 장기 결제 할인은 6개월 5%, 12개월 10%, 24개월 12%, 36개월 15%다. 결제 후 7일 안에는 전액 취소할 수 있고 자료는 즉시 삭제된다.
- 동시 접속 수, PHP 동시 처리 수, 메모리는 공개하지 않는다.

## 2차 답변 (SSL 등)

- 타사 도메인에는 무료 SSL과 SSL Basic을 쓸 수 없다. Cloudflare Origin CA 인증서도 설치할 수 없다.
- 방법 (가): 유료 인증서(Positive SSL 라이트 또는 SSL 스탠다드)를 1년 계약으로 산다. 1차(최대 199일)와 2차로 나눠 발급되고, 웹호스팅은 설치까지 자동이다. 인증은 CNAME 방식을 쓰면 Cloudflare DNS에 레코드를 넣으면 된다. 가격은 신청 화면에서만 확인할 수 있다.
- 방법 (나): Let's Encrypt 같은 외부 인증서를 「외부인증서 관리」에 등록한다. 자동 갱신이 안 되므로 90일마다 직접 다시 등록해야 한다.
- 인증서 하나로 @와 www를 함께 덮을 수 있다.
- 확정하지 못한 것: 인증서가 없을 때 443이 어떻게 응답하는지, MySQL 8에서 옮길 때 생기는 문제, Cloudflare를 거친 트래픽을 어떻게 집계하는지.

## 3차 문의 결과 (상품 변경 경로, 2026-10-16, AI 답변)

- 비즈니스 → 퍼스트클래스·자이언트: 같은 서버에서 사양만 올라가서 IP와 인증서가 유지된다.
- 비즈니스 → 자이언트플러스: 월 트래픽 종량 별도 상품이라 새 서버로 이전한다. IP가 바뀌고 이전 중 잠시 차단된다. DATA·DB는 함께 이전되며, 범위는 변경 신청 화면에서 확인한다.
- 자이언트플러스 → 단독웹: 2~3영업일, IP 변경, 단독웹 일반형으로는 갈 수 없다.
- 비즈니스 → 단독웹 직행: 공식 도움말에 따르면 가능. 단독웹에서는 PHP 메이저 버전을 바꿀 수 없고 지원 버전이 제한된다. 결제 기간은 1·3·6개월만 있다.
- Positive SSL 라이트: 다시 살 필요 없다. 서버 이전 시 재설치가 필요할 수 있다(「인증서 받기」에서 내려받은 뒤 「외부인증서 관리」에 등록).
- 장기 결제: 남은 기간 차액을 낸다. 올린 뒤에는 취소하거나 아래로 내릴 수 없다.
- Cloudflare: IP가 바뀌면 @·www A 레코드를 직접 수정한다. 미리 백업한다.
- 도움말: https://help.cafe24.com/faq/server-hosting/introduce/general-inquiry/change-web-to-dedicated-hosting

### 종현 정리 (2026-10-16)

- 자이언트플러스는 단독웹 일반형(월 약 45,000원, 종현 수치)으로 바꿀 수 없다. 올릴 수 있는 곳은 단독 비즈니스(월 약 90,000원, 종현 수치)뿐이라, 자이언트플러스를 거치면 손해다.
- 경로: 뉴아우토반 비즈니스를 쓴다. 필요하면 같은 서버에서 퍼스트클래스 또는 자이언트로 올린다(IP 유지). 고객이 정말 늘면 단독웹 일반형으로 직행한다. 그게 유일한 서버 이전이고, IP가 바뀌므로 Cloudflare A 레코드를 고치고 인증서를 다시 설치한다.
- 자이언트플러스는 경로에서 제외한다.

### 기타

- 카페24로 간다면 「뉴아우토반 비즈니스 + Positive SSL 라이트(CNAME 인증)」 조합.
- Positive SSL 라이트는 연간 38,500원이다. (종현 확인, 2026-10-16 · 상품 페이지와 동일)
- 연 총비용 예시: 설치비 11,000원 + 월 7,000원×12 = 84,000원 + SSL 38,500원 = 첫해 133,500원(장기결제 할인 전).
- 앞서 「같은 아우토반 계열 안에서 올리면 IP 유지」는 퍼스트클래스·자이언트에만 해당한다. 자이언트플러스에는 해당하지 않는다.
- 도메인: 하프도메인(halfdomain.co.kr)에서 구매, 소유자는 종현. SSL 신청 정보는 소유자 정보와 일치해야 한다.
- 7일 전액 취소 기간 안에 DB 덤프 복원 테스트와 하루 트래픽 확인을 끝낸다.
- 호스팅케이알은 BASIC보다 높은 리눅스 상품이 없어서 제외했다. 2026-10-16 이전에 써 둔 8개 항목 문의문은 보내지 않아도 된다.
