## FS-T1-006: rem+px calc 처리

### 1. home.css `.hero-map__eyebrow`
- **선택자**: `.hero-map__eyebrow`
- **이전**: `margin: 0 0 calc(0.125rem + 3px)` (= 5px)
- **이후**: `margin: 0 0 var(--space-1)` (= 4px)
- **사유**: 1px 차이 허용, 최근접 토큰 매핑. eyebrow와 dong 사이 미세 간격이라 시각 차이 미미.

### 2. home-listings.css `.card-visual__promo-badge:not(--new)`
- **선택자**: `.expo-hcard .card-visual__promo--split .card-visual__promo-badge:not(--new)`
- **이전**: `padding: calc(0.1rem - 1.5px) calc(0.4rem - 1.5px)`
- **이후**: raw 유지 + 주석 `/* 1.5px border 보정 — 의도적 비스케일 (FS-T1-006) */`
- **사유**: 1.5px 그라데이션 border 보정 값. 바로 위 `padding: 0.1rem 0.4rem` 배지와 외곽 크기를 맞추는 의도적 비스케일.
