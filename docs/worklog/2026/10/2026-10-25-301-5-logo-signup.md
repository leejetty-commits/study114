## fix1: 가입 이메일 인증 화면 lockup 통일

**기준 tip:** `61b3c936` → 브랜치 `cursor/301-5-fix1-verify-lockup-20261025`

### Gap A

`/signup/verify-email`가 `renderRecoveryStage` → `logo-wordmark.png` 그대로 렌더. 가입 단계 중 이 화면만 lockup이 아닌 wordmark → 수용 기준 "단계 간 동일 B lockup" 위반.

### 수정

- `recovery-stage.js`: `renderRecoveryStage(cardHtml, options = {})` — `options.lockup === true`이면 `brand-hero__logo` 클래스의 lockup 이미지, 기본값은 기존 `logo-wordmark.png` 유지.
- `signup-verify-email.js`: 호출부에 `{ lockup: true }` 추가.
- CSS 추가 불필요 — `.brand-hero__logo` 높이 규칙(2rem/2.5rem) 그대로 적용.
- 비밀번호 찾기 등 기존 recovery 화면: `options` 미전달 → 기존 wordmark 동작 무변경.
