### auth-ui

- `layout.js` `renderBrandHero()`: `logo-full.png` → `logo-lockup-pencil-wordmark.png`, width/height 고정값 제거 (CSS height 기반)
- `base.css` `.brand-hero` / `.brand-hero__logo`: width 기반 → height 기반 (2rem/2.5rem)
- `signup-terms.js`: inline `logo-wordmark.png` → `renderBrandHero()`, 내부 `<div class="panel">` → `<div>` (이중 panel 해소)
- `signup-form.js`: lockup 없음 → `renderBrandHero()` 추가, 내부 `<div class="panel auth-shell__card--wide">` → `<div>` (이중 panel 해소, 외부 shell 이미 `wide: true`)
- `signup-role.js`: 내부 `<div class="panel">` → `<div>` (이중 panel 해소)
- `signup-basic.js` (비학생): 내부 `<div class="panel auth-shell__card--wide">` → `<div>`, shell options에 `wide: true` 추가
- `signup-account-contact.js`: lockup 없음 → `renderBrandHero()` 추가, 내부 `<div class="panel">` → `<div>`
- `signup-complete.js`: lockup 없음 → `renderBrandHero()` 추가, `<div class="panel success-message">` → `<div class="success-message">` (이중 panel 해소). `detail-cta panel panel--muted`는 의도적 강조 박스이므로 유지.
