작성: 2026-09-04 KST  
상태: **5A 최종 보정본 · 운영 적용 전 · Primary 잠금 후보 #266BC4 · 전역 캐논 아님**

클레이 브릭 `#B5402A`는 역할에 없다. 적색 가격도 역할에 없다. `#2B7FFF`는 색 보드 밖 화면에 쓰지 않는다.

### 1.1 Primary 흰 글자 대비 (근사, WCAG 상대휘도)

| 배경 | 흰 글자 대비 | AA 본문 4.5:1 | AA 큰글 3:1 | AAA 본문 7:1 |
|------|-------------|----------------|-------------|----------------|
| `#266BC4` | **5.27:1** | 통과 | 통과 | 미달 |
| `#2B7FFF` | **3.76:1** | **미달** | 통과 | 미달 |

큰 글자 = 18px bold 또는 24px 이상. 본문 버튼 16px/600은 본문 기준으로 본다.

### 1.2 금지 색 사용

- 가격에 Primary·Error·Warning을 쓰지 않는다. 가격은 Ink.
- Primary는 CTA 채움, 활성 메뉴 밑줄, 링크, 포커스, subtle 배경에만.
- Success를 “인증 완료 / 검증 통과 / 보증”처럼 쓰지 않는다.
- 빈 이미지에 브랜드 그라데이션·장식 그라데이션을 쓰지 않는다. Background/Surface + Line.

## 2. 타이포그래피

폰트: **Pretendard만**. 크기 **12 / 14 / 16 / 18 / 22 / 28 / 36**만. 중간 크기·clamp로 새 단계를 만들지 않는다.

| 크기 | 역할 | Weight | Line-height | Letter-spacing |
|------|------|--------|-------------|----------------|
| 12 | 캡션, 뱃지, 통계, 리뷰 배너, 푸터, disabled 이유 | 400 / 500 | 1.40 | 0.01em |
| 14 | 메타, GNB, 필터, Ghost, 섹션 리드, 하단바 이름, disabled 이유(대안) | 400 / 500 / 600(활성 메뉴) | 1.45 | 0 |
| 16 | 본문, Primary/Secondary 버튼, Basic 이름·가격, 하단바 가격 | 400 / 600 / 700(이름·가격) | 본문 1.55 · 이름 1.30 | 이름 −0.01em |
| 18 | Prime·Pick 이름·가격, 레일 이름·가격, 로고, 상세 소제목 | 700 | 1.30 | −0.02em |
| 22 | 섹션 제목 | 700 | 1.30 | −0.02em |
| 28 | 페이지 제목 | 700 | 1.30 | −0.02em |
| 36 | 데스크톱 히어로 | 700 | 1.25 | −0.03em |

카드 안 크기는 최대 3단(이름/가격 · 메타 · 캡션).  
모바일은 **큰 제목만 한 토큰 내림**(36→28, 28→22, 22→18). 본문·메타·캡션·버튼 16은 유지. `RESPONSIVE.md` 참고.

## 3. 간격 — 8pt 베이스 + 4px 보조 스텝

**8pt only가 아니다.** 기본 스텝은 8px(`--s-1`)이고, 밀집 레이아웃(Basic 내부, 칩, 4px 필드 갭)을 위해 **4px 보조 스텝**을 둔다.

| 변수 | 값 | 쓰는 곳 |
|------|-----|---------|
| `--s-0-5` | 4px | Basic 필드 갭, 칩 갭, 뱃지·고스트 세로 패딩. **4px는 이 토큰만** |
| `--s-1` | 8px | 칩 간격, 카드 내부 밀집 갭, 버튼 사이. **`--s-1`은 8px이며 4px와 충돌하지 않음** |
| `--s-1-5` | 12px | Basic 그리드 갭, Basic 카드 패딩, 썸네일 갭, 필터 칩 가로 패딩. **12px 간격은 이 토큰** |
| `--s-2` | 16px | 카드 패딩, 섹션 헤드 아래, 필터 패딩 |
| `--s-3` | 24px | 레일 갭, 히어로 리드 아래, 푸터, 마이페이지 열 갭 |
| `--s-4` | 32px | 페이지 좌우(1440), 페이지 헤드 |
| `--s-5` | 40px | 섹션 상단, 히어로 그리드 갭, 버튼 최소 높이 |
| `--s-6` | 48px | 히어로 상단, 푸터 하단 |
| `--s-8` | 64px | 상세 하단, 넓은 섹션 분리, 헤더 높이 |
| `--s-10` | 80px | 예비 넓은 분리 |

`--s-1` 구충돌: 이전 팩에서 `--s-1`은 이미 8px였다. 이번 보정은 `--s-0-5`(4px)·`--s-1-5`(12px)를 **추가**하고, 본문 CSS의 반복 4px/12px **간격**을 이 토큰으로 치환한다. 1px 보더, 글자 크기, 아이콘 크기(88px 썸네일 등)는 간격 토큰이 아니다.

결정 영역당 Primary CTA는 하나.

## 4. 반지름 · 보더 · 그림자 · 빈 이미지

| 항목 | 값 | 규칙 |
|------|-----|------|
| 카드 반지름 | 12px (`--r-card`) | 카드, 레일, 필터 패널, 히어로 이미지. **반지름이지 간격 토큰이 아님** |
| 컨트롤 반지름 | 8px (`--r-ctl`) | 버튼, 입력, 셀렉트, 썸네일 |
| 뱃지 | 999px (`--r-pill`) | 상태 칩만 |
| 보더 | 1px `var(--uds-line)` | 기본. 2px는 포커스 아웃라인만 |
| 그림자 기본 | 없음 | 카드에 드롭섀도 금지 |
| 허용 그림자 | `--shadow-sticky: 0 1px 2px rgba(15,23,42,.06)` | sticky 레일(≥961px)·하단 CTA만 |
| 금지 | 강한 그림자, 유리(glass), 브랜드 그라데이션, 뉴모픽 | |

이미지 비율: **4:3** (히어로·Prime·Pick·상세). Basic 썸네일은 88×88 (1:1)로 2단 밀도에 맞춘다. 얼굴 생활 사진 없음.

**빈 이미지:** 플랫 쿨 뉴트럴(`--uds-bg` 또는 Surface) + 1px Line. 장식 그라데이션 없음. 가짜 공간 일러스트 없음. 단순 프레임 아이콘 또는 텍스트 「사진 없음」. 비율 4:3 유지.

## 5. Disabled 상태

| 요소 | 표현 |
|------|------|
| Primary / Secondary 버튼 | 배경 `--uds-disabled-bg`, 글자 `--uds-disabled-fg`, 보더 `--uds-disabled-line`. `cursor: not-allowed`, `pointer-events: none`. **흐린 Primary 채움 금지** |
| 입력·셀렉트 | 배경 disabled-bg, 글자 disabled-fg |
| 링크 | muted + 클릭 불가. Primary로 남기지 않음 |
| 대비율(컨트롤) | 의도적으로 AA 미달(약 2.3:1). 비활성은 읽히는 CTA가 아님 |

**Disabled 이유 문구 (권고, 이번 보정):**
- 버튼 **안에** 넣지 않는다. 라벨은 원래 동작명(예: 쪽지 보내기)을 유지하거나 짧게 둔다.
- 버튼 **아래**에 별도 설명(`.ctl-hint`).
- 색은 `--uds-muted` (Surface 위 충분한 대비). disabled-fg로 이유 문구를 쓰지 않는다 — 색만으로 전달하지 않는다.
- 크기 12 또는 14만.
- 클릭 불가와 이유 문장을 함께 쓴다.

Opacity만으로  suffocate하지 않고 토큰 색을 쓴다.

## 6. 960px 경계 (토큰이 아닌 미디어 규칙)

`RESPONSIVE.md`와 동일. CSS:

- `min-width: 961px` → 데스크톱 sticky 레일
- `max-width: 960px` → 레일 static 또는 레이아웃 스택. **정확히 960px에서는 sticky 없음**
- `max-width: 719px` → Basic 1열
- `max-width: 430px` (및 390/360 화면) → 하단 sticky CTA

## 7. 스코프

- 토큰은 `.uds-theme` / `[data-theme="uds-proposal"]` 안에만 산다.
- 전역 `body`는 제네릭 리셋(`#f5f5f5`)이며 사이트 브랜드가 아니다.
