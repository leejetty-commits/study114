# 5A 컴포넌트 — 우동공과 블루 최종 보정본

작성: 2026-09-04 KST  
상태: **5A 스펙 · 운영 적용 전 · 5B 구현 아님**  
**14개** (이전 13개 + Footer 유지 + Mypage 3-column shell 추가). Footer를 교체하지 않는다.

공통 규칙
- 빈 필드는 **숨긴다.** 가짜 값·플레이스홀더 문장으로 채우지 않는다. 단, **가격 미입력 시 숨김 vs 상태 카피 vs 공개 가능 여부는 정책 미확정** — 아래 가격 정책.
- 긴 텍스트는 이름 2줄, 소개 3줄까지. 그 이상은 말줄임. 카드 높이를 글자로 키우지 않는다.
- 증빙 = `있음` / `없음`만. 인증·보증·순위 아님.
- 가격 = Ink. Primary CTA = 블루 채움 하나.
- 금지: Hot / SKY / 1위 / 클레이 `#B5402A` / 전체폭 Basic 단일 행 / 가짜 장바구니 / 본문 전체 반복 레일.

### 가격 빈 값 (Prime / Pick / Basic / 레일 공통)

- **이름**이 있어야 카드가 존재한다. 이름 없음 → 카드 없음.
- 가격은 1차 정보다. 그러나 미입력 시 카드를 목록에서 제외한다고 **말하지 않는다.**
- 미입력 시 공개 표시 · 숨김 · 노출 가능 여부는 **정책 미확정**.
- 5A 목업은 **가격이 있는 예시만** 둔다.
- 「가격 문의」「상담 후 결정」 등 대체 카피를 만들지 않는다.
- 빈 가격을 숨길지, 상태 문구로 줄지는 5A에서 정하지 않는다. 운영·5B로 넘기지 않는다.

간격: 8pt 베이스 + 4px 보조(`--s-0-5` 4px, `--s-1-5` 12px). 본문에서 반복 4px/12px 간격을 토큰으로 쓴다.

### Disabled (권고)

- 전용 배경·글자·보더(`--uds-disabled-*`). Primary처럼 보이지 않음. 클릭 불가.
- **이유 문구는 버튼 안이 아니다.** 버튼 아래 `.ctl-hint`. Muted, 12 또는 14. 색만으로 전달하지 않음.
- 확인: `pages/color-board.html` 비활성 샘플.

## 10. Empty state

**목적.** 아직 없는 다음 행동. 가짜 KPI로 채우지 않는다.

| | |
|--|--|
| 필수 | 짧은 설명 14 muted, 다음 행동 1개(보통 Secondary 또는 링크) |

| 선택 | 없음. 찜·비교는 **본문**에 둔다 |
| 위계 | 정보 왼쪽, CTA 오른쪽 하나 |
| 크기·간격 | 상단 보더 1px, 패딩 10 `--s-2`(16), 하단 `max(10px, safe-area-inset-bottom)`. 본문 `padding-bottom: 72px + --s-3 + safe-area` — 바가 본문을 가리지 않음 |
| 상태 | 기본. 게이트·모달은 미확정 — 바 안에 로그인 카피 넣지 않음 |
| 긴 텍스트 | 이름 ellipsis |
| 데스크톱 | 없음(레일 사용, ≥961 sticky) |
| 모바일 | **430 / 390 / 360** 기본 |
| 금지 | 바 안에 찜·비교·공유를 함께 Primary화, 전체 요약 반복, 모달 시트 확정 표현 |

## 14. Mypage 3-column shell

**목적.** 기존 마이페이지 뼈대를 유지한다. 왼쪽 역할 메뉴, 가운데 상태+핵심 할 일, 오른쪽 보조. **새 마이페이지를 디자인하지 않는다.**

4단계 `room-mypage` 셸과 동일한 개념. 5A는 블루 토큰으로 시각만 맞춘다.

| | |
|--|--|
| 필수 | 3열: 좌 역할 메뉴 · 중 상태 카드+핵심 과제 · 우 안내. 기존 메뉴: 내 등록 / 쪽지·후기함 / 최근열람 / 찜 목록 / 구매이력 / 계정설정 |
| 선택 | 미니 프로필(역할 라벨 + 이름), 우열 쪽지 요약 |
| 위계 | 가운데가 읽기 1순위. Primary CTA는 **가운데에만 하나**. 좌·우에 Primary 채움 없음 |
| 후보 폭 | 좌 `--mp-nav` 220 · 중 `minmax(0,1fr)` · 우 `--mp-aside` 260. 열 갭 `--s-3`(24). 콘텐츠 max `--wrap` 1120. 페이지 패딩 1440=`--s-4` |
| 활성 메뉴 | Primary 글자 + `--uds-primary-subtle` 배경. 역할별 색 분할 없음 |
| hover / focus | hover = off-bg + Ink. `:focus-visible` = 공통 2px Primary 아웃라인 |
| 가운데 상태 카드 | Surface + 1px Line. dt muted / dd Ink. 공개·기본정보·사진·증빙·이용중 상품·쪽지 |
| 오른쪽 도움 | 14 muted. 안내·링크. 결정 CTA 아님 |
| 긴 메뉴 이름 | 2줄 clamp, overflow-wrap. 가로로 레이아웃을 밀지 않음 |
| 빈 상태 | 없는 보조 블록은 숨김. 가짜 완료율 % 없음 |
| 데스크톱 1440 | 3열 유지 |
| 960 | `max-width: 960px`에서 1열 스택. **접힘 순서: 가운데(핵심 과제) → 좌 메뉴 → 우 보조** (grid-area). 정확히 960도 3열 sticky가 아니라 스택 |
| 768 | 스택 유지. 상태 행은 1열 |
| 430 / 390 / 360 | 동일 스택. **모바일 읽기 순서 = 가운데 핵심 과제 먼저.** 하단 탭 최종화 아님 |
| 금지 | 새 마이페이지 메뉴 추가, 관리자 콘솔 이동, **유료상품 GNB 삭제**, 모바일 하단탭 확정, 역할 구조 변경, 역할별 Primary 색 분할, Footer를 이 컴포넌트로 교체 |
