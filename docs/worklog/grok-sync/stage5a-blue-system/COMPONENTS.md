# 5A 컴포넌트 — 우동공과 블루 잠금 후보안

작성: 2026-09-04 KST  
상태: **5A 스펙 · 운영 적용 전 · 5B 구현 아님**  
13개. 마이페이지 3열 셸은 4단계 뼈대 유지이나 5A 화면·본 목록에 넣지 않는다.

공통 규칙
- 빈 필드는 **숨긴다.** 가짜 값·플레이스홀더 문장으로 채우지 않는다.
- 긴 텍스트는 이름 2줄, 소개 3줄까지. 그 이상은 말줄임. 카드 높이를 글자로 키우지 않는다.
- 증빙 = `있음` / `없음`만. 인증·보증·순위 아님.
- 가격 = Ink. Primary CTA = 블루 채움 하나.
- 금지: Hot / SKY / 1위 / 클레이 `#B5402A` / 전체폭 Basic 단일 행 / 가짜 장바구니 / 본문 전체 반복 레일.

## 10. Empty state

**목적.** 아직 없는 다음 행동. 가짜 KPI로 채우지 않는다.

| | |
|--|--|
| 필수 | 짧은 설명 14 muted, 다음 행동 1개(보통 Secondary 또는 링크) |
| 선택 | 점선 표면 |
| 예 | 비교함 비움, 찜 없음, 검색 0건, 카드 사진 없음 |
| 빈 필드 | 빈 상태를 예시 카드 여러 개로 위장하지 않음 |
| 금지 | “인기 1위 공부방이 없습니다” 같은 과장, 스켈레톤을 콘텐츠처럼 |

카드 내부 빈 필드(소개 없음 등)는 Empty state 컴포넌트가 아니라 **필드 숨김**이다. 검색 화면에 사진 없는 Basic 한 장을 예시로 둔다.
