마이페이지: 「내 등록」옆 또는 설정에 **「동네 인사」** 올리기·수정·내리기.

## 3. Must — 홈 레일 · 노출

### 3.1 위치·형태 (§8.1)

- 학생 홈(및 정책상 게스트 홈이 있으면): **히어로(상단 요약) 아래 · 찾기 CTA 위**.
- 섹션명 예: **「우리 동네에 새로 왔어요」**.
- **얇은 레일**(한 줄 흐르기 또는 항목 2~3개). 큰 배너·지도·프라임 목록을 밀지 않음.
- 노출 0건이면 **섹션 통째 숨김**(빈 칸·「없음」문구 금지).
- 오래된 항목은 접기/더보기. 상단 고정 광고처럼 밀어젖히지 않음.
- **같은 희망·홍보 지역** 기준으로만 노출(기존 슬롯 정합).

### 3.2 로그인 학생 · 같은 동네 (§8.3 · §2.6)

- 인사 한 줄(상한 내).
- 표시명·인사·썸네일 클릭 → **베이직카드 팝업**.
- 팝업 「자세히」→ 기존 상세.
- 카드 없음·비공개·탈퇴·삭제 → **「카드를 볼 수 없어요」**만. 빈 상세로 보내지 않음.

### 3.3 게스트 블라인드 (§8.2) — 1차에 **포함**

정책 §2.5는 「1차는 로그인 학생만」이었으나 **§8이 이후 잠금**으로 게스트 티저를 명시함 → **§8 따름**.

- 표시명 부분 가림 + 역할(공부방/과외쌤).
- 인사 **앞 약 20자 + …**.
- 과목 칩 정도. 연락·상세·지도 연결 없음.
- 클릭 → 로그인/가입 게이트 한 줄: **「로그인하면 카드를 볼 수 있어요」**. 카드·연락 미리보기 **금지**. 가입 강요 카피 금지.

1. 건너뛰기만으로 가입/기본등록 완료 → 홈. 독촉 없음.
2. 공부방·과외쌤이 인사 올리면 같은 동네 학생 홈 레일에 보임. 0건이면 섹션 없음.

5. 연락처·URL 패턴 입력 시 저장 거부(또는 필터).
6. 마이에서 수정·내리기 가능. 내려도 등록/검색 불이익 없음.
