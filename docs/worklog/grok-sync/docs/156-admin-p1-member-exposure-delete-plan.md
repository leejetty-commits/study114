## 1. 범위 (이번 1순위에 넣음)

| 넣음 | 빼둠 (나중) |
|------|-------------|
| 회원 목록·상세 버튼 정리 | 「오늘 할 일」홈 전면 개편 (4순위) |
| **탈퇴 처리** = 로그인 불가 + **등록 카드 홈·찾기에서 즉시 안 보임** | 미리보기 메뉴 접기 (3순위) |
| **회원 삭제** = 탈퇴와 분리 + **확인 2단계** | 이용안내 메뉴 이름 (2순위) |
| 회원 상세 ↔ 홈·찾기 노출 연결 | 결제·유료상품 화면 큰 개편 (1순위 중 결제 화면은 **링크만**, UI 대수술은 후순위) |
| 손님 홈·찾기: **탈퇴·삭제된 주인** 카드가 안 나오게 | 쪽지 관리 화면 신설 |
| 관리자용 짧은 확인 문구 (보관연한은 관리자만) | 회원 자가 탈퇴 화면 카피 구현은 **별도 작은 묶음**으로도 가능 — 정책은 153에 이미 확정 |

## 2. 운영자가 보는 화면 — 바꿀 점

### 2-1. 회원

**버튼 (표시 이름 고정)**

| 버튼 | 확인 | 결과 (화면에 쓸 말) |
|------|------|---------------------|
| 정지 | 1회 | 로그인할 수 없어요. |
| 다시 활성 | 1회 | 다시 로그인할 수 있어요. |
| **탈퇴 처리** | 1회 확인 | 로그인 불가 · **올려 둔 등록은 홈·찾기에서 바로 안 보여요** · 쪽지 이름은 성+○○ |
| **회원 삭제** | **2단계** (아래) | 결제 없음 → 전부 지움 / 결제 있음 → 프로필은 내부 보관 후 완전 삭제(안내용은 관리자만) |

**상세에 항상 보이기**

- 이메일 · 역할 · 상태  
- 등록 카드 수 (공부방/과외쌤/학생)  
- 결제 유무 (있음 / 없음)  
- 링크: 「이 회원 카드 → 홈·찾기 노출」

**회원 삭제 2단계 (확정)**

1. **요약** — 이메일 · 역할 · 등록 수 · 결제 유무 · 「지금 홈·찾기에서 안 보여요」 → **다음** / 취소  
2. **재확인** — 「이 작업은 되돌리기 어려워요. 위와 **같은 이메일**을 적어 주세요.」 → 일치할 때만 **회원 삭제**

탈퇴 처리는 2단계 없음.

### 2-2. 홈·찾기 노출

- 탭: **공부방 / 과외쌤 / 학생**  
- 줄마다: 이름 · 지역 · 지금 보임·숨김 · **홈·찾기에서 숨김** / **다시 보이기**  
- 회원에서 넘어오면 그 회원 카드만  
- 말투: 「미노출」 대신 **「홈·찾기에서 숨김」**

### 2-3. 손님·회원 사이트 쪽 (운영 결과)

- 주인이 **탈퇴 처리** 또는 **회원 삭제**되면, 그 사람 등록 카드는 **홈·찾기·상세**에서 바로 안 보임.  
- (지금 구멍) 탈퇴만 하고 카드가 남는 상태는 **이번 1순위에서 없앤다.**

## 3. 정책 요약 (구현 검수용 · 내부)

자세한 제거 범위는 **153**. 여기선 운영 체크만.

| 구분 | 카드(홈·찾기) | 쪽지·후기 | 결제 기록(내부) |
|------|---------------|-----------|-----------------|
| 탈퇴 처리 | 즉시 안 보임 | 쪽지 남김 · 이름 성+○○ · 후기 남김 | 내부 보관(연한은 회원 화면에 안 씀) |
| 회원 삭제 · 무결제 | 즉시 안 보임 · 데이터 전부 지움 | 쪽지·후기도 지움 | 해당 없음 |
| 회원 삭제 · 결제있음 | 즉시 안 보임 | 쪽지·후기 지움 | 내부 보관 후 일정에 따라 지움 |

## 4. 초보 운영자 수락 체크 (나중에 검수할 때)

- [ ] 「탈퇴 처리」와 「회원 삭제」가 **다른 버튼**이다  
- [ ] 탈퇴 처리 후 그 사람 카드가 **손님 홈·찾기에서 안 보인다**  
- [ ] 회원 삭제는 **요약 → 이메일 재입력** 두 번 거친다  
- [ ] 이메일 틀리면 삭제되지 않는다  
- [ ] 회원 상세에서 **홈·찾기 노출**로 바로 갈 수 있다  
- [ ] 화면 말에 soft/하드/원장/5년 같은 **내부 용어가 회원용으로 안 나온다** (관리자 삭제 요약에는 결제·보관만 짧게)

## 7. 1순위 나머지 (같은 단계에서 이어서 논의)

회원·노출·삭제가 핵심이고, 아래는 **같은 1순위**에서 가볍게 잠근다.

### 7-1. 결제·유료상품
- 목표: 「누가 **유료상품**(노출·쪽지권 등)을 샀는지」 목록·상태 확인. 통계·순위는 3순위 미리보기.
- 말투: **유료상품** / **노출** / **쪽지권**. 「이용권」 사용 금지.
- 회원 상세 ↔ 서로 링크만 확실히.

### 7-2. 홈 팝업
- 큰 개편 없음. 마스터로 켜고 끄기·대상(손님/공부방/과외쌤/학생) 검수 체크만.

### 7-3. 신고·문의·제출
- 문의 답장이 **연습용 임시함**이 아니라 사이트에 남는 경로만.
- 신고 처리 상태 분명 · 제출자료 보이기/숨김 결과 한 줄.

**1순위 논의 순서 제안:** 회원·삭제(본문) → 노출 → 결제 링크 → 팝업 검수 → 신고·문의.
