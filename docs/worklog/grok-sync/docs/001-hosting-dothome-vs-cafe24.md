# 001 · 호스팅 비교 — 닷홈 vs 카페24 (우동공과)

- 작성: 2026-09-23 (KST)
- 대상: study114.net / 우동공과
- 목적: 접속 불안정·속도 이슈로 호스팅 이전을 검토할 때, 소상공이용 **작은 유료 플랜** 기준 장단점 정리
- 상태: 참고 메모 (이전 결정 전)

---

## 1. 전제

- 현재: **닷홈** 오리진 + **Cloudflare** 앞단 (`study114.net`).
- 증상: 접속이 불안하고 느릴 때가 있음 → 코드 문제인지 닷홈 서버 불안정인지 미확정.
- 제약: 소상공이므로 **작은 유료 모델부터**. 이후 과금·개인정보 구간은 HTTPS 필요 (특정 업체의 유료 SSL 상품이 필수는 아님).
- 앱 성격: 커스텀 PHP 서비스(워드프레스 전용이 아님). SPA·정적 자산·API가 있어 **디스크·트래픽**이 초소형 플랜에선 빠듯할 수 있음.

**핵심:** 닷홈·카페24 뉴아우토반 모두 **공유형 PHP 웹호스팅**이다. 이전만으로 “느림이 코드인지 서버인지”가 자동으로 갈리지는 않는다.

## 3. 장단점 (우동공과 관점)

### 닷홈

**장점**

- 이미 배포·캐시(`.htaccess` immutable 등)를 맞춰 둔 상태.
- 트래픽이 **월 풀**이라 들쭉날쭉한 일일 사용에 관대.
- 가격이 낮아 **1.5G → 5G**처럼 한 단계만 올려 검증하기 쉬움.

**단점**

- 오리진 TTFB가 간헐적으로 길면 공유 서버 한계로 느껴질 수 있음 (과거 점검에서 엣지 200과 별개로 오리진 지연을 본 적 있음).
- 오리진 인증서가 `*.dothome.co.kr` 위주면 Cloudflare **Full (strict)** 와 호스트명 불일치 → 525 위험. (방문자 쪽 Cloudflare 엣지 HTTPS와는 별개 이슈.)

### 카페24

**장점**

- 상품·모니터링·백업 UI가 정돈됨. SSD, 일일 트래픽 리셋, SMS 알림 등 운영감이 나음.
- 고객센터·상품 라인(단독웹·클라우드 등)으로 이후 확장 경로가 명확함.

**단점**

- **일반형**: 디스크 1.4GB + 하루 4GB는 SPA·이미지·API 있는 실서비스에 빡셈.
- 보유 도메인 SSL은 조건/비용 이슈 (Cloudflare로 엣지는 우회 가능).
- 파일·DB·경로·세션·cron 이사 비용이 큼.
- **공유 호스팅인 점은 닷홈과 동일** → 이웃 부하·느린 PHP는 이전 후에도 남을 수 있음.

## 4. 권장 순서 (소상공 · 작은 유료)

1. **이전 전에** 느릴 때 Cloudflare(엣지)가 느린지 / 닷홈 오리진이 느린지 가르기. 코드·부트만으로 해결되면 이사 불필요.
2. **닷홈에 남는다면** 무료·초소형보다 **5G(월 약 4~5천 원)** 쪽이 실서비스 여유에 맞음.
3. **카페24로 간다면** 절약형·일반형은 비추. 최소 **비즈니스(월 7,000원)** 부터. Cloudflare는 유지 권장.
4. 공유 호스팅을 두 곳 다 써도 불안하면 다음 단계로 **단독웹(카페24 약 5만 원대~)** — 처음부터 갈 필요는 없음.

---

## 5. HTTPS / 과금과의 관계

- 과금·개인정보 취급 시 **HTTPS는 사실상 필수**.
- **카페24·닷홈 유료 SSL 상품을 꼭 사야 하는 것은 아님.** 도메인에 유효한 인증서 + 정상 HTTPS면 됨.
- 우동공과는 Cloudflare로 이미 `https://study114.net` 가능. 우선순위는 “카페24 인증서 구매”가 아니라 **깨지지 않는 HTTPS + (필요 시) 오리진 인증서·CF SSL 모드 정합**.

## 6. 다음에 좁힐 때 필요한 숫자

- 현재 닷홈 상품명(용량) · 월 트래픽/디스크 사용량
- 느릴 때: CF TTFB vs 오리진 직결 TTFB
- 예상 동시 접속·결제 도입 시점

이 숫자가 있으면 「닷홈 5G 업」 vs 「카페24 비즈니스 이전」을 비용·리스크로 한 장 더 좁힐 수 있다.
