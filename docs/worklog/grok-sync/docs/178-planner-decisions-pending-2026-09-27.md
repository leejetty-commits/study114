## B. 기획 선택이 필요한 것

### 1) 검색·등록 앱에서 우측 레일 클릭 시 「메인 사이트로 나감」

- **상황**: 찾기/등록 화면의 레일 링크는 일부러 메인(home) 쪽으로 넘어가게 되어 있음(앱이 둘로 나뉨).
- **질문**: 이 이탈을 **정상**으로 둘까요, 아니면 가능한 한 찾기 화면에 남기거나 안내 팝업을 쓸까요?
- **선택**:  
  - **A** 지금처럼 메인으로 나가도 됨  
  - **B** 남기거나 팝업 쪽으로 줄인다 (별 티켓)

### 2) 학생(학부모)에게 「유료상품 알아보기」 CTA

- **상황**: 학생으로 검색 배너 등에서 유료상품으로 들어가면, 공급자용 화면에 가깝고 메뉴가 빈약해 보일 수 있음(S4).
- **질문**: 학생·비회원에게 유료상품 바로가기를 **보여줄까요?**
- **선택**:  
  - **A** 숨긴다 (공급자 로그인만)  
  - **B** 보여 주되 「공급자용입니다」 안내 후 진입  
  - **C** 지금처럼 두고 화면만 다듬는다

### 3) 마이페이지 위 「마이페이지」 글자(경로 표시)를 눌렀을 때

- **상황**: 지금 누르면 거의 제자리(R3/T3/S5).
- **질문**: 어디로 가게 할까요?
- **선택**:  
  - **A** 마이페이지 첫 화면  
  - **B** 내 등록 목록  
  - **C** 역할 홈  
  - **D** 클릭 불가(글자만, 링크 제거)

### 4) 「소개 페이지에서 보기」가 역할과 안 맞을 때

- **상황**: 과외쌤·학생 맥락인데 공부방 소개(`/promo/study-room`)로 가는 경우가 있음(T4/S6).
- **질문**: 역할마다 소개를 다르게 할까요?
- **선택**:  
  - **A** 과외쌤 → 과외쌤 소개, 공부방 → 공부방 소개, 학생·게스트 → (정할 한곳: 공부방 소개 / 서비스 공통 소개 / 숨김)  
  - **B** 모든 역할 동일(지금에 가깝게 공부방 소개만)  
  - **C** 소개 링크 자체를 레일·마이페이지에서 빼기

### 5) 이용안내의 「찜 목록 보기」「쪽지함 보기」

- **상황**: 카드 상세는 인페이지 「로그인하고…」인데, 이용안내는 마이페이지 전체 화면으로 감(P4).
- **질문**: 어떻게 맞출까요?
- **선택**:  
  - **A** 이용안내도 인페이지 로그인/안내 팝업  
  - **B** 지금처럼 마이페이지로 이동(자연스러운 이탈로 인정)  
  - **C** 비회원만 팝업, 회원만 마이페이지

### 6) 상세 팝업 옆 우측 레일 「현장」칸이 비는 경우

- **상황**: 상세 레일 seed에 공지·안전 등이 있어도, 화면은 고민(concern)만 「현장」으로 써서 칸이 비어 보일 수 있음.
- **질문**: 상세 옆에 「현장」을 어떻게 할까요?
- **선택**:  
  - **A** 칸 숨김(안내·소개만)  
  - **B** 공지·안전 요약을 현장에 허용  
  - **C** 고민 HOT만 채우도록 seed 변경

### 7) 학생 등록(내 등록) 화면 우측 안내가 공부방 고민방 등을 가리킬 때

- **상황**: 학생인데 공급자용 CTA가 남을 수 있음(코드 의심 RR5).
- **질문**: 학생 등록 맥락 레일 CTA는?
- **선택**:  
  - **A** 학생·학부모용만 (이용안내·쪽지·학생 고민 등)  
  - **B** 공통 안내만  
  - **C** 레일 자체를 등록 화면에서 약하게/숨김

### 8) 검색 앱 GNB에 `role=parent`가 비회원에게 붙는 것 (175-D)

- **상황**: 비회원인데 찾기에 `role=parent`가 붙으면 학부모 맥락으로 보임.
- **질문**: 비회원 찾기는?
- **선택**:  
  - **A** 항상 `role=guest` (175에 포함 권장)  
  - **B** parent와 guest UI가 같다면 지금 유지해도 됨  
  - **C** role 쿼리 없애기(서버/클라가 guest 판정)

### 9) 고친 뒤 「한 번 더 점검」범위 (사용자 요청 반영)

- **상황**: 홈 링크 깜빡임을 큰 오류로 보심 → 수정 후 재점검 원함.
- **질문**: 재스모크에 무엇을 넣을까요? (복수 가능)
- **선택 예시**:  
  - **A** 시크릿 비회원: 홍보·커뮤니티 「메인 홈으로」만  
  - **B** + 검색 GNB 홈 vs 배너 홈으로  
  - **C** + 공부방/과외쌤/학생 × 고객센터 「메인 홈으로」  
  - **D** + 유료상품 우측 레일(177 후)

### 10) 시드·관리자(레일 guestFilter) 불일치

- **상황**: 화면 기본값과 DB/관리자 저장이 어긋나면 운영 중 레일이 비거나 너무 열릴 수 있음.
- **질문**: 정본을 어디에 둘까요?
- **선택**:  
  - **A** 코드 시드(right-rail-store) 우선, DB는 덮어쓰기만  
  - **B** 관리자/DB 우선, 코드는 최초 설치용  
  - **C** 당장 손대지 않음(177·175 후)
