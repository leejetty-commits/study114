## 0. 한 줄 목적

학생 **기본정보** 탭을 Basic 카드 핵심값 입력·확인 화면으로 맞춘다.  
필드 세트·카피·저장 연결을 노션 §3-1에 잠그고, **공개 검증 게이트·부족 n개 문법을 폼에서 걷어낸다.**  
상세정보 전면·스키마 대수술·쪽지설정 저장은 **하지 않는다** (D / 별도).

## 1. 범위

### 포함

- `preview/home-ui/src/student-reg/screens.js` — `renderBasicForm` (및 기본정보 전용 바인딩이 같은 파일에 있으면 그것만)
- 기본정보 저장이 이미 쓰는 **기존** student update API / store 경로의 **읽기·쓰기 필드 정렬** (새 엔드포인트 금지가 원칙)
- 기본정보 화면 카피: 자녀/대표*/필수·부족·공개 전 완료 문구 제거 또는 비표시
- 저장 후 마이프로필(또는 기본정보)에서 Basic 카드·profile-read **기본 섹션** 값이 갱신되는지 확인
- 라우팅 + API 점검 증거

### 제외 (한 줄이라도 건드리면 거부)

- 상세정보 필드·카피·저장 재설계 (→ D)
- 마이프로필 카드/리스트 구조 재작성 (→ B 완료, 회귀만 금지)
- 쪽지설정 저장 / PHP `memo_status` allowlist
- 자녀/guardian 전면 청소 (→ E; 기본정보 화면에 새로 쓰지 말 것)
- 공부방·과외쌤 폼, 학생찾기, 가입 온보딩(14장), DB 스키마 대수술
- push / `build:dothome`
- auth/signup 미커밋과 한 커밋으로 섞지 말 것

## 2. 필드 잠금 (노션 §3-1)

기본정보에서 **받고·저장하는** 핵심값:

1. 표시명  
2. 학교급 / 학년  
3. 희망 유형  
4. 희망지역  
5. 희망과목  
6. 수업형태  
7. 수업인원  
8. 예산  
9. **한 줄 요청문** (`request_summary`)

원칙:

- 위 9종 밖 상세 전용 값(특이요청, 출생연도, 성별, 주횟수, 1회시간, 강의스타일, 수업장소 확장 등)을 **기본정보 폼에 끌어오지 말 것.**
- 이미 기본정보 폼에 잘못 섞인 상세 필드가 있으면 **상세로 옮기지 말고 보고**하거나, C 범위에서 **숨김만** (D에서 정리). 조용히 스키마 옮기기 금지.
- 같은 의미 값 이중 저장 금지.
- 「대표 희망*」라벨 금지.
- 필수 마킹·부족 n개·공개 전 완료 카피 금지. 공란은 시각 구분만.

## 3. 저장·API

1. **기존** 학생 수정 API / preview store 경로만 사용. 새 PHP 파일·새 테이블 금지.
2. `request_summary`가 기본정보 저장 payload에 **포함**되는지 확인할 것. 빠져 있으면 C에서 연결. allowlist에 없어 쓰기가 거절되면 **중단·보고** (임의로 다른 컬럼에 쑤셔 넣지 말 것).
3. 저장 성공 후 목록/마이프로필 카드의 한 줄 요청문·예산 등이 갱신되는지 점검.
4. 권한: 본인 학생만. 구멍 보이면 중단·보고.

## 4. UX

- 탭 「기본정보」 URL `#/mypage/registrations/students/{id}/basic` 유지 (A).
- 저장 버튼·성공/실패 피드백은 기존 mypage 패턴. 새 위저드 창작 금지.
- 마이프로필에서 「기본정보 수정」으로 들어왔을 때 폼이 위 9종을 보여 주면 성공.

## 5. 완료 전 필수 점검

### 5-1. 라우팅

1. `#/…/students/1/basic` 진입·새로고침 유지.
2. 저장 후에도 기본정보 또는 합의된 복귀 경로가 깨지지 않음.
3. 마이프로필·상세·쪽지설정·A 리다이렉트 **회귀 없음**.

### 5-2. API

1. 기본정보 로드: 기존 조회 200, 9종 값이 폼에 채워짐.
2. 저장 요청: 네트워크에 **한 줄 요청문·예산 등**이 실려 가고 200(또는 기존 성공 코드).
3. 저장 후 재조회 / 마이프로필 카드 meta의 한 줄 요청문이 바뀐 값과 일치.
4. **새 저장 엔드포인트 없음.** diff에 PHP를 건드렸으면 파일·이유를 명시하고, 스키마 변경이면 중단 사유에 해당하는지 자평.

### 5-3. 예상외 시

중단·보고·승인 대기. 덧대기 금지.
