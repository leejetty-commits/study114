## 4. 종현 확정 (t1157~t1158, 2026-10-02)
- 자료실 = 역할별 팁/정보 게시판 모음. 고객센터 홈 박스 순서는 좌측메뉴와 동일(공지→FAQ→약관·정책→자료실→운영문의).
- 자료실의 샘플 탭 3개·LIBRARY_SEED는 걷어내고 실제 서버 저장 게시판 카드로 채움. 파일 업로드/다운로드는 이번 범위 아님(그누보드/별도 건).
- 새 게시판: 학생용 팁 게시판(이름 제안 「학생 꿀팁 가이드」, 종현 최종명 대기). 이유: 그누보드는 공부방·과외쌤 커뮤니티라 학생 콘텐츠는 여기서 풍성하게. AI가 바로 답하는 질문게시판은 효용 없음 → 경험·정리 중심.
- 분류 6개: 공부 노하우 / 시험·내신 / 입시·진로 / 습관·마음관리 / 선생님·공부방 고르기(종현 수정: 「과외쌤 공부방 고르기」 계열 명칭) / 선배 이야기. 학부모 내용은 별도 분류 없이 「학생(학부모)」로 함께.
- 쓰기 권한(학생 팁 게시판): 유료 공급자 + 관리자 + 학생(경험담). 읽기: 모두(게스트는 제목만 기존 규칙).
- 학생에게도 이 게시판 배너를 레일(홈·학생 레일)에 노출(학생에게 실질 도움). 공부방·과외쌤 정보 게시판 2개는 학생 차단 유지.
- 고민방 3개는 커뮤니티 메뉴가 원래 자리(유지).
- 질문게시판: 별도로 두지 않는 방향 제안(t1158 답변), 확정 대기.
