# 179 — 과외쌤·학부모 소개 랜딩 본문 및 역할별 CTA

상태: 기획 스텁 · 배포/푸시 금지
근거: `178-planner-decisions-locked-2026-09-27.md`, `178a-promo-role-routing-audit-2026-09-27.md`

## 목표

`/#/promo/tutor`에 실제 과외쌤 소개 본문을 만든다. 필요하면 `/#/promo/parent`에도 학부모 소개 본문을 만든다. 본문 구조는 현재 공부방 소개와 맞춘다. 본문이 준비된 뒤 다음 CTA를 역할별 경로로 연결한다.

- `right-rail.js`의 `RAIL_MEDIA_TEASER`
- 레이아웃의 「홍보」 버튼
- 그 밖의 178a 감사에서 확인된 역할별 소개 CTA

과외쌤·학부모 페이지가 없는 동안에는 빈 준비중 페이지로 보내지 않고, 잠금된 임시 정책(공부방 소개 또는 숨김)을 유지한다.

## 공부방 소개만 먼저 있었던 이유

소개 카탈로그에서 과외쌤·학부모가 `planned`로 표시되어 있었고, 우선 기본 서비스 입구인 `STUDY_ROOM_PROMO` 본문만 먼저 작성되었다. 따라서 현재는 공부방 소개만 실제 본문이 있고, 과외쌤·학부모 경로는 제목과 준비중 대체 화면만 있다.

## 구현 방향

1. 과외쌤 소개 본문을 작성하고 카탈로그 상태를 `live`로 바꾼다.
2. 필요 시 학부모 소개 본문도 같은 방식으로 작성하고 `live`로 바꾼다.
3. 역할별 `navRole`에 따라 레일의 랜딩 경로와 레이아웃 「홍보」 경로를 선택한다.
4. 본문이 없는 역할은 빈 planned 페이지에 연결하지 않는다. 숨길 경우 사용자에게 보이는 문구도 실제 상태에 맞는 한국어로 둔다.

## Allowlist 힌트

- `preview/home-ui/src/promo/catalog.js`: 상태를 `live`로 전환
- `preview/home-ui/src/promo/tutor-content.js`(또는 유사한 새 콘텐츠 모듈): 과외쌤 본문, 필요 시 학부모 본문
- `preview/home-ui/src/promo/screens.js`: 역할별 본문 렌더 분기
- `preview/home-ui/src/right-rail.js`: `navRole`별 `landingPath`
- 레이아웃의 「홍보」 경로 선택부: 현재 역할별 소개 경로 연결에 필요한 최소 파일만

## 완료 기준

- `/#/promo/tutor`에서 실제 과외쌤 소개 본문이 보인다.
- 필요 시 `/#/promo/parent`에서도 실제 학부모 소개 본문이 보인다.
- 과외쌤·학부모 역할의 레일 「소개 페이지에서 보기」와 상단 「홍보」가 해당 소개로 간다.
- 학생·게스트 및 본문 미완성 역할은 잠금 정책에 맞는 정직한 경로와 CTA를 사용한다.
- 배포·푸시는 하지 않는다.
