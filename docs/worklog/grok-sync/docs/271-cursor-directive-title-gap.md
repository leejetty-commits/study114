## 3. 수정

### 3-1. 추가할 규칙 1개

- 파일: `preview/home-ui/src/styles/zip-bridge.css`
- 위치: **268 규칙(`> * + *`)보다 뒤.** (뒤에 와야 같은 우선순위에서 이긴다.)
- 내용: 세 화면에서 **`.section-head` 바로 다음 칸**에 `margin-top: 12px`.

```css
/* 271: 제목 → 자기 내용 16px (12px + section-head 아래 4px). 윗블럭 → 제목 32px(268)는 그대로 */
.guide-app .guide-frame__body > .section-head + *,
.concern-app <268과 같은 위치> > .section-head + *,
.support-app <268과 같은 위치> > .section-head + * {
  margin-top: 12px;
}
```

- **실제 셀렉터는 작업자가 268 규칙에 맞춰 정한다.** 268 규칙의 세 셀렉터 각각에서 `> * + *`를 `> .section-head + *`로 바꾼 모양이 기본이다.
- 268 규칙보다 우선순위(특이도)가 낮으면 안 된다. 같거나 높게 만들고, `!important`는 쓰지 않는다.
- 268 규칙 자체(32px)는 **한 글자도 바꾸지 않는다.**
