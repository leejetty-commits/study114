- **상태 포함 잠금:** 코드에 `hidden`/비공개 상태가 실제 존재하므로 숨김도 집계에 포함한다. 학생의 `request_summary`/`special_request_note` `private`·`paid_only`는 본문 공개 범위이지 학생 카드 행 수 필터가 아니다.
- **삭제 제외 잠금:** 명시적으로 삭제된 row는 등록 카드 수에서 제외한다(`study_rooms.deleted_at`, `students.exposure_status=deleted`/`deleted_at`; 과외쌤은 현재 삭제 동작이 `profile_status=hidden` 전환).
- **권장 COUNT:** 공부방·과외쌤·학생 모두 지역 매칭 후 `COUNT(DISTINCT id)`를 사용하고, 유료 테이블 조인이나 guest-visible(`published` only) 필터는 넣지 않는다. 공부방/과외쌤은 지역 매핑 테이블까지, 학생은 희망 공부방/과외 지역 축을 사용한다.
- **근거 문서:** 상세 상태·PHP 검색·프론트 필터 근거는 [125 조사 §9](125-guest-home-122-investigation.md#9-집계-공개숨김-존재-여부-사용자-답-반영)에 잠근다.
- **미확정 문구 갱신:** 아래의 기존 “무엇을 셀지/학생 칸 축 확인 중” 표현은 본 잠금으로 대체한다. 학생 칸도 희망 공부방·과외 지역 축을 기준으로 `COUNT(DISTINCT students.id)`를 적용한다.

## 10. 샘플 채움·블라인드 적용 잠금

- **샘플/빈칸 구조는 변경하지 않는다.** 게스트 홈 및 공부방찾기·과외쌤찾기·학생찾기는 좌측 샘플 1장 + 우측 빈칸, 실제 카드 1건 유입 시 샘플 제거·우측 빈칸 유지, 1행 완성 후 정본 배열·페이지 규칙을 계속 따른다.
- 블라인드는 슬롯 수·행 수·페이지 수가 아니라 **좌측 샘플/실제 카드의 콘텐츠와 CTA**에만 적용한다. 공부방·과외쌤은 공개 표시값과 로그인 게이트, 학생은 이름 마스킹·축약 티저·「로그인하고 보기」를 사용한다.
- 블라인드를 이유로 빈칸을 추가하거나 실카드를 제거하지 않는다. 학생 샘플을 만들 때도 마스킹 티저 필드와 로그인 게이트를 함께 사용한다.
- 손님 홈 베이직 정본 칸수: 비회원 데모 10 (Notion 11장·UDX-30). 04:27 미응답 → 데모 10으로 잠금. 다르게 쓰려면 말씀.
- 게스트 블라인드(정본): 공부방·과외쌤=이름 마스킹 없음·연락처·정확주소·찜/비교/쪽지는 로그인 유도. 학생=이름 마스킹·축약 티저+「로그인하고 보기」. UX 칸수/샘플규칙은 그대로, 카드 내용만 적용.
- 1행 이후(사용자 답 04:29): 픽=1행 5칸. 그 다음부터는 실제 개수만 채움(빈칸 없음). 넘치면 페이지 번호. 프라임=칸 수 고정(3). 베이직 홈 페이지당 칸수(10 vs 20)는 아직 「다 찬 뒤」질문과 별도 확인 가능.
- 프라임 첫 로드 크기 오류: 이번 122에 포함(사용자 답 04:29).
