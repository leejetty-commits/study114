## 3. 수정

### 3-1. 추가할 규칙 1개

- 파일: `preview/home-ui/src/styles/zip-bridge.css`
- 내용: 세 화면에서 **앞 칸이 있는 `.section-head`**에 `margin-top: 32px`.
- 방법 둘 중 하나:
  - (가) **특이도를 높인다.** `> * + .section-head` 모양(클래스 3개)은 공통 규칙(클래스 2개)보다 강하다.
  - (나) 같은 특이도로 **147행 공통 규칙보다 뒤**에 둔다.

```css
/* 271-1: 두 번째 이후 제목도 윗블럭 → 제목 32px. (.uds-theme .section-head 의 margin 0 이 268 규칙을 덮어쓰던 것 보완) */
.guide-app .guide-frame__body > * + .section-head,
.concern-app .concern-frame__body > * + .section-head,
.support-app .sup-frame__body > * + .section-head {
  margin-top: 32px;
}
```

- **최종 셀렉터와 위치는 작업자가 정한다.** `!important`는 쓰지 않는다.
- 제목 아래 4px(`margin-bottom`)는 건드리지 않는다. `margin-top`만 준다.

### 3-2. 하지 않는 것

- `.uds-theme .section-head` 공통 규칙 수정 금지 (다른 화면에 영향).
- 268 규칙, 271 규칙은 한 글자도 바꾸지 않는다.
- 토큰(변수) 값·새 토큰 추가 금지.
