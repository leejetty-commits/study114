## 0. 한 줄

학생 가입 Basic에서 희망유형=**공부방 찾기**일 때, 희망지역「행정동 기준」「아파트단지 기준」모두 **샘플 목록을 제거하고**, 공부방 **홍보지역 선택과 동급의 주소 검색·선택 UI/데이터**를 쓴다.  
표기 깊이: 행정동 → **~동**까지 · 단지 → **~아파트 · 몇 단지**까지(도로명 번지·호수 저장 금지 — 2장).

---

## 1. 잠금 요구

### 1.1 행정동 기준
- 시·군구·동 단계(또는 기존 홍보지역 행정동 피커와 **동일 컴포넌트/API**)로 **실데이터** 선택.
- 「샘플 주소 N」문구·하드코드 대치 목록 **금지**.
- 저장·표시 라벨은 **~동**에서 멈춤.

### 1.2 아파트단지 기준
- 단지 검색/선택도 홍보지역 단지 축과 **동일 알고리즘**(검색 → 단지명까지).
- `complexList()` 하드코드 2건 폴백으로 UI를 채우지 **말 것**. API/공용 소스가 비면 **빈 상태+안내**이지 가짜 샘플이 아님.
- 표기: **단지명(~아파트 · N단지)** 수준. 번지·호 미저장.

### 1.3 공통
- 출발 후보: `preview/auth-ui/src/screens/signup-basic.js` (`complexList` / `renderRegionSelect` / study_room 블록) · 홍보지역 공용(`preview/shared/address-region-match.js`, 개설·홍보1 피커, Region API).
- 가능하면 **공용 피커 재사용**. 복제 하드코드 금지.
- 희망유형=과외쌤 찾기 블록(시 기준)은 **회귀만** — 이번 범위에서 시 매핑 전면 재작업 금지(030 축과 분리).
- 사용자 재현 첨부: `study114-ds/docs/assets/070-student-hope-complex-samples.png` (박스에 있으면 Cursor에 직접 첨부해도 됨).

## 2. 스모크

1. 학생 가입 → Basic → 공부방 찾기 → 행정동: 대치 **외** 동도 검색·선택 가능 · 샘플 N 없음
2. 아파트단지: 실단지 검색·선택 · 대치삼성 3개만 고정 아님
3. 저장 후 라벨이 ~동 / 단지명 깊이
4. 과외쌤 찾기 희망지역(시) 회귀 OK
5. 보고: 파일 · 공용 피커 재사용 여부 · 폴백 제거 · push 안 함
