# 130 · 이용안내·커뮤니티·고객센터 카피 — 「공개/숨김」 전수조사 · 「노출」로 정리

- 상태: **닫음** → [145](145-guide-support-144-deploy-acceptance.md) (`f154183` · dothome #339 · 2026-09-25). 이용안내·고객센터 카피. 커뮤니티 hit 없음. 127은 후순위.
- 성격: 화면/게시 문구 전수조사 → 문맥에 맞게 수정. 코드 status ENUM 대청소와는 별층(필요 시 연결).

## 잠금 (사용자)
1. **이용안내 · 커뮤니티 · 고객센터**에 있는 「공개」「숨김」 등 표현을 **전수조사**한다.
2. 문맥에 맞게 고친다.
3. **카드의 「공개」에는 제한이 없다** → 그런 「공개」 표현은 **제거**.
4. 카드가 나타나는 것은 **「노출」**로 쓴다.
5. (기존) 쪽지 = 「받음 / 안받음」. 손님 블라인드 ≠ 「숨김」 단어.

## 범위 (착수 시 확정)
- 대상 화면·게시판·고정 안내 문구 목록 조사 후 티켓 잠금.
- 제외 후보: 관리자 내부 필터 라벨은 별도 판단(127과 맞춤).
- Notion/로컬 정본 문구와 충돌 시 **최근 정본** + 본 잠금 우선.

## 산출
- 조사표(어디·원문·제안·이유)
- Cursor 수정 티켓(allowlist · 금지 · 스모크)


## 잠금 보강 · 2026-09-25 (사용자)
1. 이용안내 좌메뉴 **「등록 공개」→「등록 노출」**(표기는 형제와 맞춰 **「등록·노출」**).
2. 심사·승인 없음. 상세정보 전부 채울 필요 없음. **가입 필수정보 → 기본 노출**.
3. 내부 정본·코드 카피를 위 뜻에 맞게 치환·수정. Cursor 실행 문서 = **142**.
