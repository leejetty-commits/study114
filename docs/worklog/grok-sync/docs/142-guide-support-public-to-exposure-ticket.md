## 0. 목표 (화면 이름만)

1. **이용안내** 좌측 메뉴·허브 카드·본문에서 **「등록·공개」→「등록·노출」**.
2. 같은 축의 본문이 **심사·승인·상세 전부 채워야 목록에 나온다**처럼 읽히면 **전부 고친다**.
3. **고객센터** FAQ·정책 고지에서 **카드/검색에 보이는 일**을 말하는 「공개」는 **「노출」**로 맞춘다.
4. **커뮤니티**는 대상 카피 hit 없음 → **이번 티켓에서 파일 수정 없음**(스모크만).
5. **내 등록·관리자·검색 SQL·팝업·유료상품** 손대지 않음(127 후순위).

### 1.1 권장 핵심 문장 (가이드 본문에 이 뜻으로)

```text
가입 필수정보를 입력하면 기본 노출이 시작됩니다.
상세등록은 카드와 상세 페이지에 보여줄 추가 정보를 보완하는 단계입니다.
노출을 위한 운영자 심사·승인 절차는 없습니다.
```

### 1.2 반드시 없애거나 바꾸는 오해 문장 (의미)

- 「회원가입만 하면 바로 공개되나요?」→ 게이트처럼 읽히면 안 됨 → **필수정보 입력 후 기본 노출**로.
- 「상세등록 이후 공개」「공개 = 상세등록 이후」「공개 가능 상태」
- 「회원가입만으로 자동 공개되지 않으며… 상세등록 충족…」
- 「검색·리스트에 보일 정보는 대부분 상세등록에서 완성」(→ 필수정보는 가입·기본등록, 상세는 보완)
- 「공개하기」「공개 상태로 전환해 검색에 노출」(→ 전환/게이트 암시 제거)
- 「공개 전 필수 항목」(→ **기본 노출에 필요한 가입 필수정보**)
