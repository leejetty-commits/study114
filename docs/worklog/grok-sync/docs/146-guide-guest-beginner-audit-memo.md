## 2. 순서·이미지로 보완할 부분

### 2.2 만들면 좋은 이미지(시퀀스) — 로컬 작업용 백로그

1. **찾기 5컷**: 메인메뉴에서 공부방찾기 → 지역·과목 필터 → 카드 목록 → 상세 → 찜 버튼 위치  
2. **비교 3컷**: 찜 목록 → 비교에 담기(2~3개) → 비교 화면에서 나란히 보기  
3. **쪽지 2컷**: 상세의 쪽지 버튼 → 쪽지 작성(개인연락처 넣지 말라는 캡션)  
4. **등록 4컷**: 회원가입 → 역할(공부방/과외쌤) → 기본정보(필수만) → 목록에 보임 / 상세등록은 「나중에」 배지  
5. **안전 1컷**: 쪽지 vs 운영문의 버튼을 **나란히  الأحمر**로 구분  

캡션 규칙: 화면 이름만(「공부방찾기」, 「등록·노출」). 코드명·해시 경로 노출 금지.

### 2.3 순서 다이어그램 정리안 (정본으로 통일)

**찾는 분**

`찾기 선택 → 조건 검색 → 상세 확인 → 찜 → (필요 시) 비교 → 로그인 → 쪽지`

**등록하는 분**

`회원가입 → 역할 선택 → 기본등록(필수) → 기본 노출 → (선택) 상세 보완 → (선택) 유료`

차트와 아래 단계 카드·리드 문장이 **이 한 줄과 다르면 전부 수정 대상**.

## 3. 설명이 잘못된 부분 (바로 잡을 문장)

| # | 위치 | 문제 | 수정 방향 |
|---|------|------|-----------|
| A | 비교·찜·쪽지 HTML 리드 | 「**비교 → 찜 → 쪽지** 순으로…」 | **찜 → 비교 → 쪽지**. FAQ·Sx 본문과도 충돌 |
| B | 찾기·첫 이용 | 리드 「찾기 → 찜 → 비교 → 상세」 vs 플로우 「상세가 찜보다 앞」 | **상세를 찜·비교보다 앞**으로 통일(위 2.3) |
| C | 찾기 HTML p2 | 「검색부터 **비교·찜**, 상세…」 | 말 순서도 **찜·비교** 또는 「저장·비교」로. 「비교·찜」을 비교 우선으로 읽히지 않게 |
| D | 등록 플로우 칸 | 「기본 노출」 다음에 또 「검색/리스트 노출」 | **한 단계로 합치기**. 초보에게 두 번 노출처럼 보임 |
| E | 비교·언제 쪽지 | 「**상세등록 정보**를 본 뒤…」 | 찾는 분 기준이면 「**상세 페이지**의 소개·조건」. 「상세등록」은 등록자 용어 |
| F | 쪽지 한 줄 | 「**학생과** 접촉할 수 있는 유일한 채널」 | 찾는 분·등록하는 분 모두 쓰므로 「**회원끼리** 플랫폼 안 첫 연락 통로」로. (이메일·연락처 입력란 없음은 유지) |
| G | 비교 FAQ 「몇 개까지」 | 「최대 3개가 **적절**」 | 실제 하드 제한이 3이면 「**최대 3개**」로 단정. 아니면 「권장 2~3개」와 제한을 분리해 쓰기 |
| H | 안전 「이상시」 | 「관련상황 **채집**」 | 의미는 맞으나 말투가 이상 → §4 |

잠금과 **이미 맞는** 부분(유지): 기본 노출=필수정보 후 / 상세=보완 / 심사·승인 없음 / 쪽지≠운영문의 / 카드 「공개」 게이트 표현 제거(#339).

## 4. 용어가 잘못된·어색한 부분

| 지금 | 권장 | 이유 |
|------|------|------|
| **공급자** (등록·노출 히어로 등) | **공부방·과외쌤** | 사이트 화면 용어. 기획 내부어 금지에 가깝 |
| **공급↔수요** (비교 채널 구분) | **회원끼리** / **공부방·과외쌤 ↔ 학부모·학생** | 초보 가독성 |
| **채집** (안전 플로우·본문) | **기록해 두기** / **캡처·내용 남겨 두기** | 「채집」은 일상 서비스 말투 아님 |
| **이상시** | **이상이 있으면** / **이상할 때** | 띄어쓰기·말맛 |
| **활동 시 1개 선택** (과외 기본등록 목록) | **활동 시·군 1개 선택** (또는 실제 필드명에 맞는 「활동 지역」) | **오탈·잘림으로 보임** — 우선 수정 |
| **공통가입** | 병기 「회원가입(계정 만들기)」 | 메뉴에 「공통가입」이 안 보임 |
| **노출된 신뢰정보** | 첫 등장 시 한 줄 정의(§1.1) | 인증으로 오해 |
| **공개** (「개인정보를 바로 공개하기보다」) | 유지 가능. 필요 시 「바로 **알려 주기**보다」 | 카드 노출과 혼동될 때만 |
| 메뉴 「안전이용」 vs 본문 「안전 이용」 | **안전이용**으로 통일 | 35-1 메뉴명 |
