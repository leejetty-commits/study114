## 종현 확정 (2026-11-12)

1. 「희망지역 추가」는 자유 입력을 없앤다.
2. 학생이 고른 희망 유형(학습유형, `preferred_lesson_type`)을 따른다.
   - 과외: 과외 찾기·과외쌤과 같은 시·도 → 시·군(대분류·중분류)
   - 공부방: 공부방 찾기와 같은 주소검색(동/단지)
3. 기본정보의 본 희망지역과 같은 입력 방식을 그대로 쓴다(위젯 재사용).
4. 추가 지역은 1개만 받으며, 비워도 된다.
5. 찾기·매칭에는 본 지역과 추가 지역을 함께 쓴다. 둘 중 하나만 맞아도 해당한다.
6. 저장은 지금 텍스트 메모(`preferred_region_note`)가 아니라, 본 지역과 같은 구조의 새 칸이다.
7. 예전에 적어 둔 메모는 시·군이나 주소로 자동 변환하지 않는다. 잘못 옮기면 다른 지역이 붙을 수 있기 때문이다.
8. 기존 메모 칸은 화면 입력에서만 뺀다. 컬럼과 이미 저장된 글은 지우지 않는다. 새로 고른 지역만 찾기에 쓰인다.
9. 위치와 라벨은 「희망지역 추가」를 유지한다.

## 범위

1. **입력:** 상세정보 「희망지역 추가」에서 글 입력칸을 없애고, 희망 유형에 따라 본 희망지역과 같은 칸을 둔다. 유형을 바꾸면 추가 칸 UI도 바로 바꾼다. 다른 유형으로 저장해 둔 값은 그 화면에서 보여 주지 않는다.
2. **저장:** `students`에 본 지역과 같은 구조의 추가 칸을 만든다(과외: 지역 id, 공부방: 지역 id·단지 id·basis). 이름은 기존 컬럼과 구분이 되게 하고, 본 지역과 같이 외래키·인덱스를 둔다. `sql/schema/`에 적용 SQL과 롤백 SQL을 추가한다. 번호는 최신 `main`에 있는 다음 빈 번호를 쓰고, 다른 미머지 브랜치 번호와 겹치면 비어 있는 다음 번호를 쓴 뒤 보고에 적는다.
3. **찾기·매칭:** 희망 유형이 과외이면 본 `preferred_tutor_region_id`와 추가 과외 지역을 OR로, 공부방이면 본 공부방 지역과 추가 공부방 지역을 OR로 쓴다. 유형에 맞지 않는 쪽 추가 값은 찾기에 쓰지 않는다. 본 지역만 보던 기존 조건을 모두 찾아 같이 맞춘다.
4. **읽기:** 마이페이지 읽기 화면은 새로 고른 추가 지역의 라벨을 보여 준다. 옛 메모 글을 이 칸의 값처럼 보여 주지 않는다.
5. **기존 메모:** `preferred_region_note` 컬럼과 값은 삭제·변경·자동 이전하지 않는다. 화면 입력과 읽기에서만 뺀다. 저장 API가 이 칸을 받아도 새 추가 지역으로 쓰지 않는다.
6. **필수 여부:** 추가 지역은 필수가 아니다. 기본정보 완료 판정에 넣지 않는다.
7. **문서:** 화면·안내·SSOT에서 이 칸이 자유 입력처럼 적혀 있으면 「희망지역 추가」와 이번 방식으로 맞춘다.

운영 DB에는 이 SQL을 적용하지 않는다. 로컬 검증에만 쓰고, 운영 적용이 필요하다고 보고에 적는다.

## 손대지 말 것

- 기본정보의 본 희망지역 동작(과외 시·도·시·군, 공부방 주소검색)을 새 요구로 바꾸지 말 것. 추가 칸이 그와 같게만 맞춘다.
- 과외쌤·공부방의 지역 입력, 관리자 화면을 새로 꾸미지 말 것. 관리자에 옛 메모가 남아 보이면 발견 목록에만 적는다.
- 학생 이름 가림(366·366-보완), 표시명, 프로모 잠금

## 필수

- 본 희망지역과 추가 지역의 입력 경험(대분류·중분류, 주소검색, 동/단지)이 같아야 한다. 코드를 복제해 다르게 만들지 말고 기존 위젯을 재사용한다.
- 테스트 계정은 `st1`만 쓴다. 실명·실계정을 캡처·로그·보고에 남기지 않는다.
- 관련 기존 verify는 통과해야 한다. 추가 지역이 찾기에 반영되는 검증을 넣거나 기존 검증을 확장한다.

1. 희망 유형을 과외로 두고 상세정보 「희망지역 추가」: 시·도·시·군(대분류·중분류)이 본 희망지역과 같다. 1280·390 캡처.
2. 희망 유형을 공부방으로 바꾸면 추가 칸이 주소검색(동/단지)으로 바뀐다. 1280·390 캡처.
3. 추가 지역을 비운 채 저장할 수 있다.
4. 추가 지역만 다른 시·군(또는 동)으로 저장한 뒤, 그 지역 찾기에서 이 학생이 나온다. 본 지역 찾기에서도 나온다.
5. 읽기 화면에 새 추가 지역 라벨이 보이고, 옛 메모 글은 이 칸에 보이지 않는다.
6. 관련 verify 통과.
