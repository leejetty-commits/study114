# 155 · 관리자 페이지 수정 방향 — 초보 운영자 기준

- **작성일:** 2026-09-25 (KST)
- **목적:** 기획자(코드 비전문)가 **사이트를 안전하게 운용**할 수 있도록, 관리자 화면의 **말투·메뉴·버튼·순서**를 내가 주도해 잡는다.
- **전제:** 사용자는 기획 확인·잠금만. 구현은 이후 Cursor 티켓. **배포·푸시는 별도 지시 전 금지.**
- **근거:** [154](154-admin-main-menu-priority-order.md) 순서 · [153](153-withdraw-vs-admin-delete-policy.md) 탈퇴·삭제 · [152](152-admin-vs-site-member-priority-audit.md) 현황
- **상태:** **방향 잠금 초안** (사용자 「이 순서대로·네가 주도」 수락 반영)

## 0. 한 줄 목표

관리자는 「영카트식 만능 설정판」이 아니라,  
**우동공과를 매일 돌리는 작은 운영 책상**이다.

초보 운영자가 묻지 않고도 할 수 있어야 하는 일:

1. **누가** 가입·결제했는지 보고  
2. **홈·찾기에 뭐가 보이는지** 끄고 켜고  
3. **신고·문의**에 답하고  
4. **테스트 잔여**를 깨끗이 치운다  

그 밖의 메뉴는 「나중에 / 미리보기」로 낮춘다.

## 1. 운영자 눈높이 원칙 (내가 지키는 규칙)

| 원칙 | 뜻 |
|------|-----|
| **사이트와 같은 말** | 관리자도 「노출」「이용안내」「쪽지」처럼 **손님 화면 제목**을 쓴다. 코드명·영문·랩 용어 금지. |
| **위험한 버튼은 이름부터 다르게** | 「탈퇴 처리」와 「삭제」를 섞지 않는다. 확인창에 **이메일·등록 개수·되돌리기 가능 여부**를 보여 준다. |
| **한 화면 = 한 목적** | 「회원 찾기」와 「카드 숨기기」와 「결제 고치기」를 한 페이지에 몰지 않는다. 서로 링크만 건다. |
| **실도구 vs 미리보기** | 아직 문자·PG가 안 붙었으면 메뉴에 **「미리보기」**를 붙이거나 접는다. 실수 클릭 방지. |
| **보관연한은 안쪽에만** | 회원 화면에는 인사만(153). 관리자 확인창에는 「결제 기록은 내부에서 ○년」처럼 **짧게**만. |
| **설명은 버튼 옆 한 줄** | 「이 버튼을 누르면 홈·찾기에서 바로 안 보여요」처럼 **결과**를 적는다. |

## 2. 머릿속 지도 — 메뉴를 이렇게 부른다

지금 사이드바 골격은 유지하되, **보이는 이름·묶음·순서**를 아래처럼 재정렬한다.  
(기술 라우트는 Cursor가 맞추고, 기획은 **왼쪽 이름**만 보면 된다.)

### A. 매일 쓰는 칸 (위쪽 · 강조)

| 새 표시 이름 | 지금에 해당 | 초보가 여기서 하는 일 |
|--------------|-------------|------------------------|
| **오늘 할 일** | 운영 홈 | 짧은 안내 + 바로가기 4개만 |
| **회원** | 회원관리 | 찾기 · 정지 · **탈퇴 처리** · **삭제**(분리) |
| **홈·찾기 노출** | 노출 보정 (+ 필요 시 목록 링크) | 공부방·과외쌤·학생 카드 **보이기/숨기기** |
| **결제·유료상품** | 결제·주문 | 누가 **노출(프라임·픽)·쪽지권** 등 유료상품을 샀는지 · 보정 |
| **홈 팝업** | 팝업 관리 | 손님·역할별 팝업 끄고 켜기 |
| **신고·문의** | 고객응대 | 신고 처리 · 문의 답변 · 제출자료 |

### B. 가끔 쓰는 칸 (가운데)

| 새 표시 이름 | 지금에 해당 | 하는 일 |
|--------------|-------------|---------|
| **공지·안내 글** | 게시판관리 | 공지 · FAQ · **이용안내**(이름 변경) · 채널·우측칸 |
| **사이트 기본** | 환경설정 나머지 | 사이트 이름·점검 · 가입 받기 · 약관 글 · 운영자 계정 |

### C. 지금은 만지지 않는 칸 (아래 · 「미리보기」)

| 표시 | 포함 | 운영 규칙 |
|------|------|-----------|
| **미리보기 · 마켓** | 현황·목록·매출·후기·미완료(실연동 전) | 열어봐도 됨. **실데이터로 믿지 말 것** |
| **미리보기 · 문자·부가** | 알림·문자 · 부가서비스 · 홍보 런치 | 연동 전까지 **접어 두기** 권장 |
| **작업 기록** | 운영 로그 | 문제 났을 때 「누가 무엇을 눌렀는지」 확인 |

## 3. 「오늘 할 일」홈 — 초보용 첫 화면

운영 홈을 **대시보드 숫자판**이 아니라 **체크리스트형**으로 바꾼다.

**고정 카드 4장 (문구 초안)**

1. **회원 정리** — 「테스트 계정·탈퇴·삭제」 → 회원으로  
2. **홈에 뭐가 보이나** — 「카드 숨기기·다시 보이기」 → 홈·찾기 노출로  
3. **문의·신고** — 「답장할 글」 → 신고·문의로  
4. **홈 팝업** — 「지금 뜨는 팝업」 → 홈 팝업으로  

아래에 한 줄:  
「아래쪽 **미리보기** 메뉴는 아직 연습용이에요. 실운영은 위 네 가지만 쓰세요.」

## 4. 1순위 화면 — 수정 방향 (상세)

### 4-1. 회원

**목표:** 「이 사람 로그인만 끊을지 / 사이트에서 통째로 치울지」를 헷갈리지 않게.

| 버튼(제안) | 언제 쓰나 | 누르면 생기는 일 (화면에 쓸 말) |
|------------|-----------|----------------------------------|
| **정지** | 잠시 막고 싶을 때 | 로그인 불가. 카드는 별도로 숨길 수 있음 |
| **다시 활성** | 정지 해제 | 다시 로그인 가능 |
| **탈퇴 처리** | 회원 요청에 준하거나, soft로 계정만 닫을 때 | 로그인 불가 · **등록 카드는 홈·찾기에서 바로 안 보임** · 쪽지 이름은 성+○○ (153) |
| **회원 삭제** | 테스트·더미, 또는 관리자 제재 | **결제 없음** → 전부 지움 / **결제 있음** → 프로필은 1년 내부 보관 후 완전 삭제, 결제 기록은 더 김 (관리자 확인창에만). **확인 2단계 필수** |

**회원 상세에 반드시 보일 것**

- 이메일 · 역할(공부방/과외쌤/학생) · 상태  
- **등록 카드 개수** + 「홈·찾기 노출로 가서 숨기기」 링크  
- 결제 유무(있음/없음) — 삭제 버튼 분기용  

**「회원 삭제」 확인 2단계 (확정 · 2026-09-25)**

한 번 눌러서 바로 지우지 않는다. **요약 확인 → 재확인** 두 창을 거친다.

| 단계 | 화면 | 운영자가 하는 일 |
|------|------|------------------|
| 1 | **삭제 요약** | 이메일 · 역할 · 등록 카드 수 · 결제 유무 · 「지금 홈·찾기에서 안 보이게 됩니다」를 읽고 **다음** |
| 2 | **재확인** | 대상 **이메일을 그대로 입력**한 뒤 **회원 삭제**를 다시 누름. (입력 틀린면 진행 불가) |

- 1단계에서 **취소**면 아무 일도 없음.  
- 2단계 문구 초안: 「이 작업은 되돌리기 어려워요. 위 이메일이 맞다면 아래에 같은 이메일을 적어 주세요.」  
- **탈퇴 처리**는 지금처럼 확인 1번으로 둔다. **2단계 재확인은 「회원 삭제」에만** 둔다.

**초보 실수 방지**

- 「탈퇴 처리」만으로 카드가 안 빠지던 **현재 구멍**은 1순위 구현에서 **반드시 막는다** (153).

### 4-2. 홈·찾기 노출

**목표:** 손님 홈·찾기에 **무엇이 보이는지**만 다루는 방.

- 공부방 / 과외쌤 / 학생을 탭으로 나눈다.  
- 각 줄: 이름 · 지역 · 지금 보임/숨김 · **숨기기 / 다시 보이기**  
- 회원 화면에서 넘어오면 해당 사람 카드만 필터.

말투: 「미노출」「비공개」보다 **「홈·찾기에서 숨김」**.

### 4-3. 결제·유료상품

**목표:** 「누가 **유료상품**(노출·쪽지권 등)을 샀는지」 확인·가벼운 보정.
※ 「이용권」이라는 말은 쓰지 않는다. 사이트와 같이 **유료상품** / **노출** / **쪽지권**으로 부른다.

- 목록 + 상태. 복잡한 통계는 3순위(미리보기)로 둔다.  
- 회원 상세와 서로 링크.

### 4-4. 홈 팝업

**목표:** 이미 된 것 **유지·검수**. 큰 개편 없음.

- 대상(손님/공부방/과외쌤/학생)이 사이트와 같은지 확인 체크리스트만 운영 메모에 둔다.  
- 마스터 계정으로만 (기억: jetty@naver.com).

### 4-5. 신고·문의·제출

**목표:** 「답장 창」이 연습용이 아니라 **진짜 글**로만 보이게.

- 문의: 답장하면 사이트에 남는 경로만 쓰기 (세션 임시함 오해 제거).  
- 신고: 처리 상태만 분명히.  
- 제출자료: 보이기/숨기기 결과를 한 줄로.

## 6. 내가 주도하는 진행 방식 (당신 역할)

| 단계 | 내가 함 | 당신이 함 |
|------|---------|-----------|
| 방향 | 이 문서처럼 **말·버튼·순서** 제안 | 「OK / 여기만 바꿔」 |
| 잠금 | 확인 카피·버튼 이름 확정 | 한 줄 수락 |
| 티켓 | Cursor에 **붙여넣기용** 지시문 (화면 제목·금지 범위) | PC에서 붙여넣기 |
| 검수 | 「초보 운영자 체크」로 결과 대조 | 화면 보고 수락/보완 |
| 배포 | **당신이 「배포」라고 할 때만** | 배포 지시 |

지금은 **1순위 방향까지 이 문서로 잠근 것**으로 본다.
