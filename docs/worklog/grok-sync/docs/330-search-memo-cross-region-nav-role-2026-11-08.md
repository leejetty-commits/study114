## 운영 정책 (승인자 확정 · 2026-11-08)

| 항목 | 정책 |
|------|------|
| 쪽지 **지역 제한** | **없음.** 같은 행정동·단지에서만 보내야 하는 규칙이 아니다. |
| 홈 카드 | 보통 **내 동네** 중심으로 보이므로, 홈에서는 같은 지역만 쪽지하는 것처럼 **느껴질 수 있음** (노출 범위 ≠ 쪽지 금지). |
| 다른 지역으로 보내기 | **공부방 찾기 / 과외쌤 찾기**에서 가능. 이사·이전 예정 등 이유로 다른 동네에 보내도 된다. |
| 학생 → 공부방 (찾기) | **허용** — 상대가 「받는 중」일 때 |
| 학생 → 과외쌤 (찾기) | **허용** — 동일 |
| 악용·스팸 | 수신측(공부방·과외쌤)이 **차단**으로 대응 |
| 홈 같은 동네 | 카드가 뜨면 기존처럼 쪽지·수신 가능 |

---

## 쉬운 말 — 무엇이 버그였나

- 코드에도 **지역으로 쪽지를 막는 조건은 없었다.**
- 막힌 이유: 찾기 SPA(`/search/#/search/…`)에서 로그인 학생을 **손님(guest)** 으로 착각 → 「이 대상에게는 쪽지를 보낼 수 없습니다.」
- 수정 후 찾기에서도 세션 역할(학생)을 쓰도록 고침.
