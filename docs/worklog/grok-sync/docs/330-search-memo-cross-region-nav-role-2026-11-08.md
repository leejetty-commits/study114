## 쉬운 말 요약

- **홈**에 뜨는 카드는 보통 **내 동네(행정동·단지)** 중심이라, 같은 지역에서만 쪽지하는 것처럼 느껴질 수 있다.
- 정책상 **쪽지를 같은 지역으로만 제한하지 않는다.** 이사·다른 동네 탐색은 **공부방 찾기 / 과외쌤 찾기**로 보내고, 싫으면 상대가 **차단**하면 된다.
- 코드에도 **지역으로 쪽지를 막는 조건은 없었다.**
- 막힌 이유: 찾기 SPA(`/search/#/search/…`)에서 쪽지 시작이 로그인 학생을 **손님(guest)** 으로 착각함 → 「이 대상에게는 쪽지를 보낼 수 없습니다.」
