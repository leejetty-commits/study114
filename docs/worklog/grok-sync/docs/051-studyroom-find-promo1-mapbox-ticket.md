## 0. 한 줄

로그인 공부방이 **공부방찾기**에 들어오면 게스트 대치동 데모가 아니라 **홍보1(가능동)**이 현재위치·맵·상세검색 지역 기본·프라임/픽/베이직 `현재위치`에 깔린다.  
맵 요약 박스 카피·상태 dl·갯수 규칙은 **046과 동일**. 상세검색 폼은 **찾기에서 유지**.

## 3. 알고리즘

1. 공부방 로그인 + `#/…공부방찾기`(정확 라우트 확인): 진입 시 `activeRegionLabel`/canonical = 홍보1 (`promo_label` 경로, 048 폴백 금지).  
2. 맵·섹션헤더·상세검색 지역 필드가 그 SSOT 소비.  
3. region 모드 목록 = 그 지역 검색 결과. self 방을 지역 무시하고 끼워 넣지 말 것(필요 시 047과 조율·보고).  
4. 검색 클릭 후 = 폼 지역·필터 적용(학생찾기 050과 같은 “기본 홍보1 → 검색 시 필터”).

## 5. 스모크

1. 공부방찾기: 현재위치·맵 동·상세검색 지역 기본·베이직(및 프라임/픽) 현재위치 = **가능동/의정부 가능동**. 대치 **0**

5. 게스트 공부방찾기 = 대치 데모 유지
