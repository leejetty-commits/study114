### 2.1 사용자 잠금 — 에스크로 · 분류 정정 (2026-09-25)

1. **에스크로 제거 (확정)**  
   - 우동공과는 에스크로를 **시행하지 않는다**.  
   - FAQ 질문 제목·본문·허브·안전 시드·손님용 안내에서 **「에스크로」 단어를 쓰지 않는다**.  
   - 「안전번호나 에스크로가 있나요?」류는 **「안전번호·대금 보관이 있나요?」**로 바꾸고, 답은 「없습니다. … 제공하지 않습니다」.  
   - 약관·플랫폼 역할 고지에 남아 있는 「에스크로 … 제공하지 않습니다」도 로컬 작업 시 **「대금 보관·안전결제를 제공하지 않습니다」**로 바꿔, 없는 제도 이름을 손님에게 가르치지 않는다.

2. **분류·위치 정정 (확정)**  
   - §3의 A~F는 「검토」가 아니라 **고칠 대상으로 채택**.  
   - 특히: 이용=이용안내 / 고객센터=공식 도움·정책·운영문의 경계 유지, `#/support/safe`→이용안내 안전이용 유지, 고객센터 「안전과외」는 **약관·정책**으로 모음, FAQ는 정책·채널 중심·이용 순서 상세는 이용안내 링크.

## 5. FAQ — 시드 교체·대폭 보강 (수정+추가)

### 5.1 기존 6문항 수정문

**Q. 회원끼리 연락은 어떻게 하나요?**  
A. 회원 간 공식 연락은 **쪽지**입니다. 우동공과가 전화·이메일을 대신 연결해 주지는 않습니다.

**Q. 운영·서비스 문의는 어디로 하나요?**  
A. 고객센터 **운영문의**(로그인 후 문의 폼)로 남겨 주세요. 답변은 적어 주신 이메일과 **마이페이지 → 내 문의 내역**에서 확인할 수 있습니다. 쪽지함과는 다른 채널입니다.

**Q. 안전번호나 대금 보관이 있나요?**  
A. 없습니다. 안전번호·대금 보관·안전결제·보증·분쟁 대리는 제공하지 않습니다. (**에스크로라는 말은 쓰지 않음** — 제도 자체 미시행.)

**Q. 유료 서비스는 학부모가 구매하나요?**  
A. 아닙니다. **공부방·과외쌤**용 동네 노출(프라임/픽)·쪽지권 등이며, 학부모의 과외비·수업료 결제와는 무관합니다.

**Q. 프라임/픽은 무엇인가요?**  
A. 동네에서 더 잘 보이도록 돕는 **기간형 노출 상품**입니다. 주목·추천 같은 광고 표시는 이 상품에 함께 적용되는 경우가 있습니다. 자세한 안내는 유료상품 화면을 보세요.

**Q. 환불·과외비 분쟁은?**  
A. 당사자끼리 협의하는 것이 원칙입니다. 우동공과는 과외비·환불 분쟁을 대신 조정하거나 대금을 보관하지 않습니다. 필요하면 약관·정책의 안전과외·신고 안내를 확인하세요.

### 5.2 추가 FAQ (고객센터용 · 권장 18+)

**이용·채널**

1. 이용안내와 고객센터는 무엇이 다른가요? → 이용=사용 흐름 / 고객센터=공지·FAQ·운영문의·정책  
2. 쪽지와 운영문의 차이가 뭔가요? → 회원끼리 vs 운영팀  
3. 로그인 없이 문의할 수 있나요? → 운영문의는 로그인 후. FAQ·공지·일부 정책은 게스트 가능  
4. 내 문의 답변은 어디서 보나요? → 마이페이지 → 내 문의 내역  

**찾기·등록(짧게 + 이용안내 링크)**

5. 가입만 하면 목록에 보이나요? → 필수정보 입력 후 기본 노출. 심사 없음. 자세한 순서→이용안내 등록·노출  
6. 학생찾기는 학부모용인가요? → 아니요. 공부방·과외쌤이 요청을 보는 메뉴. 학부모는 공부방찾기·과외쌤찾기  
7. 비교는 몇 개까지인가요? → **최대 3개**. 더 보려면 내려놓고 다시. 상세→이용안내 비교·찜·쪽지  

**안전·정책**

8. 선입금을 요구받으면? → 조건·환불 확인 전 서두르지 말 것. 안전과외·이용안내 안전이용  
9. 제출·증빙은 우동공과가 확인하나요? → 아니요. 참고용. 보증·심사 없음  
10. 신고는 어디서 하나요? → 약관·정책의 신고·제재 + 운영문의  
11. 학생 개인정보는? → 필요한 범위만. 민감정보는 쪽지로도 조심  

**계정·유료**

12. 비밀번호·로그인이 안 돼요 → 운영문의(계정·로그인)  
13. 학부모가 프라임을 사야 하나요? → 아니요(위 유료 FAQ와 통일)  
14. 환불은 과외비가 아니라 유료상품인가요? → 상품별 정책·문의. 과외비는 당사자
