## 구현

1. 메일 주소 상수는 `preview/shared/inquiry-contact.js`에만 둔다. `mailto:`와 화면에 보이는 주소가 서로 어긋나지 않게, 주소 문자열을 한곳에서 만든다.
2. 패널 항목은 `preview/shared/back-to-top.js`에서 로그인 여부에 따라 맞춘다. 로그인 판별·이벤트(`auth:login` / `auth:logout` / `auth:session-hydrated`, 패널을 열 때 재동기화)는 현행을 유지한다. `auth-session.js`를 shared에 직접 import하지 말 것.
3. 비로그인 둘째 항목 구성:
   - 첫째 줄 「이메일 문의」, 둘째 줄 `help@study114.net`. 주소는 줄바꿈되어도 잘리지 않게 한다. 사용자에게 픽셀 숫자를 보여 주지 말 것.
   - 항목 전체를 눌러 복사한다. 복사 전용 버튼을 따로 두지 말 것.
   - 클릭 시 `help@study114.net`을 클립보드에 넣고, 「메일 주소를 복사했어요」를 짧게 보여 준 뒤, `mailto:help@study114.net`도 연다(받는 사람 유지).
   - 복사가 실패해도 「복사했어요」라고 말하지 말 것. 주소는 화면에 남아 있으므로 직접 고를 수 있다. 이 경우에도 mailto는 시도한다.
4. 안내는 모달(`s114Alert`)을 쓰지 말 것. `preview/home-ui`의 `showP24Toast`는 shared에서 import하지 말 것(auth-ui 번들에 home-ui가 딸려 들어간다). 짧은 토스트는 `preview/shared`에 작은 헬퍼로 두거나, 이 패널에서만 쓰이는 짧은 안내로 구현한다. `role="status"`로 읽히게 한다.
5. 로그인 둘째 항목은 지금처럼 라벨 「운영문의」, `inquiryContactUrl()`만. 주소 줄·복사·mailto를 붙이지 말 것.
