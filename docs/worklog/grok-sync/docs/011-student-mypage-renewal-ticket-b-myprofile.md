## 0. 한 줄 목적

학생 **마이프로필** 본문을 검수판이 아니라 **확인형**으로 채운다.  
상단 = **홈과 같은 학생 Basic 카드(실측)**, 아래 = **과외쌤 마이프로필과 같은 리스트형 자기확인** + 기본정보/상세정보로 가는 수정 링크.  
기본·상세 **폼 필드·저장·검증 재설계는 하지 않는다** (C/D).

## 3. UI 잠금

### 3-1. 마이프로필 위계 (고정)

1. 상단 탭 (A 유지, 건드리지 않음이 원칙)
2. **학생 Basic 카드** — 홈 `#/search/student` Basic과 **같은 마크업·같은 실측 크기**
3. **리스트형 정보 구역** — 과외쌤 마이프로필(`renderTutorProfileRead`)과 같은 확인형 레이아웃
4. 항목 **수정** → `#…/basic` 또는 `#…/detail`로 이동 (인라인 저장 폼 금지)
5. 공란은 경고/필수 마킹 없이 **시각적 구분**만 (톤·배경). “아직 부족 n개” 금지

### 3-2. Basic 카드

- **재사용 우선.** 홈과 다른 카드 HTML을 새로 그리지 말 것.
- viewer: 본인 확인용이므로 게스트 티저/로그인 게이트·공급자 쪽지 CTA는 **끄거나 무력화**. `open-student-detail`로 검색 상세가 열리면 안 된다 (마이프로필에서는 카드 = 미리보기만).
- 표시 핵심: 표시명, 학교급/학년, 희망 유형·과목·지역, 수업형태·인원, 예산, **한 줄 요청문** (`request_summary`). 특이요청은 카드 필수가 아님(상세 책임).
- 데이터가 비면 카드가 깨지지 않게 empty 처리. 공개 게이트 문구를 카드 위에 올리지 말 것.

### 3-3. 리스트형 자기확인

과외쌤 마이프로필 섹션 구조를 준용하되, 학생 필드만 채운다.

| 구역(권장) | 값 출처 | 수정 링크 |
|------------|---------|-----------|
| 기본 노출 요약 | Basic 핵심 (표시명~예산, 한 줄 요청문) | → 기본정보 |
| 확장·매칭 | 상세 (추가지역, 장소, 횟수·시간, 스타일, 성별, 출생연도, 특이요청) | → 상세정보 |
| (선택) 쪽지 수신 | `memo_status` 읽기 표시만 | → 쪽지설정 탭. **저장 버튼 금지** |

- “대표 희망*” 라벨 금지 (노션 §6).
- 리스트에 공개하기 / 미리보기 / 부족 체크리스트 / 숨김·삭제 danger zone **넣지 말 것** (A에서 뺀 것 되돌리지 말 것).

### 3-4. 디자인

- 기존 `mp-room` / mypage / `expo-basic` 클래스 재사용. 새 디자인 시스템 창작 금지.
- Stage5B 전면 패스는 F. B는 레이아웃·정보가 맞게 보이면 충분.

## 4. 구현 원칙

1. A 라우팅·탭·리다이렉트를 **회귀시키지 말 것.**
2. 쓰기 API·스키마 변경 없이 **읽기 + 화면 조립**만.
3. student store / `GET …/students.php` 응답으로 카드·리스트를 채울 것. 매핑이 애매하면 **중단·보고** (가짜 하드코딩 금지).
4. 예상외 오류·티켓 밖 파일 필수 시 → 즉시 중지·보고·승인 대기. 덧대기 금지.

## 5. 완료 전 필수 점검 (라우팅 + API)

보고에 **경로와 결과**를 적을 것.

### 5-1. 라우팅 (학생 세션, id=1)

1. `#/mypage` → 마이프로필. 상단에 Basic 카드가 **보인다** (플레이스홀더 문구 없음).
2. 카드 아래 리스트가 보이고, 기본정보/상세정보 **수정 링크**가 각 탭으로 이동한다.
3. 기본정보·상세정보·쪽지설정 탭은 A와 동일하게 유지. 폼 필드 세트가 B에서 **늘어나지 않았다**.
4. publish·목록 URL은 여전히 마이프로필. 마이프로필에 공개 CTA가 **다시 생기지 않았다**.
5. 공부방·과외쌤 마이프로필/허브 스모크: 깨짐 없음.

### 5-2. API

1. 마이프로필 진입 시 학생 조회(기존 list/detail) **200** 또는 의도적 empty가 명확.
2. 카드에 보이는 한 줄 요청문·희망지역 등이 API/스토어 값과 일치 (예: 부산).
3. **새 저장 API 없음.** 실수로 저장을 건드렸으면 diff에 명시.

### 5-3. 예상외 오류 시

재현 경로·콘솔/네트워크·최소 시도만 보고하고 **승인 대기**.
