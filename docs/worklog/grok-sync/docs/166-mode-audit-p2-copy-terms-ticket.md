## 3. 이슈별 「커서 주석」·오판 방지

### 공통

> 1. **영문 상수키**(enum `BASIC`, i18n key `EXPOSURE`)는 코드에 남아도 됨. **화면에 찍히는 문자열**만 한국어.  
> 2. **해시 라우트·파일명·API path rename 금지.**  
> 3. **146–148** 긴 FAQ/가이드 문단을 이 커밋에 섞지 말 것. START HERE / Go use **배지 두 개**만 예외.  
> 4. 제품명 **베이직카드/픽/프라임**을 다시 BASIC 등으로 되돌리지 말 것.  
> 5. 「학생 의뢰」가 보이면 **등록**으로 (164와 동일 정책). 이 티켓 범위 밖이어도 **회귀 검사**에 넣을 것.

### N11–N14

> - 유료상품·등록점검·커뮤니티 **뱃지 컴포넌트**가 영문 하드코딩이면 카피 맵/상수로.  
> - `pending`을 「팬딩」「대기중」애매어로 쓰지 말 것 → **결제 대기**.  
> - Basic/Pick/Prime이 **CSS class**면 class는 유지, **라벨 텍스트만** 한국어.

### N15–N16

> - 「시드」「서버 상태값」은 개발 내부어. 사용자 문장에 **절대** 남기지 말 것.  
> - AFTER 문장을 **임의로 더 기술적으로** 쓰지 말 것. 표의 정중체 유지.  
> - 151 쪽지설정 레이아웃(흰카드·이유 우측)은 **EXCLUDE · 이번 아님**. 카피 한 줄만.

### N17

> - 주대상 옵션 라벨만. 검색 API payload 키를 `대입준비`로 바꾸지 말 것(깨짐).  
> - SKY를 「SKY대」「스카이」로 순화하지 말 것 → **주요 대학 출신 우선**.

### N18

> - 「마이샵」→「프로필 꾸미기」. 「샵」「스토어」잔존 금지.  
> - `#/promo/study-room`을 과외 화면에 남기면 **실패**. 숨김 또는 과외 프로모(있을 때만).  
> - 학생 사이드 「소개 페이지에서 보기」동일.

### N19

> - 접근성: `aria-label` 필수에 가깝게. 마우스 `title`만으로 끝내지 말고 가능하면 둘 다.  
> - 비교/찜/쪽지 **기능 자체**를 이 티켓에서 재설계하지 말 것. 라벨·툴팁·0 의미 완화만.

### N20–N21

> - 「지도 스타일」오타/오역 수정이지 지도 UX(150)와 무관.  
> - 지역 join: `sido + ' ' + sido` 버그 가능성. **고유 파트만** join.  
> - IELTS·최근 본 목록: **데이터 중복 vs 더블 렌더** 구분. UI map 키/필터로 dedupe.
