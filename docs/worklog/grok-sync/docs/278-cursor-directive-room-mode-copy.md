## 쉬운 말 요약 (종현 확인용)
- 이용안내 「찾기·첫 이용」의 첫 단계 문장을 모든 사용자에게 같게 바꾼다(F-07). 이용안내 화면은 계정마다 다르게 만들지 않는다.
- 개발 말(「정본 라우트」, 「가이드와 별도 유지」)을 지운다.
- 「학생찾기에서 검색하세요」처럼 엉뚱한 안내를 고친다.
- 커뮤니티에서 로그인한 사람에게 「게스트 안내」가 안 보이게, 글을 못 쓰는 사람에게 「첫 글을 남겨 보세요」가 안 보이게 한다.
- 「Pick·Prime」 영어를 「프라임·픽」으로, 공부방 성별 안내의 「과외쌤」 말을 고친다.
