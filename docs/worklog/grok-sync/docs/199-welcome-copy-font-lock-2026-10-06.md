## 카피 정본 (초안 = 티켓 Must)

### 로그인
- 제목: 「로그인」 유지 (SSOT A-5 골격).
- 보조: 「우리 동네 공부방과 과외쌤을 이어서 만나 보세요.」
- 가입 유도: 「처음이신가요? 회원가입」 / 「학생·공부방·과외쌤으로 시작할 수 있어요.」
- 돌아갈 화면 있을 때: 「로그인하면 방금 보던 화면으로 돌아가요.」
- 없을 때: 「저장해 둔 탐색과 최근 본 후보를 이어서 볼 수 있어요.」
- 칩(유지·톤만): 「우리동네 공부방 찾기」「과외쌤 비교하기」「쪽지로 이어서 상담하기」
- 로그인 직후: 전용 환영 페이지는 만들지 않음. 목적지 도착 후 **짧은 인페이지 안내 1회**(토스트·배너 또는 기존 오버레이 패턴) — 「다시 만나서 반가워요.」 (이름 있으면 「○○님, 다시 만나서 반가워요.」). 실패 문구는 감성 유지: 「로그인을 완료하지 못했어요. 잠시 후 다시 시도해 주세요.」

### 가입 흐름 (핵심만·해요체)
- 약관: 「약관 동의」 / 「서비스를 쓰려면 약관에 동의해 주세요.」
- 회원구분: 「어떤 회원으로 시작할까요?」 / 「하나만 골라 주세요. 계정을 만들고 이메일을 확인하면 기본정보로 이어져요.」
- 가입폼: 「회원가입」 / 「공통으로 필요한 정보만 받아요. 학교·과목·희망 조건은 여기서 받지 않아요.」
- 이메일 확인: 해요체로 부드럽게 다듬기(링크는 새 탭, 이 화면 유지, 스팸함 안내 유지).
- 확인 완료: 「이메일을 확인했어요」 / 「기본정보는 처음에 열어 둔 화면에서 이어서 적어 주세요.」

### 가입완료
- 학생 제목: 「가입이 끝났어요」 / 「적어 주신 내용은 학생 카드에 바로 반영돼요.」
- 공급자 제목: 「가입이 끝났어요」 / 「계정과 기본등록이 끝났어요. 아직은 검색에 안 보여요. 상세등록을 채우면 이웃에게 열려요.」
- 프로필 줄: `#id`·kind 코드 금지 → 역할 표시명만(「공부방」「과외쌤」).
- alert/confirm도 같은 톤. 「동네에 인사할까요?」 모달 톤은 현행 유지(이미 감성).

### 게스트 게이트
- 「에 오신 것을 환영합니다」 유지 가능. 보조는 해요체: 「로그인하면 후기·위치·비교·찜·문의를 더 볼 수 있어요.」
