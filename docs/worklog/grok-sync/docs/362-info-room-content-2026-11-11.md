## 범위 — 글 규격 (모든 글 필수)
각 파일 맨 위 머리말(YAML):
```
---
title: 
topic: startup | operation | marketing
category_suggest: know-how | recruit | admin-tax
basis_date: 2026-11-11        # 사실 확인 기준일
chars: 0                      # 본문 글자 수(공백 포함, 머리말 제외)
uncertain_facts: []           # 확인 필요 사실 목록
---
```
본문 구성(순서 고정):
1. `# 제목` — 원장님이 검색할 만한 구체적 제목
2. **요약 3줄** — 「이 글에서 알 수 있는 것」 3개 불릿
3. 소제목(`##`) **4개 이상**, 소제목마다 실질 내용 문단
4. **실제 사례 또는 예시** 1개 이상 — 가상의 예시는 「예시」라고 명시(실존 인물·업체 이름 지어내기 금지)
5. **체크리스트** — `- [ ]` 5개 이상
6. 마무리 인사 한 문단(정중한 존댓말)
- 길이: **본문 2,500~4,000자**(공백 포함). 2,500자 미만은 불합격.
- 말투: 공부방 원장님께 친절하고 정중한 존댓말(「~하시면 좋아요」「~해 보세요」). 과장·단정 광고 문구 금지.
- 한국 맥락 필수 반영(해당 주제에서): 교습소 신고 vs 개인과외교습자 신고 차이, 학원의 설립·운영 및 과외교습에 관한 법률(학원법)과 시·도 조례(교습시간·교습비 게시·옥외가격표시), 관할 교육지원청, 사업자등록·면세 여부·종합소득세·현금영수증 의무, 임대차·주거용 건물 사용, 아동학대 예방·성범죄 경력 조회, 지역 맘카페·당근(동네생활·비즈프로필)·네이버 플레이스·블로그·인스타그램·전단·아파트 게시판, 상담·재등록·수강료 관리 등.
- **법·요금·세율·과태료·신고 절차 같은 사실은 문장 끝에 `(기준일 2026-11, 확인 필요 시 관할 교육지원청)` 식으로 기준일 표기**, 확실하지 않으면 머리말 `uncertain_facts`에 올리고 본문에 「※ 지역·시점에 따라 다를 수 있어요」 표기.
- 출처: 2025~2026년 자료 우선(정부·교육청·국세청·법령정보센터 등 공식 자료 우선, 그다음 언론·업계). 오래된 자료만 있으면 연도 표시.

## 확인 (셀프검수 방법)
배치마다:
1. `node scripts/verify-info-room-content.mjs <폴더>` 출력 전체 첨부.
2. **복사 표본 검사**: 글마다 특징적인 문장 2개(배치당 최소 20문장)를 골라 웹 검색(따옴표 정확 일치)해서 같은 문장이 나오는지 확인 → 표(글 번호, 문장, 검색 결과 일치 여부). 일치하면 그 글 재작성.
3. 기준일·확인 필요 표기 누락 점검: 법·금액·세율·과태료가 나온 문장 목록과 표기 여부.
4. 주제 내 중복 표(제목·소제목 겹침).
