# 지역 「구 2단계」 정책 잠금 (종현, 2026-10-01)
1. 구가 있는 시는 모두 시→구 2단계(광역시 구·군 포함, 도의 일반구 시 포함). 세종 등 구 없는 곳은 1단계. 가입·기본정보·마이페이지 입력 동일.
2. 현재위치 표기: 게스트 과외쌤·학생 페이지 = 「서울 강남구」. 게스트 홈·공부방 관련 = 행정동 「대치동」. (회원은 본인 저장 지역 기준)
3. 서울시 = 서울특별시 (같은 지역, 별칭 통일로 처리).
4. 구 없이 광역시만 저장한 기존 회원: 구 입력 전까지 광역시 이름 표시. 별도 안내 발송 없음(기존 회원은 전부 테스트계정, 종현이 직접 제어). 새 가입자는 구 입력 필수.
5. 게스트 홈 지도 위 「대치동」 박스 집계(게스트 전용, 로그인 후 무관): 공부방=대치동 기준, 과외쌤=대치동이 속한 강남구 기준, 학생=강남구 기준.
6. 기존 저장 id·유료 노출 id 이전: 기존 회원이 전부 테스트계정이므로 보존 이전 불필요(필요 시 종현이 정리). 새 마스터 기준으로 새로 저장.
7. 구 목록·군 목록은 공식 자료(행정표준코드 등)에서만 가져오고 기억으로 채우지 않는다. 가짜/목업 지역(시 대표 가짜 행, 정적 id, MOCK_*)은 제거.
8. 공부방=행정동·단지, 과외쌤=시·군(+구), 학생=가입 분기(preferred_lesson_type) 기준 (기존 잠금 유지).
## 순서
마스터(공식 지역) → 입력 → 집계 → 검색·필터 → 표기·게스트 기준·178-11 가드 정리·목업 제거
