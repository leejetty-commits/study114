# 254-1 보완 지시서 — 0이 섞인 간격 15줄 표기 통일 (값 무변경)

- 작업 번호: 254-1 (254 보완)
- 날짜: 2026-10-19
- 브랜치: `cursor/254-student-remaining-bundle-20261018` (이미 push된 브랜치. 새로 만들지 마라)
- 기준 커밋: `bb965c0b` (254 검수 조건부 합격 커밋. 아래 줄 번호는 전부 이 커밋 기준이다)
- 이 지시서의 목적: 254에서 이미 토큰으로 바꾼 44줄과 표기를 맞추기 위해, 0이 섞여 남아 있던 15줄만 마저 토큰 표기로 통일한다. **값은 전과 완전히 동일해야 한다. 표기만 토큰으로 바꾸는 작업이다.**
- 모델 지정 없음: 이 지시서는 종현이 Cursor에 직접 전달한다.

> 쉬운 말 안내: `margin: 0 0 24px`처럼 숫자 0과 px가 섞인 줄에서, 0은 그대로 두고 px 부분만 이미 있는 공통 토큰(`var(--space-…)`)으로 바꿔 적는 것이다. 화면 간격은 1px도 달라지지 않는다.

## 1. 확정 배경 (다시 조사하지 말고 이 전제로 시작해라)

1. **254는 검수 조건부 합격이다.** 브랜치 `cursor/254-student-remaining-bundle-20261018`, 커밋 `bb965c0b`까지 push되어 있고, 조건은 이 지시서의 15줄 표기 통일 한 건이다. 종현이 2026-10-19에 "0 섞인 15줄 마저 통일"을 확정했다.
2. **이미 바꾼 44줄은 건드리지 마라.** `bb965c0b`에서 이미 토큰으로 바뀐 줄들을 "개선"한다는 이유로 다시 만지면 그 자체가 범위 위반이다.
3. **254의 다른 합격 부분은 전부 그대로 둔다.** 이번 작업은 아래 15줄 외에 아무것도 바꾸지 않는다.
4. 토큰 값 (기준: `tokens.css`, html 16px):
   - `--space-1` = 0.25rem = **4px**
   - `--space-2` = 0.5rem = **8px**
   - `--space-3` = 0.75rem = **12px**
   - `--space-4` = 1rem = **16px**
   - `--space-6` = 1.5rem = **24px**
   - (참고: `--space-5` = 20px이며 이번 15줄에는 쓰지 않는다. 20px이 새로 보이면 이 지시서 범위가 아니므로 고치지 말고 중단 보고해라.)

## 2. 작업 범위 — 이 15줄만

### 사전 확인 (필수, 작업 시작 전)

- `preview/home-ui/src/styles/tokens.css`에 **`--space-1` 토큰이 실재하는지 먼저 확인**해라 (값이 `0.25rem`인지까지 볼 것).
- **`--space-1`이 없거나 값이 0.25rem이 아니면:** 4px가 들어간 2줄(아래 표의 `student-detail.css:32`, `student-mypage-stage5b.css:135`)은 **건드리지 말고 멈춰서 중단 보고**해라 (6장). 임의로 토큰을 신설하거나 `tokens.css`를 고치지 마라. 나머지 줄도 임의로 진행하지 말고, 중단 보고에 "4px 2줄만 막혔는지, 전체를 멈춰야 하는지"를 적어 종현 확인을 받아라.
- `--space-2`, `--space-3`, `--space-4`, `--space-6`도 같은 파일에서 실재와 값을 함께 확인하고, 하나라도 다르면 그 줄을 건드리지 말고 중단 보고해라.

### 대상 15줄 (행 번호는 `bb965c0b` 기준)

줄 번호가 밀렸을 수 있으므로 **줄 번호만 믿지 말고, 파일 안에서 아래 "수정 전" 값(px) 문자열을 찾아 대조한 뒤** 바꿔라. "수정 전"과 글자까지 일치하는 줄이 없거나, 같은 문자열이 대상 줄 외에 더 나오면 임의로 고르지 말고 중단 보고해라.

### 변환 규칙 (전 줄 공통)

- **0은 그대로 `0`으로 둔다.** 0을 토큰으로 바꾸지 마라.
- 바꾸는 것은 **4px, 8px, 12px, 16px, 24px** 다섯 값뿐이며, 위 토큰 값 표대로만 바꾼다.
- `!important`, 세미콜론, 들여쓰기, 선언 순서 등 토큰 외의 글자는 수정 전과 똑같이 유지해라.
- 한 줄에 위 다섯 값 외의 px(예: 20px, 28px)가 섞여 있으면 그 줄은 대상이 아니다. 건드리지 말고 중단 보고해라.

## 4. 작업 순서

1. 저장소를 최신으로 맞추고(`git fetch`), 브랜치 `cursor/254-student-remaining-bundle-20261018`을 checkout/pull 한다. **rebase는 하지 마라.** 작업 시작 전 `git status`가 깨끗한지, HEAD가 `bb965c0b`(또는 그 위에 종현이 승인한 후속 커밋만 있는 상태)인지 확인하고, 아니면 보고하고 멈춰라.
2. 2장 사전 확인을 한다 (`tokens.css`의 `--space-1` 등 토큰 실재·값 확인). 막히면 그 자리에서 중단 보고하고 멈춘다.
3. 대상 15줄을 파일 안에서 **값(px) 문자열로 찾아 대조**한 뒤, 표대로 바꾼다. 파일당 한 번에 몰아서 바꾸지 말고, 바꾼 뒤 줄별로 표와 대조해라.
4. 5장 전수 대조(토큰→px 복원 시 수정 전과 전 줄 일치)를 통과시킨다. 통과 못 하면 커밋하지 말고 보고해라.
5. 새 커밋 1개만 추가한다. 커밋 메시지는 아래를 써라:
   - `254-1 style(student): 0 섞인 간격 15줄 표기를 공통 토큰으로 통일`
   - 파일 2개만 지정해서 add한다 (`git add -A` 금지). 예: `git add preview/home-ui/src/styles/student-detail.css preview/home-ui/src/styles/student-mypage-stage5b.css`
6. 브랜치를 push하고 **멈춘다.** main에 합치지 마라.
7. 이후 순서는 **검수 → 종현 승인 → main 병합**이다. 종현 승인 없이 main에 merge하지 마라.

## 5. 확인 방법 (전수 대조 필수)

1. **토큰→px 복원 전수 대조 (필수, 이 작업의 합격 조건):**
   - 수정한 2개 파일을 복사본에서 토큰을 px로 되돌린다 (`var(--space-1)`→`4px`, `var(--space-2)`→`8px`, `var(--space-3)`→`12px`, `var(--space-4)`→`16px`, `var(--space-6)`→`24px`).
   - 되돌린 결과가 `bb965c0b`의 수정 전 원본 파일과 **전 줄 글자까지 같은지** diff로 전수 대조해라. 단 한 줄이라도 다르면 값 변경이 섞인 것이므로 커밋하지 말고 어느 줄이 다른지 보고해라.
   - 이 대조는 수정한 15줄만이 아니라 **파일 전체**를 대상으로 한다 (의도치 않은 줄 변경·공백·줄바꿈 변경까지 잡기 위함이다).
2. `git diff bb965c0b --stat`와 실제 diff에서 바뀐 줄이 정확히 15줄(파일별 4줄/11줄)인지, 허용 파일 2개만인지 확인해라. 15줄이 아니거나 다른 파일이 있으면 보고하고 멈춰라.
3. 이미 바꾼 44줄이 diff에 다시 등장하지 않는지 확인해라.
4. 화면 확인은 값 무변경이 전제이므로 거창하게 하지 마라. 단, CSS 문법 오류가 없는지(중괄호·세미콜론 깨짐) diff 눈검사와, 가능하면 학생 상세·마이페이지 화면이 수정 전과 같게 뜨는지만 가볍게 확인해라. 화면이 달라 보이면 값 변경을 의심하고 1번 대조부터 다시 해라.
