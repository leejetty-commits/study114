## 2. 목표 UX (잠금)

### 2-A. 홈 · 우리동네 학생 탭

| 항목 | 요구 |
|------|------|
| 상세검색 | **완전 제거** (검색/초기화/희망지역 편집 없음) |
| 지역 | **홍보1 고정** 읽기전용. 개설·hub·대치 MOCK 금지 |
| 목록 | 탭 진입 시 자동 로드 · 홍보1 동네 학생 |
| 희망유형 | UI 없음. API 기본 = **공부방**(공부방 로그인) / 과외쌤 로그인이면 과외쌤 |

## 8. 추가 오류 잠금 (2026-09-24 · 학생찾기 스크린샷)

공부방 로그인 · 홍보1=**가능동** 계정 기준 (개설과 달라도 가능동).

| # | 증상 (스크린샷) | 요구 |
|---|-----------------|------|
| 1 / 1.1 | 상단 `현재위치 서울` | **`현재위치 가능동`**(홍보1 동 라벨). 시 단위「서울」만 나오면 실패. 희망지역 기본도 홍보1 |
| 2 | (빈칸) 프라임·픽이 뜨는 자리 | 결과/섹션이 생기면 **현재위치·지역 라벨도 홍보1(가능동)**. 대치·서울시·개설주소 금지 |
| 3 | (빈칸) 베이직이 뜨는 자리 | 동일. 베이직 헤더·카드·`현재위치` = 홍보1 |

관련(같은 화면, 050 범위에 포함): 희망유형이 「과외쌤」으로 열려 있으면 공부방 로그인 기본 **공부방**으로 (유형 UI는 찾기에서 변경 가능하나 **진입 기본**은 역할 정합).

빈 결과 카피(「이 지역에 학습 요청이 없습니다」)는 지역 문자열이 홍보1을 가리키는지 스모크에 포함.
