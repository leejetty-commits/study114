# 172 · 동네 인사 (가입 선택 노출 · 카드 연결)

---

## 1. 한 줄 목표

같은 동네 학생(학부모)이 **방금 들어온 공부방·과외쌤의 짧은 인사**를 한 번 더 보고, 닉네임·인사를 누르면 **그 사람의 베이직카드**로 바로 이어지게 한다. 올린 쪽은 부담 없는 동네 노출(마케팅)이 된다.

---

## 2. 잠금 규칙

### 2.1 자발성 (최우선)
- 가입·기본등록 **어느 단계에서도 필수 아님**.
- 스킵·나중에·안 함 — 모두 동일. 재촉 배너·미완료 뱃지·검색 순위 감점 **금지**.
- 문구 예: 「동네에 한 줄 인사를 남길 수 있어요. **안 하셔도 됩니다.**」

### 2.2 누가 올릴 수 있나 (1차)
- **공부방 · 과외쌤** 우선 (공급자 마케팅 축).
- 학생/학부모 인사는 1차 **넣지 않음**(결이 다름). 필요하면 후속 티켓.

### 2.3 언제
- 기본등록(또는 가입 완료) 직후 **한 번** 「올리기 / 건너뛰기」.
- 마이페이지에서도 **언제든** 올리기·수정·내리기.
- 계정당(또는 등록 카드당) **활성 인사 1개**.

### 2.4 내용
- **한 줄**(권장 40자 내, 하드 상한 예: 80자).
- 선택 칩: 주력과목·대상 학교급(이미 등록된 값 재사용 가능).
- **금지:** 전화번호·카톡·외부 URL·다른 업체 유도·긴 홍보문·이미지 첨부(1차는 텍스트만).
- 검열: 금칙어·연락처 패턴 기본 필터 + 신고.

### 2.5 어디에 보이나
- 같은 **희망·홍보 지역(시/동 정책은 기존 슬롯과 정합)** 안의
  - 학생 홈·찾기 주변 **「이번 주 동네 인사」** 짧은 레일/목록.
- 오래된 인사는 접기·「더보기」. 상단 고정 광고처럼 밀어젖히지 않음.
- 게스트 노출 여부: **1차는 로그인 학생(학부모)만** (게스트는 후속 결정).

### 2.6 클릭 → 카드 (핵심 UX)
- 표시명·인사문·썸네일 클릭 → **베이직카드 팝업**.
- 팝업에서 「자세히」→ 기존 상세/찾기 상세.
- 카드가 없거나 비공개·탈퇴·삭제면 클릭 시 「카드를 볼 수 없어요」만. 빈 상세로 보내지 않음.
- 인사 목록에 **항상 등록(카드) ID 연결**. 카드 없는 인사 저장 불가.

### 2.7 내리기·수정
- 본인이 즉시 비공개/삭제.
- 관리자 숨김(신고·정책 위반).
- 내려도 가입·카드·노출상품과 **무관**.

### 2.8 카피 톤
- 공개 자랑·카페 「가입인사 필수」톤 금지.
- 「우리 동네에 왔어요」수준의 짧은 인사.
- 사이트 용어: **등록** · **베이직카드** (「의뢰」금지).

## 3. 가입 흐름에 넣는 위치 (강제 없이)

1. 가입·기본등록 저장 성공  
2. 완료 화면 또는 직후 모달:  
   - 제목: 「동네에 인사할까요?」  
   - 본문: 「같은 동네 학생에게 한 줄만 보여요. **건너뛰어도 바로 쓸 수 있어요.**」  
   - 입력(선택) + **「인사 올리기」** / **「건너뛰기」** (동등 강조, 건너뛰기를 작게 만들지 말 것)  
3. 홈 착지.

마이페이지: 「내 등록」옆 또는 설정에 「동네 인사」편집.

## 7. 함께 잠그는 환영 UX (강제 없음 · 2026-09-27 사용자 수락)

아래도 **전부 선택·끌 수 있음**. 안 받아도 이용 동일.

### 7.1 역할별 첫 쪽지 (봇/운영 명의)
- 가입 직후 1통. 공부방·과외쌤·학생 문장만 다르게.
- 공개 글 아님 · 수신함에서만.
- 끄기: 계정설정 「안내 쪽지 받기」.

### 7.2 홈 「오늘 할 일」환영 한 줄
- 가입 후 **첫 방문 1회**만. 멘트 + 다음 버튼 하나.
- 닫으면 다시 안 뜸(또는 마이페이지에서만 다시 보기).

### 7.3 동네·역할 맞춤 한 줄
- 「○○시 과외쌤으로 들어오셨네요」수준. 긴 템플릿 금지.

### 7.4 첫 7일 안내 쪽지 (최대 3통)
- 환영 → (2일) 베이직카드 채우기 → (5일) 찾기 열어보기.
- **다음 한 걸음만**. 광고 톤 금지. 일괄 수신 거부 필수.

### 7.5 우선 조합
- **동네 인사(본문 §2)** + **7.1 쪽지** + **7.2 홈 한 줄**을 1차 묶음.
- 7.4는 2차(쪽지 인프라 이후).

## 8. 홈 배치 · 게스트 블라인드 (2026-09-27 잠금)

### 8.1 위치
- 게스트·학생 홈: **히어로(또는 상단 요약) 아래 · 찾기 CTA 위**.
- 섹션명 예: 「우리 동네에 새로 왔어요」.
- **얇은 레일** — 한 줄 흐르기 또는 항목 2~3개. 큰 배너·지도·프라임 목록을 밀지 않음.
- 노출할 인사 **0건이면 섹션 통째 숨김**(빈 칸·「없음」문구 금지).

### 8.2 게스트 (블라인드 · 시선만)
- 표시명: 성+○○ 등 부분 가림 + 역할(공부방/과외쌤).
- 인사: **앞 약 20자 + …** (한 줄 티저).
- 과목 칩 정도만. 연락·상세·지도핀 연결 없음.
- 클릭 → 로그인(또는 가입) 게이트: 「로그인하면 카드를 볼 수 있어요」. **카드·연락 미리보기 금지**.

### 8.3 로그인 학생 · 같은 동네
- 인사 한 줄 전체(또는 정책 상한 내).
- 클릭 → **베이직카드 팝업**(§2.6).

### 8.4 여전히 강제 없음
- 공급자가 인사 안 올려도 홈·검색·등록 불이익 없음.
- 게스트 레일은 **티저 전용**, 가입 강요 카피 금지(게이트 한 줄만).
