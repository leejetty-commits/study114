## 0. 한 줄

메일 확인 링크가 새 탭을 여는 동선은 유지하되, **대기 화면(및 가능하면 확인 메일 본문)**에 「새 창에서 이어간다 · 이 탭은 닫아도 된다」를 **명시**한다. 유저가 두 창을 보고 헤매지 않게 한다.

---

## 1. 잠금 카피(의도 · 문장 다듬기 OK)

### 1.1 `verify-email?send=1` 대기 화면 (필수)
지금 「확인 메일을 보냈습니다…」 아래에 **눈에 띄는 안내 블록** 추가:

- 제목급: **메일 안의 링크를 누르면 새 창(또는 새 탭)이 열립니다.**
- 본문: **가입은 그 새 창에서 이어서 진행하세요.** 이 화면(탭)은 닫아도 됩니다.
- 보조(선택): 스팸함 안내와 한 블록에 묶어도 됨. 「메일 다시 보내기」 동작·쿨다운은 유지.

### 1.2 확인 메일 본문 (가능하면)
링크 위/아래에 한 줄: **이 링크를 누르면 브라우저에 새 창이 열릴 수 있습니다. 열린 창에서 가입을 계속하세요.**

### 1.3 확인 직후 랜딩(Basic 진입 전/후)
이미 Basic으로 떨어지면 필수 아님. 「이메일 확인 완료」 중간 화면이 있으면: **이메일 확인이 끝났습니다. 이 창에서 기본정보를 이어서 입력하세요.**

### 1.4 하지 말 것
- 원래 탭 자동 focus/닫기/동기화 구현(후순위)
- 035 같은 탭 이어하기 회귀 깨기
- 홈 069 · 희망지역 071과 한 커밋
- push / build:dothome

---

## 2. 스모크

1. 가입 → 메일 발송 화면: 새 창 이어가기 안내가 **본문에서 바로 보임**
2. (가능하면) 실메일 본문에 동일 취지 한 줄
3. 메일 링크 → 새 탭에서 Basic 진입 회귀 OK
4. 보고: 파일 · 최종 카피 전문 · push 안 함
