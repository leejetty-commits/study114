## 6. 우측 배너 레일 — 편의 방향 (**논의 중** · 2026-09-25)

### 6-1. 지금 구조 (요약)

지금 「우측 배너」는 **이미지 시즌 광고판**이 아니라,  
페이지 오른쪽에 **글 묶음 칸(슬롯)** 을 두고 게시판 글을 끌어오는 쪽에 가깝다.

- 위·아래 순서는 안에 **우선순위 숫자**로 정해짐 (목록은 그 숫자 오름차순).
- 칸마다 제목·바로가기 링크·어느 게시판에서 글을 가져올지 등이 있음.
- **방학/가을/겨울 같은 시즌 분류·일련번호 아카이브**는 **아직 없음**.
- 링크는 칸의 「바로가기」로 하나씩 둘 수 있으나, **예전에 쓴 홍보 링크 이력철**은 없음.

### 6-2. 기획자 질문에 대한 답

| 질문 | 지금 | 목표 (편의) |
|------|------|-------------|
| 위·아래 순서를 내가 정확히 정할 수 있나? | 숫자(우선순위)로는 가능. 초보에게는 불편할 수 있음 | **위로 / 아래로** 또는 끌어 옮겨 **보이는 순서 = 실제 순서** |
| 홍보배너 링크가 기록·일련번호·방학·가을 등으로 분류되나? | **안 됨** | 원하면 **시즌/캠페인 꼬리표 + 지난 링크 목록**을 **새로** 넣는 방향 (아래 잠금) |

### 6-3. 편의 잠금 초안 (사용자가 「쉽게 가공」 요청)

초보 운영자가 배너 레일을 쓰려면:

1. **순서:** 「1번이 맨 위」가 화면에 그대로 보이게. 숫자 몰라도 **위/아래 버튼**으로 조정.  
2. **한 칸 = 한 카드:** 제목 · 켜기/끄기 · 바로가기 주소 · (선택) 짧은 메모.  
3. **홍보용일 때:**  
   - **시즌/분류** 고르기 (예: 상시 · 방학 · 봄 · 가을 · 겨울 · 직접 입력)  
   - **캠페인 이름** (예: 2026 겨울방학)  
   - 링크를 바꾸면 **이전 링크가 기록에 남음** (날짜 · 주소 · 캠페인명). 일련번호는 자동.  
4. **미리보기:** 저장 전·후에 「손님 화면 오른쪽에 이렇게 보여요」 한 줄/썸네일.  
5. **말투:** priority/slot 같은 말 금지. 「위 칸 · 아래 칸 · 켜짐 · 꺼짐」.

### 6-4. 방향 잠금 초안 (**2026-09-25** · 사용자 의견 + 우동공과2 권고)

**결론: C안 — 두 모드 모두 필요.**  
홍보(카탈로그·영상)는 **페이지**, 그 외 우측 칸은 **게시판 글 모음**. 레일에서는 둘을 **다른 종류의 칸**으로 다룬다.

| 모드 | 어디에 두나 | 레일에서의 역할 |
|------|-------------|-----------------|
| **A. 게시판형** | 공지·FAQ·이용안내 등 **글** | 오른쪽에 최신/골라 둔 **글 목록** + 더보기 |
| **B. 홍보·카탈로그형** | **홍보 페이지**(시즌·테마 단위, 재활용) | 레일에는 **짧은 카드**(제목·썸네일·「자세히」)만. 누르면 **그 페이지**로 |

**왜 페이지가 맞나 (의견)**  
카탈로그는 이미지·문단·여러 상품·유튜브가 겹침. 레일 칸 하나에 다 넣으면 좁고 수정이 어렵다.  
**페이지 = 본편**, **레일 = 예고편(입장권)** 이 초보 운영에도 맞다.

**유튜브**  
- 홍보 **페이지 본문**에 영상 넣기(또는 유튜브 주소 붙이기)가 본진.  
- 레일 카드에는 **썸네일 + 「영상 보기」** 정도만 (레일에 큰 플레이어 강제 X).  
- 같은 영상을 **여러 시즌 페이지에서 재사용** 가능하게 (주소·제목만 공유).

**재활용**  
- 홍보 페이지는 **끄지 않고 보관**(보관함). 시즌이 지나도 삭제하지 않음.  
- 새 방학에 **복제해서 고치기** / 예전에 쓴 페이지를 **다시 켜서** 레일에 걸기.  
- 시즌·캠페인 꼬리표 + 자동 일련번호(이력). 링크·영상 주소 변경 이력은 관리자만.

**레일 편의 (앞 절과 동일)**  
위/아래 순서 · 켜기/끄기 · 미리보기 · 「게시판 칸 / 홍보 칸」 종류만 고르면 됨.

### 6-5. 아직 다듬을 말 (구현 전 문장만)

- 시즌 기본 목록: **상시 · 방학 · 봄 · 여름 · 가을 · 겨울** (+ 직접 입력) — **확정** (2026-09-25)  
- 손님 메뉴에 「홍보」 노출 여부: 기본은 **레일·팝업·직접 링크**로만 들어가고, GNB에 「홍보」를 따로 둘지는 **나중에**  
- 홈 팝업과 홍보 페이지는 **다른 것** (팝업=뜨는 창, 페이지=읽을 거리)

### 6-6. 범위

- 2순위 논의에 **포함**. 코딩·배포 보류.  
- 레일 ≠ 팝업 ≠ 유료상품 카드. 홍보 페이지는 **새 콘텐츠 종류**로 문서에만 선잠금.

### 6-7. 수락 메모 (2026-09-25)

- 두 모드(게시판형 + 홍보 페이지형) **수락**
- 유튜브는 페이지 본진 · 레일은 짧은 카드 **수락**
- 카탈로그 페이지 **보관·복제·재사용** **수락**
- 시즌: 상시·방학·봄·여름·가을·겨울 + 직접입력 **수락**

## 가입 받기 vs 사이트 점검 (잠금 · 2026-09-25)

사용자 동의: **「가입 받기」 단독 스위치는 두지 않는다.**

- **사이트 점검(전체 일시 중지)** 만 둔다 → 손님·기존 회원·신규 가입 모두 잠시 멈춤.
- 점검 중에는 가입도 자연히 불가하므로 가입만 OFF하는 별도 토글 **불필요**.
- **약관·개인정보 글 수정**은 점검/가입 토글과 **별개로 유지**.
- 나중에 「기존 회원은 쓰는데 가입만 막기」가 필요하면 그때 재논의.

관리자 2순위(157)·환경설정 손볼 때: 가입 받기 UI는 **제거·흡수**, 점검 스위치·카피로 통일.


## 법적 문서 vs 일반 안내 글 (잠금 · 2026-09-25)

사용자 동의.

| 글 | 관리 위치 |
|----|----------|
| **이용약관 · 개인정보처리방침** (+필요 시 운영정책) | **관리자 환경설정** 전용. 일반 게시판 권한으로 올리지 않음 |
| **공지 · FAQ · 이용안내** | **관리자 공지·안내 글**(게시판형 OK) |
| 가입 화면 체크 문구 | 위 약관·개인정보와 **같은 글**을 가리킴 |

고객센터·가입에는 **보이게** 하고, **고치는 손**은 위 표대로. 약관을 일반 게시판에 두고 권한만 주는 방식 **비채택**.
