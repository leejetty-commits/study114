**참고 사이트에서 읽은 점**
- 학원(상가 기반) 창업과 업체 광고 중심 구조이며, 「공부방(주거지) 창업」 전용 구조는 아님. 우리 게시판은 **창업자의 진행 순서(순서도)** 중심으로 가는 편이 차별점이 됨.
- 눈에 띄는 분류 축: ①프랜차이즈를 과목별로 나눔 ②업체를 분야별(인테리어·용품·마케팅 등)로 나눔 ③건물·매매를 따로 둠 ④교육·모임 메뉴가 별도 있음.
- 사이트 성격상 업체 광고가 섞여 있으므로, 우리 게시판에서는 정보 글과 업체 소개를 섞지 않는 것을 권장.
