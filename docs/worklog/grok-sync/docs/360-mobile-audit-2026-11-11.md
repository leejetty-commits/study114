## 대상
로컬 5174(`preview/home-ui`) + 로컬 API, 모드별 테스트 계정. 참고 문서: `docs/worklog/grok-sync/docs/326-mobile-responsive-proposal.md`, `docs/worklog/2026/11/2026-11-10-342-mobile-home-compact.md`.
폭: **390×844, 360×740** (Playwright 또는 DevTools 기기 모드, DPR 2).

## 범위
모드별 주요 화면을 위→아래 전체 캡처하고 문제를 표로.
- 비회원: 홈, 찾기(지도·목록), 공부방 상세, 과외쌤 상세, 정보게시판 목록·글, 로그인, 가입(3모드), 고객센터
- 학생: 홈, 찾기, 상세→쪽지 보내기, 쪽지함, 마이페이지(기본정보·찜·리뷰), 학생 카드 등록
- 과외쌤: 홈, 내 카드, 카드 등록·수정 폼, 상품홈·체크아웃, 구매이력, 쪽지함, ☰ 메뉴(영상)
- 공부방: 홈, 내 공부방 카드, 등록·수정 폼, 상품홈·체크아웃, 구매이력·환불 패널, 리뷰 관리
- 공통: 헤더·☰ 메뉴, 모달(상세·비교·리뷰·로그인), 토스트, 플로팅 버튼, 하단 여백

점검 기준(행마다 해당 항목 표기):
1. 가로 스크롤(`scrollWidth > innerWidth`) 2. 글자 잘림·겹침·줄바꿈 이상 3. 터치 영역 < 44px 4. 고정 요소가 내용 가림 5. 모달이 화면 밖으로 넘침/닫기 버튼 안 보임 6. 입력 시 키보드가 입력칸 가림 7. 이미지 비율 깨짐 8. 기본 카드 가로형 유지 여부 9. 글자 크기 < 12px 10. 로딩 지연(체감, LCP 대략)
