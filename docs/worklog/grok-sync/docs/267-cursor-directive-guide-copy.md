- 바꾼 것 외의 동작(저장·토글·쪽지 답장·찾기 필터·인증 이어가기 버튼·상세 저장)이 수정 전과 같은지도 함께 적어라.
- 자동 검사(verify 스크립트 등)를 돌렸으면 이름과 결과를, 못 돌렸으면 이유를 적어라.

## 11. 완료 보고 양식

완료 보고에는 아래를 빠짐없이 적어라.
