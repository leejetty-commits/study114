## 1. 증거 (박스에서 2026-09-24 16:01~)

- DNS: Cloudflare(2606:4700… / CF 엣지).
- `GET /` 한 번 **522** body `error code: 522` (~19s).
- 이후 재시도는 **200**이 섞임(0.25s ↔ ~20s) → **간헐적 오리진/SSL 불안정**.
- `/search/` · `/auth/` 도 지금은 200 가능 — “완전 다운”이 아니라 **들쭉날쭉**.

검색 화면 “깨짐”과 겹치면: (A) 525/522로 자산·API 일부만 실패하거나 (B) 069 이후 UI 버그가 **별개**. 지금은 **접속 불가는 A가 1순위**.

## 2. 당장 할 일 (운영자)

1. **Cloudflare** → SSL/TLS → Overview  
   - 모드 확인: 닷홈 오리진이 `*.dothome.co.kr` 인증서만이면 **Full (strict)는 525 위험**.  
   - 임시: **Full**(strict 아님) 또는 오리진에 **study114.net 유효 인증서** 설치 후 Full strict.  
   - (001에 동일 경고 있음.)
2. **닷홈** 제어판: 계정/웹호스팅 **정상·과금·트래픽·디스크**, 서버 점검 공지, SSL/도메인 연결.
3. Cloudflare **Overview / Analytics / 525·522** 비율 확인. Origin IP가 닷홈 안내 IP와 일치하는지.
4. 잠시 Flexible는 최후(혼합콘텐츠·보안 약화) — 가능하면 Full + 올바른 오리진 인증서.

앱 `git revert` / 재배포로는 **525가 고쳐지지 않음**.
