## 0. 한 줄 목표

관리자 문을 열면 **오늘 뭐 하면 되는지** 네 장만 보이게 한다.

---

## 1. 「오늘 할 일」홈

**카드 4장 (문구)**

1. **회원 정리** — 테스트·탈퇴·삭제 → 회원  
2. **홈에 뭐가 보이나** — 카드 숨김·다시 보이기 → 홈·찾기 노출  
3. **문의·신고** — 답장할 글 → 신고·문의  
4. **홈 팝업** — 지금 뜨는 팝업 → 홈 팝업  

하단: 「아래쪽 **미리보기**는 연습용이에요. 실운영은 위 네 가지만.」

숫자 대시보드보다 **바로가기** 우선.

## 2. 작업 기록 (운영 로그)

- 이미 있는 기록 화면 활용  
- **탈퇴 처리 · 회원 삭제 · 노출 변경**이 기록에 남는지만 맞춤  
- 초보용 설명: 「누가 위험한 버튼을 눌렀는지 보는 곳」

## 3. 신설 후보 — 학생 등록 목록

- **이름 잠금 (2026-09-25):** 「학생 의뢰」 표현 **폐기**. 공부방·과외쌤·학생 **모두 「등록」**.  
- **기본 표현:** 세 종류 등록의 기본(무료) 카드는 모두 **베이직카드**. (프라임·픽 등은 유료 노출 쪽)  
- **지금:** 노출·제출에 흩어짐  
- **목록 UX 잠금 (2026-09-25, 후보):** 학생이 많아질 수 있으므로  
  - **기본 화면:** 최근 **1주일**만 보여 준다.  
  - **그다음:** **지역별 · 기간별**로 골라(또는 정렬해) 더 볼 수 있게 한다.  
  - 전체 무한 스크롤을 기본값으로 두지 않는다.  
- **날짜 기준 잠금 (2026-09-25):** **등록일**만 쓴다. (베이직카드·기본정보를 올린 날)  
  - **계정 가입일은 이 목록에서 의미 없음** — 쓰지 않는다.  
  - 가입만 하고 등록 없는 계정은 **회원 정리**에서 다룬다. 학생 등록 목록에는 넣지 않는다.  
- 1~2순위가 익숙해진 **뒤**에 논의. 이 티켓에서는 **후보**만 표시.

## 등록 목록 확대 잠금 (2026-09-25)

「학생 등록 목록」후보만 두지 않는다. **공부방 · 과외쌤 · 학생** 모두 같은 뼈대의 **등록 목록**으로 둔다.

공통:
- 이름: **○○ 등록 목록** (「의뢰」금지)
- 기본 보기: **최근 1주**
- 날짜: **등록일**(베이직카드/기본정보)만 · **계정 가입일 제외**
- 필터·정렬: **지역 · 기간**
- 카드 유형: **베이직카드**
- 가입만 한 계정(기본정보 없음) → 이 목록이 아니라 **회원 정리**

후순위 점검 우선 안에서는 「학생만」이 아니라 **역할별 등록 목록(방·과외·학생)** 으로 본다.
