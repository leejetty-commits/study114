## 3. 수정 방식 (확정)

### 3-1. 찾기 첫 진입에서 홈 피드를 부트한다 (`search-page.js`)

- `afterSearchPageMount`에, **과외쌤 로그인 + 과외쌤 탭일 때만** 홈과 같은 순서로 `bootTutorHome(rerender)` → `bootTutorHomeTutors(rerender)`를 부른다. 홈 화면의 부트 순서·방식을 그대로 따른다(`preview/home-ui/src/screens/tutor.js:161-167` 선례).
- 지역 준비가 끝나기 전에는 `bootTutorHomeTutors`가 아무것도 요청하지 않는 것이 기존 동작이다(`tutor-home-seed.js:254-255`). `bootTutorHome`의 rerender가 화면을 다시 그리면 부트가 다시 불려 조회가 시작되는 흐름에 맡겨라. **타이머·지연 호출·임의 재시도 루프를 새로 만들지 마라.**
- 검색 복원(`_needsSearchRestore`) 경로나 검색 실행 후 동작보다 우선하게 만들지 마라. 검색을 실행한 뒤에는 이 초기 피드가 결과를 덮지 않아야 한다(3-2의 `!searchExecuted` 조건과 함께 지킨다).

### 3-2. 검색 전 피드 연결을 찾기까지 연다 (`search-find-surface.js`, `search-region-feed.js`)

- `regionFeedContext`의 과외쌤 분기를, **과외쌤 로그인 + 과외쌤 탭 + 검색 실행 전에 찾기 화면(`surfaceType: 'search'`)인 경우**까지 연다. 단, 게스트·학생(학부모)·공부방 분기와 홈(`homeSelf`) 분기의 기존 조건은 한 글자도 바꾸지 마라.
- `search-region-feed.js`에서는 홈 분기와 찾기 분기가 **같은 매핑·같은 `pending` 규약**을 쓰게 한다. 찾기 전용이라는 이유로 별도 매핑·별도 정렬·별도 상한을 만들지 마라. 홈 조회가 이미 `limit: 20, sort: 'latest'`로 받아 둔 목록을 그대로 쓴다.
  - 구현 형태는 작업자 재량이되, 의미는 하나여야 한다: "과외쌤 검색 전 목록 = 대표 과외지역 id로 조회한 베이직카드 전부(본인 포함)". 홈 전용 플래그를 찾기에서 그대로 켜는 방식이든, 찾기 전용 플래그를 추가해 같은 분기로 합치는 방식이든, **결과·상태·매핑이 홈과 같아야** 하고 허용 파일을 벗어나면 안 된다.
- **조회는 표시 라벨이 아니라 실제 지역 id로 한다.** id 산출·조회는 3-1의 부트(`bootTutorHomeTutors` 내부 `tutor_region_id`)가 담당한다. 찾기 코드에서 현재위치 라벨 문자열(예: "의정부시")을 지역 id로 역변환하거나 라벨로 서버에 묻는 코드를 새로 만들지 마라.
- 결과 표시는 기존 검색 전 규약 그대로 **베이직카드 flat**(`renderSearchTierResults`에 `mode: 'region'`, `surfaceType: 'search'`)로 한다. 홈 티어 문법(프라임/픽)으로 바꾸지 마라.

### 3-3. 상태별 표시 (불러오는 중에 「없음」 금지)

찾기 과외쌤 검색 전 구역에서, 상태 읽기(`getTutorHomeTutorFeedStatus()`)를 기준으로 아래처럼 가른다. 홈 구역의 기존 가드(`search-find-surface.js:2799-2821`)와 같은 구조를 찾기 구역에도 적용하는 것이 요지다.

| 상태 | 표시 | 근거/문구 |
|---|---|---|
| 아직 조회 전·불러오는 중 (`idle`/`loading`, 또는 목록이 아직 `null`) | 「불러오는 중」만 표시. **「선택한 지역에 과외쌤이 없습니다」를 절대 표시하지 마라.** | 기존 상수 `GUEST_FEED_LOADING`('목록을 불러오는 중입니다.', `search-find-surface.js:140`) 재사용 |
| 조회 실패 (`error`) | 실패 문구만 표시. 「없음」으로 표시하지 마라. | 기존 상수 `GUEST_FEED_ERROR`(`search-find-surface.js:141`) 재사용 |
| 대표 과외지역 없음·미등록 (`no-region`) | 「선택한 지역에 과외쌤이 없습니다」를 표시하지 마라. 지역을 등록하면 목록이 보인다는 취지의 한 줄 안내로 표시한다. | 문법 선례: 과외쌤 홈 학생 탭의 `noRegion` 안내(`preview/home-ui/src/student-reg/student-reg-copy.js:71`). 대상만 과외쌤으로 바꾼 한 줄 외에 새 문구를 창작하지 마라. |
| 조회 끝, 0명 (`ready`이고 목록 0건) | **이때만** 기존 제로 문구 「선택한 지역에 과외쌤이 없습니다」를 표시한다. | 기존 제로 문구 그대로 (`preview/home-ui/src/empty-state-copy.js:210`). 문구를 새로 쓰거나 바꾸지 마라. |
| 조회 끝, 1명 이상 | 베이직카드 flat 목록 (본인 포함) | 3-2 |

### 3-4. 지역 라벨 일치

- 목록 제목·현재위치에 쓰는 지역 라벨은 부트가 채운 **대표 과외지역 라벨**을 쓴다. 찾기에서 라벨을 따로 계산해 목록 지역과 어긋나게 만들지 마라. 라벨이 비어 있는 동안(지역 준비 전)은 3-3의 불러오는 중 표시가 우선한다.
