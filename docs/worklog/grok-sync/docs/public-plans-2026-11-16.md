# 비로그인 유료상품 가격 공개 지시서 (2026-11-16)

기준: origin/main 최신. 새 .wt 워크트리, 새 브랜치 `work/public-plans-2026-11-16`.
선행: 홈 속도 분할 PR(home-speed-split)이 머지된 뒤 시작한다. 충돌을 피하려는 것이다.
목적: KG이니시스 사이트 사전검사 「상품 등록 유무」 대응. 비로그인도 상품 이름·가격·설명을 볼 수 있게 한다.

## 현재 (11-15 확인)
- `#/plans`, `#/plans/positions`, `#/plans/access`는 비로그인에게 로그인 안내만 보인다.
- 홈 빈 프라임·픽 칸과 `#/promo/study-room`, `#/promo/tutor`에는 이름·설명만 있고 가격이 없다.

## 범위
1. 비로그인으로 `#/plans/positions`(프라임·픽), `#/plans/access`(쪽지권)를 열면 상품 이름·가격·기간·설명을 보여 준다. 가격은 지금 로그인 화면과 같은 출처(카탈로그 API·관리자 설정)를 쓴다. 하드코딩 금지.
2. 구매·결제 버튼은 비로그인일 때 「로그인하고 구매하기」로 바꾼다. 누르면 로그인 화면으로 가고, 로그인 뒤 같은 상품 화면으로 돌아온다(기존 pending-route 사용).
3. 역할 제한을 표시한다. 프라임·픽은 공부방·과외쌤 전용, 쪽지권은 해당 역할 전용임을 한 줄로 안내한다. 학생 계정으로 로그인하면 기존 규칙대로 막는다.
4. 환불 규정 링크(FAQ 결제·상품 또는 이용약관 환불 조항)를 상품 목록 아래에 붙인다.
5. 카탈로그를 읽는 API가 로그인을 요구하면, 공개용 읽기 전용 응답(이름·가격·기간·설명만, 회원 정보 없음)을 추가한다. 쓰기·결제 API는 그대로 로그인 필수.

## 하지 않을 것
- 결제·환불·쿠폰·프라임 판정 로직 변경. 가격 변경.
- 운영 SQL. 머지·force push·reset --hard.

## 수락 기준
1. 비로그인 시크릿 창에서 `#/plans/positions`, `#/plans/access`에 이름·가격·설명이 보인다(PC·모바일 390 스크린샷).
2. 비로그인 구매 버튼 → 로그인 → 같은 상품 화면 복귀.
3. 공부방·과외쌤·학생 로그인 시 기존 구매 화면과 제한이 그대로다(회귀 스크린샷).
4. 공개 API 응답에 회원·결제 정보가 없음을 응답 예시로 보고.
5. 작업 기록 `docs/worklog/2026/11/2026-11-16-public-plans.md`.
