## 2. 이슈별 수정 (N22–N28)

### N22 · 게스트 커뮤니티 GNB = 게스트 홈 GNB

- **재현:** 비로그인 `#/guest` GNB에는 공부방찾기·공부방상세정보 등이 있는데, `#/community` 로 가면 과외쌤 위주로 바뀌고 공부방 항목이 빠짐.
- **AFTER:** 게스트일 때 커뮤니티도 **홈과 같은 GNB 구성** (최소: **공부방찾기 · 공부방상세정보** 복구 + 홈과 동일 정렬·라벨).
- 로그인 역할별 GNB 차이는 유지 (과외 홈에 공부방찾기 없음 등).

#### 「커서 주석」·오판 방지 (N22)

> 1. 커뮤니티 레이아웃이 **tutor 기본 GNB**를 쓰는 잔재일 수 있음 (N3와 계열). 게스트 세션이면 **guest GNB 프리셋**.  
> 2. 「커뮤니티에서는 단순화」로 축소하지 말 것 — **사용자 잠금: 홈과 일치**.  
> 3. GNB 컴포넌트 props에 role=`tutor` 하드코딩이 있으면 제거.  
> 4. 164 N3(푸터 홈)과 같이 고치면 좋으나 **커밋은 티켓 분리** 가능. 회귀만 같이 스모크.

---

### N23 · 게스트 상세등록·유료 → 소개+로그인 CTA

- **재현:** 게스트 GNB에 공부방상세정보·과외쌤상세등록·유료상품이 보이나, 클릭 시 「로그인 후」 **빈 차단 카드만**.
- **권장 잠금:** 메뉴는 두되, 랜딩에 **짧은 소개 카드 + 로그인/회원가입 CTA**.  
  대안(비권장): 메뉴를 로그인 뒤로 숨김 — 이번엔 **소개+CTA** 권장.

#### 소개 카드 카피 초안 (정중 · 사이트 표시명)

**공부방 상세등록 (게스트)**

- 제목: **공부방 상세정보를 등록하려면 로그인이 필요해요**
- 본문: **공부방 회원으로 로그인한 뒤, 위치·수업·사진 등 상세를 등록할 수 있어요. 등록이 충분히 채워지면 홈·찾기에 베이직카드 등으로 소개됩니다.**
- CTA: **로그인** → `auth/#/login` · **회원가입** (기존 가입 경로)

**과외쌤 상세등록 (게스트)**

- 제목: **과외쌤 상세등록은 로그인 후 이용할 수 있어요**
- 본문: **과외쌤 회원으로 로그인하면 수업 지역·과목·소개를 등록할 수 있어요.**
- CTA: **로그인** · **회원가입**

**유료상품 (게스트)**

- 제목: **유료 안내는 로그인 후 역할에 맞게 보여 드려요**
- 본문: **유료상품(노출·쪽지 등)은 공부방·과외쌤 회원용이에요. 로그인하시면 안내에 맞게 확인할 수 있어요.**
- CTA: **로그인** · (선택) **게스트 홈으로** → `#/guest`

> 「학생 의뢰」표현 금지. 학생 유료는 대상 아님을 본문에 이미 반영.

#### 「커서 주석」·오판 방지 (N23)

> 1. 기존 차단 컴포넌트를 **카피만 갈아끼우면** 됨. 결제/등록 플로우를 게스트에게 열지 말 것.  
> 2. 빈 `div`·영문 Lock 배지 남기지 말 것 (영문 배지는 166).  
> 3. 로그인 후 올바른 역할 등록/유료로 이어지는지 한 번만 스모크.

  (공부방·과외 LNB에 이미 있으면 패턴 맞춤 · 실경로 확인)

### N26 · 공부방 · 과외쌤찾기 정책

- **실측:** 공부방 GNB에 과외쌤찾기 **없음**(역할에 맞음). 이용안내에는 과외쌤 찾기 링크 **있음** → 모순.
- **잠금 권장:**  
  - GNB: 공부방에게 과외쌤찾기 **계속 없음**  
  - 이용안내 CTA: **역할별로 숨기거나** 문구 조정  
- **범위:** 이용안내 본문이 146–148 작업이면 **이번 티켓에서 가이드 파일 대수술 금지**.  
  → 구현 가능하면 역할 가드 한 줄; 아니면 **수락란에 「146 후속」메모**만 남기고 GNB는 현상 유지.

#### 「커서 주석」·오판 방지 (N26)

> 1. 공부방 GNB에 과외쌤찾기를 **추가하지 말 것**(잠금은 없이 유지).  
> 2. 가이드를 고치려면 146 티켓과 충돌 여부 확인. 불확실하면 **노트로 종료**.  
> 3. 「정책 정리」만 하고 GNB를 갑자기 열어 버리지 말 것.

### N27 · 등록점검 요약 모순

- **재현:** 「완료 19/26 · **부족 7** · **모든 필수 항목 입력 완료**」가 **동시에** 보임.
- **AFTER:**  
  - 필수가 남으면 → 「필수 n개 남음」/「부족 n」만. **「모든 필수 완료」 숨김**  
  - 필수가 다 찼으면 → 「모든 필수 항목 입력 완료」. **부족 n 숨김**(선택 항목 잔여는 별도 「선택 m개」로만)
- 숫자 로직(19/26)과 필수/선택 구분이 있으면 **필수 완료 여부**로 문장을 갈라야 함.

#### 「커서 주석」·오판 방지 (N27)

> 1. 카피 템플릿이 플래그 두 개를 동시에 true로 찍는 버그. **상호 배타** 렌더.  
> 2. BASIC/PICK/PRIME 영문 배지는 166. 이 티켓은 **요약 문장 논리**만.  
> 3. 「부족 0 · 모든 필수 완료」는 OK. 「부족 7 · 모든 필수 완료」는 **실패**.

### N28 · 학생찾기 배너 유료상품 링크 제거 (학부모)

  (공부방·과외가 같은 배너 컴포넌트를 쓰면 **역할 분기**)

#### 「커서 주석」·오판 방지 (N28)

> 1. 학생 GNB에 유료가 없는 정책과 **맞출 것**. 배너만 남아 있으면 실패.  
> 2. `#/plans` 고아 화면(N8/165)과 별개이나, 링크를 지우면 직접 진입만 남음 — 165와 순서 무관.
