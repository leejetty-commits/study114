| 구분 | 내용 |

| **변경분과 같은지/다른지** | **다름(이름)**: Notion=「원장 고민방」「과외쌤 고민방」「학부모/학생 고민방」 ↔ 변경분=「공부방」「과외쌤」「학생 학부모」. 변경분이 우선. 「방 3개 + 해결후기·알림은 별도」 구성 자체와 3축 역할 구분은 **같음**. 변경분에 「고민방」 접미어·「/」 유무는 명시되지 않음. |

| **노션 정본 기록** | **「쏙쏙정보」「따끈 팁가이드」: 노션에서 못 찾음.** 가장 가까운 기록: ① 23장 boardKey 표 `library`(자료·다운로드, 「자료실」은 사용자 명칭 후보), `library-template`(양식·체크리스트), `library-guide-pdf`(가이드 PDF), `safe-guide`(안전 가이드), `showcase`(사례 공유, 2차 후보). ② 23장 §8 보드군 분류 「큐레이션형 게시판 — 운영자가 선별한 게시물만 노출 — 추천 사례, 운영 팁」(예시일 뿐 이름 없음). ③ 23장 §9 「자료실 = 게시판 엔진 안의 특정 보드군 명칭」. ④ 23장 §22 우측 레일 활용: 「우측 배너 = 게시판 진입/요약/추천 슬롯」, 어울리는 것=학습자료·양식·PDF·공지·가이드 진입, 본문 route 대체 금지. ⑤ 23장 §25 홈 우측 seed = `notice`/`library`/`safe-guide`. ⑥ **23장 §26-3 위치 3단계**: 소속 메뉴군(sectionOwner) → 본문 route(routeSlug) → 보조 노출 슬롯(slotKey). 예: 자료실 계열 `#/library/*`, 고객센터 계열 `#/support/*`. ⑦ 30장: 자료실 `#/library`, `#/library/templates`, `#/library/guides`, 「GNB 제외·유틸 진입」. ⑧ **6장 §6-2 「제외 또는 후순위: 자료실/포털 메뉴 대확장」**. ⑨ ACL: library 계열 권한 「구현 확인 전 보류」. ⑩ **도착 메뉴 위치**(정보 게시판 전용): 못 찾음. |

## 주제 3. 이달의 베스트 / HOT 선정 기준

| 구분 | 내용 |
|---|---|
| **노션 정본 기록** | **「이달의 베스트」: 노션에서 못 찾음.** HOT 관련: 부록 레일 §3-1 「오늘의 현장 — 고민 / 댓글 / 공감 / 공지 / HOT 슬롯」, §7-1 「오늘의 현장: 오늘의 고민 1개 + 공감 많은 글 1개 + 댓글 많은 글 1개」, §7-2 홈 전용형 「지금 현장 고민 HOT — 원장/과외쌤/학부모 — 회전형 3슬롯」, §13-2 「고민/HOT 슬롯: 자주 갱신」. **기간·반응 종류·임계 수치·노출 범위 규정은 없음**(「공감 많은 글」「댓글 많은 글」만 있고 기준값 없음). 노출 범위: ACL 「HOT 링크도 대상 채널 게이트를 그대로 탄다」, 「HOT 카드: 비회원=고민방 이름·소개만, 학부모·학생=학부모·학생 고민방만 실제 글, 공부방·과외쌤=세 방 실제 글」. 30장: 「고민 HOT」은 홈 레일 입구. 같은 이름의 점수식(👍×2+댓글×1, 7일)은 **CSapp(다른 앱) 문서**의 것으로 우동공과 정본이 아님 — 인용 금지. |
| **변경분과 같은지/다른지** | 변경분 「이번 달 글 긍정 이모티콘 반응 합계 순」은 Notion에 **대응 문장이 없음**(신규). Notion의 「공감 많은 글」「댓글 많은 글」과는 방향이 비슷하나 **댓글 수는 변경분에 없음 → 다름**(변경분이 우선). 「HOT」과 「이달의 베스트」가 같은 것인지 별개인지 Notion은 정의 안 함 — 내부 188 문서는 둘을 별도 구역으로 다룸. |
| **노션에 기록이 없는 공백** | 기간(이번 달=달력월 vs 최근 30일), 동률 처리, 최소 반응 수(코드의 `BEST_STRIP_MIN_REACTIONS=5`는 Notion 근거 없음), 1개/N개 노출 수, 방별 분리 vs 통합, **노출 범위**(자기 방만/서로 보기 — ACL 게이트가 HOT에 적용된다는 원칙만 있음), HOT의 정의 — 전부 못 찾음. |

## 8. 노션에 이미 있어서 **종현에게 물으면 안 되는 것**
1. 레일은 게시판 본문이 아니라 **입구(진입/요약/CTA)** 이고 본문은 별도 route — 23장 §22·§26, 부록 레일 §12 (그대로 재확인 질문 금지).

## 9. 노션에도 없어서 **정말 물어야 하는 것**
1. **고민방 새 이름의 최종 표기**: 「공부방」「과외쌤」「학생 학부모」 뒤에 「고민방」을 붙이는지(메뉴·레일 배너·H1 모두 동일 적용인지). Notion은 「원장/과외쌤/학부모·학생 고민방」 + 「공부방 원장 고민방」 혼용.
2. 「고민방 3개 + 부록」에서 **부록이 무엇인지**(해결후기? 커뮤니티 알림? 별도 방?). Notion으로는 특정 불가.
3. **정보 게시판 2개(쏙쏙정보·따끈 팁가이드)의 소속 메뉴군·본문 route·boardKey**, 그리고 레일 배너가 도착하는 메뉴 위치(커뮤니티 하위/고객센터/자료실 계열/단독 route). Notion엔 이 두 이름 자체가 없음.
4. **정보 게시판과 자료실의 경계**를 어떻게 자를지(정보성 글·가이드 = 정보 게시판, 파일 다운로드·양식·PDF = 자료실로 둘지). 자료실 최종 노출 위치도 Notion이 「구현 확인 후 보류」.
5. 정보 게시판 **분류 4개의 이름·읽기/쓰기 권한** — Notion에 없음(188은 제안 상태).
6. **이달의 베스트 세부**: 「이번 달」=달력월/최근 30일, 동률, 최소 반응 수(현재 코드 5는 근거 없음), 노출 개수, 방별/통합, **노출 범위**(자기 방만/서로 보기). HOT과 베스트가 같은 구역인지.
7. **긍정 이모티콘 범위**: ❤️👍는 확정으로 보이나 😮「몰랐어요」·😢「걱정돼요」를 긍정 합계에 넣는지. 1인 1반응·취소 시 처리.
8. **게스트 샘플 베이직카드**: 「실제 카드 0」의 판정 범위(기준 지역 실카드만 보나, 노출 중 전체인가), 샘플 카드 문구·표시 방식, 과외쌤·학생 탭에서 「서울시 강남구」 표기 노출 문구. Notion은 「서울시」(9장).
