## 2. 잠금 정책

1. **동일:** 공부방 모드 학생찾기와 같은 구성(상세검색·자동 목록·카드·빈상태 톤).  
   - 과외에만 있는 **희망유형 선택으로 막히는 게이트**가 공부방에 없으면 **제거·완화**해 공부방과 같게.  
   - 희망유형 기본값: 공부방=공부방 / 과외쌤=**과외**(대칭).
2. **유일한 의도적 차이 — 현재위치 SSOT**  
   - 공부방: 기존처럼 **홍보1**(지역대표).  
   - 과외쌤: **활동지역 대표(지역대표 / 활동지역1 / `is_primary`)**.  
   - 로그인 과외쌤 학생찾기에서 「현재위치」라벨은 **GPS·주소검색·URL·게스트 서울 기본·다른 활동지역 클릭 잔여**로 **바뀌지 않음**.  
   - 상세검색으로 다른 지역을 넣어 **검색 결과**를 바꿀 수는 있어도(공부방과 동일 규칙이면 유지), **「현재위치」가 가리키는 문구**는 대표로 남긴다. (공부방도 동일하게 「현재위치=홍보1 고정」이 깨져 있으면 **같은 원칙으로만** 최소 수정 · 과외만 억지로 다르게 만들지 말 것.)
3. 홈 「우리동네 학생」이름·스냅샷 로직 변경 금지(이미 별도 수락).
4. 조회수(103/105) 파일·ROI PHP **손대지 말 것.**
