# 038 · 상세정보 「저장」과 진행 인정 정책

- 작성일: 2026-09-24 (KST)
- 관련: [037](037-signup-detail-optional-save-copy-ticket.md) · 사용자 질의(저장 안 누르고 창 닫기)
- 상태: **정책 잠금** (코드 동작 확인 기준)

---

## 0. 한 줄

**빈 칸이어도 저장할 수 있다 ≠ 창만 닫아도 저장된 것이다.**  
진행·다음 로그인 재개 기준은 **서버에 성공한 저장(또는 저장을 포함한 「다음」)** 뿐이다.

---

## 1. 질문

항목이 비어 있어도 저장되는 정책은 맞다.  
그런데 유저가 맨 아래 **저장을 잊고** 빈 채로 창을 닫으면?

1. 그걸 저장으로 받아들이는가?  
2. 다음 로그인 때 **그다음 화면**으로 만나는가?

---

## 2. 답 (현재 코드 · 권장 정책 동일)

| 행동 | 서버 반영 | 단계 진행 인정 | 다음 로그인 |
|------|-----------|----------------|-------------|
| **저장** 클릭 (빈 값 OK) | 예 (`saveCurrentStep`) | 해당 단계 저장됨 · `detail_completion_status` 갱신 | 마지막 성공 저장 상태 기준 |
| **다음** 클릭 | 예 (저장 후 이동) | 예 | 위와 같음 |
| 창 닫기 / 탭 종료 / 저장·다음 없이 이탈 | **아니오** | **아니오** | **다음 화면으로 건너뛰지 않음**. 마지막 성공 저장(또는 기본등록만 된 상태)으로 재개 |
| 화면만 보고 해시만 바꿈 (저장 없음) | 아니오 | 아니오 | 동일 |

근거 (`preview/study-room-ui`):

- 상세1: 저장·다음 모두 `saveCurrentStep(..., 'lesson')` 후에야 `detailLessonSaved`  
- 상세2: 저장·다음 모두 facility/career 저장 후 `detailFacilitySaved`  
- 재진입: `room.detail_completion_status`가 `expanded_in_progress` / `expanded_complete`일 때만 플래그 복원 (`main.js` `initApi`)

카피 「지금 다 안 채워도 됩니다. **저장(다음)은 눌러 주세요**」는 바로 이 구분용이다.

---

## 3. 하지 않는 것 (당분간)

- 창 닫기 = 자동 저장(silent draft)으로 진행 인정 — **도입하지 않음** (논의 전)  
- 저장 없이 「다음 단계 방문함」만으로 completion 승격 — **금지**

원하면 후속 UX: `beforeunload` 「저장하지 않은 내용이 있습니다」경고만 (진행 승격 아님).
