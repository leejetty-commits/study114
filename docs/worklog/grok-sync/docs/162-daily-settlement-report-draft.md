### A. 목적

「**어제 하루 사이트에서 무슨 일이 있었나**」를 **숫자 한 장**으로 본다.
관리자가 아침에 메일 한 통만 열어도 결제·응대·등록·탈퇴·팝업 상황을 한눈에 알 수 있게 하는 것이 목적이다. 목록이나 상품별 내역을 읽게 하는 보고서가 아니다.

### B. 언제 · 누구에게

- 시간 기준: **한국 시간(Asia/Seoul)**.
- 하루 = **그날 0시 ~ 밤 12시**(자정). 자정에 그날을 마감한다.
- 발송: 마감·집계 후 **다음날 0:00 ~ 0:30 사이**에 **관리자(마스터 등)** 에게 메일로 보낸다.
- 자정 정각에 바로 보내야 한다는 요구는 **없다**. 30분 안이면 된다.

### C. 본문 5줄과 세는 법

보고서 본문(화면·인쇄·메일)은 아래 **5줄만** 담는다.

| 줄 | 이름 | 세는 법 |
|----|------|---------|
| ① | **오늘 결제** | 그날 결제된 **총 건수와 총 금액**. 그리고 **공부방 / 과외쌤 / 학생**으로 나눈 건수·금액. **상품별(쪽지권·픽·프라임 등) 내역은 본문에 넣지 않는다.** |
| ② | **남은 응대** | 아직 처리하지 않은 **문의 / 신고** 개수. 「그날 들어온 수」가 아니라 **보고서를 만드는 「지금」 기준**으로 남아 있는 수다. |
| ③ | **오늘 등록** | 그날 **베이직카드가 등록된 수**. 기준은 **베이직카드 등록일**이고, **계정 가입일이 아니다**(가입만 하고 카드를 안 만든 사람은 세지 않는다). **역할별**(공부방 / 과외쌤 / 학생)로 나눈다. |
| ④ | **오늘 탈퇴·삭제** | **본인 탈퇴**와 **관리자 삭제**를 **따로** 센다. 각각을 **역할별**(공부방 / 과외쌤 / 학생)로 나눈다. |
| ⑤ | **지금 홈 팝업** | 보고서를 만드는 시점에 **켜져 있는 홈 팝업 개수**(그 순간 스냅샷). |

### D. 예시 한 장 (예시 — 실제 숫자 아님)

```
[예시] 2026-10-06 일간 보고서
① 오늘 결제   5건 50만 원  (공부방 3건 20만 원 · 과외쌤 2건 30만 원)
② 남은 응대   4건  (문의 3 · 신고 1)
③ 오늘 등록   5건  (공부방 1 · 과외쌤 0 · 학생 4)
④ 오늘 탈퇴   2건  (공부방 1 · 학생 1)  /  관리자 삭제 1건 (과외쌤 1)
⑤ 지금 홈 팝업 2개
```

### E. 자세히 보기

- 숫자 뒤의 **목록**(예: 결제 건마다 결제 시각·회원·상품명·금액 등)은 **보고서 화면 옆 「자세히 보기」 링크에서만** 본다.
- 이 목록은 **인쇄와 메일 본문에는 넣지 않는다.** 본문은 C의 5줄뿐이다.
- 상품(쪽지권·픽·프라임 등)을 건건이 보는 것도 여기서만 한다(2026-09-25 잠금 2와 같음).

### F. 주간 · 월간

- 같은 **5줄**을 쓰고, **기간만 늘려 누적**한다.
- 주간: **월요일 0시 ~ 일요일 밤 12시**. 메일은 **월요일 0:00 ~ 0:30**.
- 월간: **1일 0시 ~ 말일 23:59:59**. 메일은 **다음 달 1일 0:00 ~ 0:30**.
- 기간이 길어질 때 다르게 세는 줄:
  - ② 남은 응대 → 주간·월간에서는 **기간 중 새로 들어온 문의·신고 건수**.
  - ⑤ 홈 팝업 → **기간 마지막 시점의 스냅샷**(켜져 있는 개수).
  - ①·③·④는 기간 동안의 합계.

### G. 보고서에 넣지 않는 것

- **노출 변경**(홈·목록 노출 바꾼 기록) — 넣지 않는다.
- **Nice**(본인인증) — 넣지 않는다.

| ② 남은 응대 | 159 **「문의·신고」 카드** |
| ③ 오늘 등록 | **159 등록 목록**이 곧 ③의 「자세히 보기」 |
| ④ 오늘 탈퇴·삭제 | 159 **「회원 정리」 카드** · 작업 기록 |

## 1-1. 마감·기간 (잠금 · 2026-09-25)

시간대: **한국(Asia/Seoul)**.

| 보고서 | 기간 | 마감 |
|--------|------|------|
| **일간** | 그날 **0시 0분 0초 ~ 그날 끝** | **당일 밤 12시**(자정). 즉 그날 23:59:59.999까지 포함 후 마감 |
| **주간** | **월요일 0시** 시작 ~ **일요일 끝** | **일요일 밤 12시**(자정) 마감 |
| **월간** | 그달 **1일 0시** ~ **그달 마지막 날 23:59:59** | **익월 1일이 되기 직전** (말일 23:59:59) |

한 줄:
- 한 주 = **월 0시 ~ 일 24시 직전**(일 밤 12시 마감).
- 한 달 = **1일 0시 ~ 말일 23:59:59**.
- 일간 = **그날 0시 ~ 그날 밤 12시 마감**.

## 1-2. 관리자 자동 메일 (잠금 · 2026-09-25)

- **가능 · 후순위**(화면 집계 확정 후).
- 받는 사람: 관리자(마스터 등).
- 본문: 보고서 **요약만** (상품·건건이·자세히 보기 본문 제외. 링크는 선택).
- **발송 시한:** 기간 마감·집계 후, **익일(다음 구간이 시작된 날) 0시부터 30분 이내**이면 됨.
  - 일간: 당일 밤 12시 마감 → **다음날 0:00~0:30** 사이 발송 OK
  - 주간: 일요일 밤 12시 마감 → **월요일 0:00~0:30** 사이 발송 OK
  - 월간: 말일 23:59:59 마감 → **익월 1일 0:00~0:30** 사이 발송 OK
- 자정 정각 즉시 발송은 **요구하지 않음**.



## 1. 보고서 vs 자세히 보기

| | **보고서** (일·주·월) | **자세히 보기** |
|--|----------------------|-----------------|
| 무엇 | 숫자 요약 한 장 | 그 숫자 뒤 **목록** |
| 결제 | 합계 건수·금액 + **역할**(방/과외/학생) | **건건이** 시각·회원·**상품명**·금액 |
| 응대·등록·탈퇴삭제·팝업 | 합계 + 분류 | 건건이 목록 |
| 상품 종류 쪼개기 | **안 함** | **함** (결제 행마다) |

## 2. 일간 보고서 본문 (매일)

### ① 오늘 결제
- **합계** N건 · M원  
- **분류** 공부방 n건 m원 / 과외쌤 n건 m원 / 학생 n건 m원  
- 상품별 쪼개기 → 보고서에 **없음** (자세히 보기)

### ② 남은 응대 *(일간만 «지금» 기준)*
- **합계** 미처리 N건  
- **분류** 문의 n / 신고 n  

### ③ 오늘 등록
- **합계** N건  
- **분류** 공부방 / 과외쌤 / 학생  
- 기준: **등록일**(베이직카드). 계정 가입일 아님.

### ④ 오늘 탈퇴·삭제
- **탈퇴** n건 — 공부방 a / 과외쌤 b / 학생 c  
- **관리자 삭제** n건 — 공부방 a / 과외쌤 b / 학생 c  

### ⑤ 지금 홈 팝업 *(일간만 «지금» 스냅샷)*
- 켜짐 N개 (+ 필요 시 대상별 개수)

**자세히 보기**는 보고서 화면 옆 링크로만 두고, **인쇄·저장용 보고서 본문에는 넣지 않음.**

## 3. 주간 · 월간 (일간을 누적)

같은 다섯 덩어리. **기간만** 오늘 → 이번 주 / 이번 달.

| 항목 | 주간·월간에서 세는 방식 |
|------|------------------------|
| **결제** | 기간 내 완료 건수·금액 합 + 역할별 |
| **등록** | 기간 내 등록일 기준 건수 + 역할별 |
| **탈퇴·삭제** | 기간 내 처리 건수 + 탈퇴/삭제 × 역할 |
| **응대** | **기간 중 새로 들어온** 문의·신고 건수 + 분류 *(「지금 남은」이 아님)* |
| **홈 팝업** | 기간 **말일(또는 보고 시점) 스냅샷** 켜진 개수 · 또는 「기간 중 켠 횟수」는 후순위 — **1차는 기간 말 스냅샷** |

주간·월간에도 **상품 쪼개기·건건이 표는 본문에 없음.** 자세히 보기에서 기간 필터로 목록.

홈 팝업 2개 켜짐  

**주간** (같은 줄, 「이번 주」합계)  
**월간** (같은 줄, 「이번 달」합계)

## 5. 플래너용 한 줄

보고서(일·주·월)는 **역할까지 나눈 숫자 요약만**. 상품·건건이는 **자세히 보기**. 주·월은 일간과 같은 칸을 **기간만 바꿔 누적**.
