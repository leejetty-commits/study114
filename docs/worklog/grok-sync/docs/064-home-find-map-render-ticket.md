## 0. 한 줄

공부방 홈·공부방찾기에서 네이버 지도가 안 나오고, 찾기에서 지역을 바꿔 검색해도 맵이 안 바뀐다. **원인 진단 먼저**, 그다음 최소 수정.

---

## 1. 재현

1. 공부방 로그인 홈 → 우리동네 공부방: 맵 영역 파란 빈 판 + 「표시할 위치 정보가 없습니다 — 목록은 그대로 유지됩니다.」
2. 가능동·신곡동 등 홍보1/검색 지역을 바꿔도 동일할 수 있음(사용자 보고).
3. 공부방찾기: 지역 변경 후 검색 → **그 지역 중심 지도+마커**여야 함(기대).
4. 게스트 홈(대치)는 맵이 보이는 사례 있음 → 로그인/좌표/키/초기화 분기 차이 의.

---

## 2. 1단계 — 진단 요청 (수정 전 필수 보고)

아래를 **수정 없이** 보고할 것:

1. 브라우저 콘솔 에러(Naver/maps/403/Referer/키 관련 전문)
2. 홈 vs 찾기 맵 마운트 파일·함수 (`naver-map` · `search-map` · `provider-home` · study-room 스크린 등)
3. 맵에 넘기는 center/bounds/markers 소스(홍보1 lat/lng · region_id · geocode 실패 여부)
4. 「표시할 위치 정보가 없습니다」문자열이 나오는 조건 분기
5. API 키/클라이언트 id가 홈·찾기에 다르게 로드되는지
6. 가설 1~2개(단정 금지)

진단만 오면 우동공과2가 판단 후 수정 지시(또는 본 티켓 §3으로 진행 허가).

---

## 3. 수정 목표 (진단 후 · 허가 시)

- 홈: 홍보1(또는 현재 동네) 좌표로 지도 렌더 + 목록 연동 마커(기존 정책 유지)
- 찾기: 검색 제출 지역의 지도로 **갱신**
- 목록 유지 카피가 나와도 **좌표만 비어 맵을 포기하는 잘못된 early-return**이면 고침
- signup·063 샘플·멤버박스와 커밋 혼합 금지
