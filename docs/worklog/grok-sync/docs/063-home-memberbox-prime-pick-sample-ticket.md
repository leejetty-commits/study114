## 2. 프라임

- 실 프라임 **0** → 왼쪽 **샘플 1**(이미지 `샘플`·가상 고정·점유/sku 아님) + **EMPTY 2**(실 프라임과 **동일 크기**).

- 실 1~2면 샘플 넣지 말고 실+EMPTY만. 047 자기방 프라임 금지 유지.
- 게스트 데모 시드와 로그인 샘플 경로 섞지 말 것.
