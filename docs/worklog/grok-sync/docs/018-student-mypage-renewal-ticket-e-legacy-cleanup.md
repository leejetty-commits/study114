## 0. 한 줄 목적

학생 마이페이지·관련 진입에서 **자녀 / guardian / 대표학생 / 대표희망\*** 레거시 문법·카피·라우트·상태를 걷어낸다.  
A~D에서 잠근 IA·카드·기본정보·상세정보 **재설계는 하지 않는다.**  
공부방·과외쌤 마이페이지, 히스토리 문서, 가입 14장 전면은 **하지 않는다.**

## 2. 범위

### 2-1. 포함 (학생 마이페이지·내 등록 축만)

원칙적으로 아래 트리·경로에서 **보이는 카피·죽은 UI·잘못된 라우트·상태 전이**만:

- `preview/home-ui/src/student-reg/**` (screens, router, store 연동 등 — **필요 최소**)
- `preview/home-ui/src/mypage/**` 중 **학생** 셸/내비 카피
- 학생 내 등록에서만 호출되는 헬퍼에 남은 `renderPhaseStepper` / `getStepDone` / publish-게이트 UI가 **학생 마이페이지 경로로 다시 노출되면** 제거 또는 비연결
- 「자녀」「대표 학생」「guardian」「대표 희망*」문자열·메뉴·빈상태·not-found

파일 allowlist를 미리 전부 박지 않는다. **작업 전** 위 패턴으로 검색 목록을 보고에 적고, 그 목록만 수정. 목록 밖이 필요하면 **중단·보고·승인 대기.**

### 2-2. 제외 (한 줄이라도 건드리면 거부)

1. 기본정보 9종·`request_summary` 재설계 (C)
2. 상세정보 9종·특이요청 재설계 (D)
3. 마이프로필 Basic 카드/리스트 구조 재작성 (B)
4. 쪽지설정 **저장** / PHP `memo_status` allowlist (별도 티켓)
5. 공부방·과외쌤 마이페이지·등록 전면
6. 학생찾기, 가입·온보딩(14장) 전면 리라이트
7. DB 스키마·컬럼 drop·guardian_user_id 물리 삭제 (계정 모델 대수술 금지). **화면 문법만** 청소
8. 히스토리/아카이브 문서, 다른 역할 화면의 과거 카피 “전수 소거”를 핑계로 광역 수정
9. push / `build:dothome` · auth WIP와 커밋 혼합
10. Stage5B 전역 리디자인 (→ F)

## 3. 제거 잠금 (노션 §6)

학생 **마이페이지·내 등록 진입**에서 아래가 **보이거나 동작하면 실패:**

- 자녀 목록 / 자녀 추가 / 자녀 정보 보완 / 자녀 추가 후 진행
- 대표 학생 선택 / 학생 전환 전제 메뉴
- guardian 전용 허브 카피(학생 화면에 노출되는 것)
- 대표 희망지역 · 대표 희망과목 · 대표 수업형태 · 대표 수업인원 · 대표 예산
- 필수 등록 · 아직 부족 · 공개 전 완료 필요 (학생 내 등록 경로에 다시 붙는 경우)
- 별도 「확인」탭을 공개설정처럼 부활

허용:

- 코드 내부 변수명 `guardian_user_id` 등 **API/DB 식별자**는 스키마 대수술 없이 둘 수 있다. 다만 **사용자에게 보이는 문자열**에 guardian/자녀를 쓰지 말 것.
- soft-delete·권한 로직은 유지. “자녀” UX만 제거.

## 4. 죽은 게이트·스테퍼

A 이후 `renderStudentShell`은 탭만 쓴다. 그런데 `renderPhaseStepper` / `getStepDone` / publish 체크리스트가 **파일에 남아** 다른 경로로 다시 호출되면 회귀다.

E에서:

1. 학생 마이페이지 경로(`#/mypage…`, student-reg P19-*)에서 stepper·부족·공개 전 완료 UI가 **호출되지 않게** 정리.
2. 아무 경로에서도 안 쓰이면 **삭제 또는 미사용 명시** (dead code 제거 권장). 불확실하면 호출부만 끊고 보고.
3. `data-p19-hope-dual`이 **상세 폼에 없는데** detail submit에만 남은 분기는 제거 가능. basic의 희망지역 UI는 **건드리지 말 것** (C 회귀).

## 6. 완료 전 필수 점검

### 6-1. 라우팅 (id=1)

1. `#/mypage` → 마이프로필. A/B 유지.
2. basic / detail / settings 탭 정상. C/D 필드 세트 **회귀 없음.**
3. 구 URL·자녀/대표학생 전제 경로가 있으면 **마이프로필 또는 합의 리다이렉트**. 새로 만들지 말 것.
4. 학생 내 등록에서 stepper·부족 n개·공개 전 완료·자녀/대표\* 문구 **화면 검색 0건** (보고에 검색 키워드·결과).

### 6-2. API

1. 학생 조회 200. 마이프로필·basic·detail 로드 정상.
2. basic `request_summary` · detail `special_request_note` 저장 **스모크 각 1회** (회귀).
3. 새 엔드포인트 없음. 스키마 미변경.

### 6-3. 예상외

중단·보고·승인 대기.
