## 2. Must (해야 할 일)

### 2.1 최우선 버그 — 비교·찜·쪽지 순서
- `screens.js` 등 **「비교 → 찜 → 쪽지」** 리드 → **「찜 → 비교 → 쪽지」**
- copy/플로우/칩/본문에서 비교가 찜보다 앞에 오는 문장 전부 통일
- 비교 FAQ: 「최대 3개가 **적절**」류 → **「비교 후보는 최대 3개」** + 「더 보려면 담은 것을 빼고 다시」 (147 §2.1 문장 사용 가능)

### 2.2 찾기·첫 이용 순서 통일 (146 §2.3)
정본 한 줄(찾는 분):  
`찾기 선택 → 조건 검색 → 상세 확인 → 찜 → (필요 시) 비교 → 로그인 → 쪽지`  
- 리드 「찾기 → 찜 → 비교 → 상세」처럼 **상세가 찜 뒤**인 문장 수정
- 「검색부터 비교·찜」 → **찜·비교** 순으로 읽히게

### 2.3 등록·노출
- 히어로 등 **「공급자」** → **「공부방·과외쌤」**
- **「활동 시 1개 선택」** → **「활동 시·군 1개 선택」**(또는 실제 필드 화면명에 맞는 「활동 지역」)
- 플로우 칸 **「기본 노출」** 다음에 또 **「검색/리스트 노출」** 있으면 **한 단계로 합치기**
- 「공통가입」첫 등장에 **「회원가입(계정 만들기)」** 병기
- 증빙/제출: **심사·보증 없음 · 참고용** 한 줄 (146 §1.1)

### 2.4 비교·찜·쪽지 문장
- 「상세등록 정보」→ 찾는 분 기준 **「상세 페이지」**
- 「학생과 접촉…」→ **「회원끼리 플랫폼 안 첫 연락」**
- 「공급↔수요」→ **회원끼리 / 공부방·과외쌤 ↔ 학부모·학생**

### 2.5 안전이용
- **채집** → **기록해 두기 / 캡처·내용 남겨 두기**
- **이상시** → **이상이 있으면**
- 「노출된 신뢰정보」첫 등장에 146 §1.1 한 줄 정의

### 2.6 짧은 보충 (본문·리드에만 · 새 큰 섹션 금지)
146 §1.1 블록을 **기존 문단/리드에 끼워 넣기**:
- 찾기: 로그인 전 목록·상세 OK · 찜·쪽지는 로그인 후
- 등록: 공통가입=회원가입 · 필수만 하면 기본 노출 · 무심사 · 상세는 선택
- (선택) 각 서브 맨 아래 「막히면 고객센터 FAQ」 **한 줄 동일 패턴** — 고객센터 페이지 내용 복제 금지

### 2.7 홈 학생 입구 — **최소만** (147 잠금 · FAQ/절 본문 금지)
- 이용안내 홈: 큰 상황 카드 **3장 유지**
- 그 **아래 보조 층**(안전이용·고객센터와 같은 층)에만  
  라벨 **「학생·학부모예요」** / **「학생 안내 보기」** + 한 줄 설명  
- **큰 카드 4번째 금지**
- CTA는 `#/guide/start` **또는** `#/guide/register` **한곳만** (앵커/절 신설이 이번 티켓에 없으면, 해당 페이지 **상단·하단으로 스크롤되는 기존 위치로만** 연결; 학생찾기·학생등록 **새 절 HTML은 147**)
