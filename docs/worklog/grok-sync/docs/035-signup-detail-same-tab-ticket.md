- 상태: **로컬 수락** → [036](036-signup-detail-same-tab-acceptance.md)

## 0. 한 줄 목적

공부방 「상세등록 이어하기」(및 동일 패턴)가 **새 창(`window.open` `_blank`)으로 열리지 않게** 하고, **같은 탭**에서 이어가게 한다.  
기본등록 → 상세 진입 때 게스트 「공부방상세정보」가 2–3초 깜빡이는 문제도 **같은 축이면 함께** 잡는다.

---

## 1. 현상 (잠금)

1. 이메일 확인/완료 후 이어하기가 **새 창**으로 열림.
2. 코드 축(기확인): `preview/auth-ui/src/screens/signup-complete.js` — 공부방 상세 이어하기 `window.open(STUDY_ROOM_UI_BASE, '_blank')`. 과외쌤은 이미 `location.assign` 계열.
3. 공부방 기본→상세 때 게스트 「공부방상세정보」가 잠깐 보였다가 로그인 상세로 바뀌는 **플래시**(사용자 보고). 새 창·게스트 엔트리가 원인 후보.

**첨부:** 사용자가 새 창/플래시 관련 스크린샷·재현을 Cursor에 직접 첨부.

---

## 2. 포함

1. 공부방 상세 이어하기: `_blank` / `window.open` **제거** → 같은 탭 `location.assign`(또는 기존 과외쌤과 동일 패턴).
2. 학생이 마이페이지로 이어가는 경로에 `_blank`가 있으면 **가입 이어하기 맥락만** 같은 탭으로. (무관한 외부 링크는 제외 판단 후 보고.)
3. 게스트 상세 플래시: 같은 탭 전환 후에도 남으면, **가입 직후 상세 진입 라우트**만 최소 수정(잘못된 게스트 엔트리·해시·부트 순서). 공부방 공개 상세 UX 전면 개편 금지.
4. 라우팅 점검 증거: 완료 → 이어하기 → 상세1(또는 합의 화면)이 **같은 탭** · 게스트 플래시 없음(또는 원인·잔여 명시).
