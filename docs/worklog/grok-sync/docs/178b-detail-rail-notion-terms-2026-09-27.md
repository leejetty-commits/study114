## 1. 결론

**항목 6의 상세 레일은 A/B/C 중 하나로 통째로 고정된 구조가 아니다. 슬롯별로 섞여 있다.**

- **A(인페이지 요약/팁)**: 레일 카드에 짧은 체크 항목과 설명을 보여준다.
- **B(메뉴 페이지 링크)**: 안전이용·비교/찜/쪽지·고객센터 같은 정식 안내 페이지로 보낸다.
- **C(커뮤니티/Q&A성 게시글)**: 실제 고민/사례를 짧게 미리 보여주고, 커뮤니티의 해당 고민방으로 보낸다.

따라서 질문을 한 줄로 답하면:

> **첫 연락·안전·쪽지 도움은 A 요약 + B 안내 페이지가 정본이고, 비슷한 고민/사례만 C(커뮤니티 게시글 입구)다. 레일 자체가 질문답 게시판 본문은 아니다.**

### 핵심 구분

- **C는 “해당 항목 질문답 게시판을 레일에 넣는다”는 뜻이 아니다.** 실제 커뮤니티 글의 요약/추천/입구를 둔다는 뜻이다.
- **안전 가이드·첫 연락·쪽지 도움은 커뮤니티 글보다 안내 허브가 우선**이다.
- 문서의 “고민/공지형”은 두 종류를 분리해야 한다.
  - 고민·후기·사례: 커뮤니티(C)
  - 공식 공지: 고객센터의 공지사항(B)
  - 커뮤니티 안의 짧은 운영 알림: 커뮤니티 알림(B/C 중 본문은 커뮤니티에 두되, 레일에서는 입구만 노출)

## 5. 구현/검수에 바로 쓰는 정본 문구

### 상세 레일 권장 표면

1. **첫 연락 전 체크**
   - 공개 정보 다시 보기
   - 가격·위치 확인
   - 첫 연락은 쪽지로 시작할 수 있어요
2. **안전이용**
   - 개인정보·선입금 전 확인할 내용을 안내해요
   - 신고 안내는 고객센터에서 확인해요
3. **유사 고민·사례**
   - 실제 커뮤니티 글의 제목/요약/반응만 보여줘요
   - 클릭하면 역할별 고민방으로 이동해요
4. **쪽지 이용 알아보기**
   - 비교·찜·쪽지 흐름을 안내해요
5. **소개 영상**
   - 사이트 안 팝업으로 재생하고 원래 상세로 돌아와요

### 금지할 해석

- 레일에 Q&A 게시판 본문·댓글을 직접 복제하지 않기
- 안전이용을 고민방으로 보내지 않기
- 운영문의를 쪽지로 표시하지 않기
- 공식 공지와 커뮤니티 알림을 같은 메뉴로 표시하지 않기
- `학생 의뢰`, `BASIC/PICK/PRIME`, `안전가이드`를 현재 노출 문구로 남기지 않기
- 실제 커뮤니티 글이 없는데 HOT/고민을 가짜로 채우지 않기
