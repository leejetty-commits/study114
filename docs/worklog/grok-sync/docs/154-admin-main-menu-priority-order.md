## 기준 (한 줄)

**사이트가 이미 하는 일 → 운영자가 매일 만져야 하는 화면**을 앞세우고,  
**미리보기·미연동(랩)** 은 손보기보다 **표시·숨김·이름**부터 정리한다.

---

## 묶음 순서 (4단)

### 1순위 — 지금 바로 손봐야 함 (실사이트 운영·청소)

사이트에 **실제 회원·등록·노출·결제**가 돌아가는데, 관리자가 여기로 못 맞추면 테스트 카드·탈퇴 잔여가 남는다.

| 주메뉴 | 하위(우선) | 왜 |
|--------|------------|-----|
| **회원관리** | 회원 목록 | 탈퇴 ≠ 삭제(153). 등록물 숨김·관리자 삭제 분리. 테스트 회원 청소의 입구 |
| **마켓·결제** | **노출 보정**, **결제·주문** | 홈·찾기 카드 숨김/노출, 유료상품·주문. **실연동** |
| **환경설정** | **팝업 관리** | 홈 팝업 이미 실연동. 마스터만 |
| **고객응대** | 신고 처리, 문의, 제출자료 확인 | 신고·문의·제출이 제품에 있음. 문의는 DB 경로 안정화 |

**이 묶음에서 할 일 요약:** 탈퇴/삭제 정책 구현 → 노출·회원 연동 → 팝업은 유지·검수.

---

### 2순위 — 사이트 콘텐츠와 이름·흐름을 맞출 것

이미 손님·회원이 보는 **이용안내·공지·FAQ·가입**과 관리 화면이 어긋난 부분.

| 주메뉴 | 하위 | 왜 |
|--------|------|-----|
| **게시판관리** | 공지사항, 자주 묻는 질문, (구)안전과외 가이드 | 제품은 **이용안내·고객센터**. 가이드 **이름·경로**를 제품에 맞춤 |
| **게시판관리** | 게시판 채널, 우측 배너 | 실연동. 노출 정책과 충돌 없는지 점검 |
| **환경설정** | 사이트 기본, 가입·등록, 약관·개인정보, 권한·계정 | 가입·약관·운영자 계정. 팝업 다음으로 정비 |

**이 묶음에서 할 일 요약:** 라벨을 사이트 말투에 맞추고, 가입·약관 토글이 실제 가입과 같은지 확인.

---

### 3순위 — 메뉴는 있으나 「미리보기」로 낮출 것 (손보기보다 표시)

Youngcart식 골격에 남아 있는 **랩/미연동**. 운영자가 실도구로 오해하면 위험.

| 주메뉴 | 하위 | 조치 방향 |
|--------|------|-----------|
| **마켓·결제** | 마켓 현황, 공부방·과외 목록, 매출·순위, 이용 후기, 미완료 결제 | 「미리보기」 표시 또는 사이드에서 접기. 후기·통계는 실테이블 연동 전까지 비우선 |
| **알림·문자** | 기본설정~전송내역 전체 | 실제 문자 미발송. 랩 표시 |
| **부가서비스** | 홈 / PG / SMS / 본인인증 | 벤더 허브·스텁. 연동 전까지 비우선 |
| **홍보 런치** | 홍보 런치 데스크 | 링크 허브 성격. 운영 핵심 아님 |

---

### 4순위 — 있으면 좋음 · 급하지 않음

| 항목 | 비고 |
|------|------|
| **운영 홈** | 바로가기만 정리. 1~2순위 화면으로 링크 |
| **운영 로그** | 이미 실연동. 탈퇴·삭제 로그와 맞춰 보면 됨 |
| **(신설 후보)** 학생 등록 목록 | 기본=최근1주·**등록일**기준(가입일 제외)·지역·기간. 베이직카드. 2순위 이후 |

---

## 한 장으로 보는 순서

1. **회원관리** (+ 탈퇴/삭제 153)  
2. **노출 보정 · 결제·주문**  
3. **팝업 관리** (유지·검수)  
4. **고객응대** (신고·문의·제출)  
5. **게시판·이용안내 이름 맞춤**  
6. **나머지 환경설정** (기본·가입·약관·권한)  
7. **랩 메뉴 표시/접기** (마켓 랩 · 문자 · 부가 · 홍보)  
8. **운영 홈·로그 다듬기** · 학생 목록 신설은 나중
