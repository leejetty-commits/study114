- `max-width: min(100vw - 32px, card-width)`

- C 스플릿은 ≤768에서 세로 스택 전환 권장
- 오버레이: `rgba(28,25,23,0.40)` · 카드 중앙 · z-index 상위

체크/문구는 **muted 중성** — 사이트 블루·카테고리 액센트로 칠하지 않음.

## 2. 색 분리: 사이트 블루 ≠ 팝업 카테고리 (bright-only)

홈·GNB는 이미 UDX Primary `#266BC4` 톤. 팝업까지 블루로 채우면 단조롭고 “재미”가 없음.

**규칙**
- 사이트 셸(가짜 홈 헤더·히어로)만 블루 유지 → 대비로 팝업이 돋보임
- 팝업은 카테고리별 **밝은** 개성 색 (네이비·차콜·근흑 패널 **금지**)
- 공유 크롬만 약하게 연결: 오버레이, 흰 원형 X, 중성 dont-show

| 유형 | 카드/패널 | 액센트 | CTA | 톤 |
|------|-----------|--------|-----|-----|
| A 공지 | cream `#FFFBF5` | amber stripe `#D97706` / badge | ochre `#92400E` (블루 fill 금지) | 신뢰·제도적 |
| B 이벤트 | cream body `#FFF9F5` | soft coral/peach hero | coral `#E86B4A` | 시즌·즐거움 |
| C 광고 | soft mint 좌 `#D8F3EC` + 흰 우 | teal badge | vivid teal `#14B8A6` | 밝고 산뜻한 홍보 |

닫기 버튼: **밝은 흰 원** (다크 필 금지). 히어로 위에서도 흰/반투명 라이트 원.

## 3. 언제 어떤 유형을 쓸까

- **A 공지** — 점검, 약관·정책, 운영 안내. 이미지 없이 텍스트 우선.
- **B 이벤트** — 기간 한정 혜택, 시즌 캠페인. 비주얼 히어로가 핵심.
- **C 광고/홍보** — 서비스 가치 제안, 크로스셀, 가벼운 프로모. 짧은 피치 + 듀얼 CTA.

동시에 여러 팝업을 띄우지 말 것. 우선순위: 공지(필수) > 이벤트 > 광고.

---

## 4. Do / Don’t

**Do**
- 고정 데스크톱 사이즈를 레이아웃 계약으로 잠금
- 카테고리 액센트로 블루 셸과 구분
- 한글 본문 14px, 제목 18–22px semibold
- 「오늘 하루 보지 않기」는 모든 유형에 동일 위치 패턴 유지

**Don’t**
- 팝업 CTA/패널에 `#266BC4` 블록 fill (사이트와 동화되어 지루함)
- 네이비·차콜·근흑 패널/다크 시리즈
- 카지노식 깜빡임·강한 그림자·골드 과다
- 공지에 히어로 이미지, 광고에 장문 문서 본문
