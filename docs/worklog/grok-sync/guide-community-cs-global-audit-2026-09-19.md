## 5. 후속 작업 제안 (짧게 · 3분류만)

### 그대로 유지할 것
- 이용안내≠고객센터, 안전이용≠안전과외, 쪽지≠운영문의 (17장 — 기존 문서에 이미 존재)
- Pretendard · Primary `#266BC4` · shell max 1280 · Type B 좌메뉴 family
- 커뮤니티·CS 부록 v2 장식 문법(브래킷 금지, edge/icon/halo)
- 이용안내 5메뉴 IA

### 현재 구현에 이식할 것
- 시안의 **토큰화된** 공통분모(카드 chrome, Type B 내비, CS 기하 히어로·퀵타일, 가이드 상황 3카드 IA) — 단 FS는 **12/14/16/18/22/28/36만** (UDX-10)
- 가이드·CS 카피/역할 분리 구조 (이미 정본과 정합)

### 사용자 승인 후에만 문서 수정할 것
- UDX-20 안 **nav160/body800/gap8/rail224** vs **220/648/300** 병기 정리
- 이용안내 **우레일 없음(b2)** 을 family 예외로 문서화할지 여부
- 시안 CSS의 **11/13/15/17** 잔존을 정본 예외로 둘지, 구현 전 토큰만으로 고칠지
