## 1. 현재 문제 진단 (라이브)

1. **제목 체계 붕괴** — H1이 `이용안내 / ○○` 이중 표기, 문서 title은 전역「메인 화면 프리뷰」.
2. **같은 링크 과반복** — 허브 카드 · 좌메뉴 · 우레일 ·「빠른 흐름 요약」이 동일 목적지 반복.
3. **서브 과밀** — 각 서브가 히어로 칩 + 플로우 차트 + 단계 카드(+FAQ)로 **같은 여정을 2~3번** 설명.
4. **좌메뉴↔본문 관계 약함** — 본문이 “또 다른 목차”처럼 보여 메뉴 active가 약해짐.
5. **우측영역 실익 부족** — 서브에서 파란 여백 + 좌메뉴와 같은 가이드 카드 → 중복·공간 낭비.
6. **라우트 드리프트** — 신고 CTA가 레거시 `#/policy/reporting` vs 정본 `#/support/policies/reporting`.
7. **고객센터와 경계 흐림** — 허브에 CS 타일 벽(공지·FAQ·약관·자료·문의)이 커져 안내 허브가 CS처럼 보임. (역할 분리는 유지하되 **표현 밀도** 문제)
8. **모바일 390** — GNB 가로 스크롤·클리핑, 허브가 카드 중간에서 시작, 좌메뉴 미정리.
9. **카피 리듬** — 짧은 친절 배너보다 긴 블록·반복 문장이 많아 초보 리딩이 끊김.
10. **용어 흔들림** — 쪽지/문의/신고가 문맥에 따라 섞여 읽힐 여지 (채널 구분 필요).

- 허브의 CS 타일 벽(공지/FAQ/약관/자료/문의 격자) → **「고객센터」텍스트 링크 1행**으로

## 3. 이용안내 홈 + 4서브 레이아웃 제안

### 공통 Shell
- **좌메뉴**: 5항목 · active = Primary 글자 + subtle bg · 라벨=아래 공식명 그대로
- **본문**: white 정보형 (유료 warm 강제 적용 안 함)
- **우측**: 허브는 **최소**(다음 행동 1~2) 또는 없음 · 서브는 **접기/슬림**(관련 다음 가이드 1 + 고객센터 1) — 좌메뉴 복제 금지
- 타이포: Eyebrow `이용안내` · **H1 = 페이지명만** · H2 섹션 · 본문 14/16 리딩형
- 장식: chip / icon tile / thin divider (브래킷·광고판 금지)

### 3-1. 이용안내 홈 `#/guide`
**역할 1줄:** 상황만 고르면 되는 **입구 허브**.

| 구역 | 제안 |
|------|------|
| 상단 | 친절 배너: H1 `이용안내` + 리드 1~2문장 · Primary CTA 없음(또는 `찾기 시작` Ghost 1) |
| 핵심 | **상황 카드 3** — 찾는 중 / 등록하려요 / 비교·찜·쪽지 쓸래요 → 각 서브로 |
| 보조 | 카드 아래 링크 행: `안전이용` · `고객센터` |
| 좌메뉴 | 5항목 · 홈 active |
| 우측 | **불필요에 가깝음** → 제거 권장. 남기면「오늘 할 일」1문장만 |
| 하단 CTA | `공부방 찾기` · `과외쌤 찾기` (실이용 연결) |

**삭제:** 자주 찾는 4카드 + 빠른 흐름 3열 + CS 타일 벽 + 우레일 가이드 4장.

**역할 1줄:** 후보를 모으고 고르고 **쪽지로 첫 연락**하는 법.

| 핵심 | 기능 **3칩**(찜 / 비교 / 쪽지) → 스텝 4~5 **한 벌** → 짧은 비교 팁 1표(선택) |

### 3-5. 안전이용 `#/guide/safe`
**역할 1줄:** 이용 중 **행동 수칙**(친절한 주의) — 정책 전문은 CS.

| 구역 | 제안 |
|------|------|
| 상단 | H1 `안전이용` + 배너 |
| 핵심 | **하세요 / 하지 마세요** 2열 체크 · 쪽지로 첫 연락 · 선입금·외부결제·개인정보 주의 (짧게) |
| 좌메뉴 | active |
| 우측 | `고객센터 · 안전과외 정책` · `신고·분쟁`(**정본** `#/support/policies/...`) · `운영문의` |
| 하단 CTA | `고객센터 가기` · `신고·도움 안내`(정본 라우트만) |

**유지:** CS의 안전과외/신고/정책 페이지는 삭제·병합하지 않음. 가이드는 “먼저 읽고 행동”, CS는 “공식 기준·접수”.

## 6. 가장 추천하는 최종안 1개

**이름: “상황 3입구 · 서브 단일 스토리 · CS는 링크만”**

1. 홈은 **상황 카드 3 + 안전이용/고객센터 링크**만.  
2. 네 서브는 각각 **친절 배너 + 스텝(또는 체크) 한 벌 + 하단 CTA**. 차트·장문 FAQ 남발 금지.  
3. 우레일 복제 가이드 삭제 · 필요 시 다음 행동 1~2만.  
4. 안전이용은 행동 수칙, CS 안전과외·신고·정책은 공식 허브로 **병행 유지**.  
5. 쪽지≠운영문의 카피·CTA 분리.  
6. 라우트 5정본 + 구주소 alias + policy 리다이렉트.  
7. 모바일 좌메뉴 셀렉트/아코디언.

이 안은 이용안내를 **더 친절한 안내 허브**로 만들되, 고객센터·GNB·안전 병행·채널 구분을 깨지 않습니다.
