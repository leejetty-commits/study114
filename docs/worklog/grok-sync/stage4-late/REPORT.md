## 3. ‘단지 거점’ 시각 언어 요약

한 문장: **아파트 단지와 동네를 중심으로 공부방을 따뜻하게 발견하고, 충분한 정보와 근거를 비교해 안심하고 선택하는 지역 교육 플랫폼.**

잠정 토큰 (`.site-theme-danji`, 사이트 전역 확정 아님):

| 역할 | 값 | 쓰는 곳 |
|------|-----|---------|
| Primary | `#B5402A` | CTA 채움, 활성 밑줄, 포커스만 |
| Ink | `#1C1917` | 제목, 본문, **가격** |
| Muted | `#57534E` | 보조, 메타 |
| Background | `#F7F4F0` | 따뜻한 스톤 페이지 |
| Surface | `#FFFFFF` | 카드·헤더 |
| Line | `#E7E0D8` | 1px 경계 |
| Success / Warning / Error | `#2F6F4E` / `#B45309` / `#B42318` | 상태 문구. 인증 뱃지 아님 |

글자: Pretendard만. 크기 **12 / 14 / 16 / 18 / 22 / 28 / 36**만.
- 12 캡션·뱃지·상태
- 14 메타
- 16 본문·버튼·Basic 이름·가격
- 18 Prime·Pick 이름·가격
- 22 섹션
- 28 페이지 제목
- 36 데스크톱 히어로

카드 안 크기는 최대 3단. 임의 중간 크기·clamp로 새 크기 만들지 않음.  
모바일은 **큰 제목만 한 토큰 내림**(36→28, 28→22, 22→18). 본문·메타·캡션은 유지.

간격 8pt. 카드 반경 12. 행·버튼·입력 8–10. 1px 보더. **강한 그림자·유리·그라데이션·장식 없음.**  
이미지 4:3. 얼굴 생활 사진 없음. 공간·책상·창·단지 실루엣 SVG 자리 이미지.  
따뜻함은 공간 사진 + 웜 스톤 + 클레이 브릭 CTA + 여백으로만.

가격은 Ink. Primary CTA는 **결정 영역당 하나.**  
역할 차이는 브랜드색 분리가 아니라 **정보 우선순위 / 상태 / CTA**로 둔다.

## 4. 대표 화면별 설계 의도

### A. `guest-home.html` — 따뜻한 발견
- 실제 서비스명 우동공과. 메뉴는 현재형: 홈, 공부방찾기, 과외쌤찾기, 학생찾기, 유료상품, 커뮤니티, 고객센터, 로그인.
- 히어로: 왼쪽 카피, 오른쪽 공간 이미지. 기본 동작 공부방찾기, 보조 과외쌤찾기.
- 회원 수·등록 수·인증률·1위 주장 없음.
- 저장 지역·단지 칩(대치동, 은마아파트 등)으로 거점 발견. 지도 검색은 넣지 않음.
- 홈에서만 Prime 3 · Pick 5를 **홈 노출 예시**로 보여 주고, 바로 아래 Basic 행을 두어 세 역할을 섞지 않는다.
- 유료상품 판매 페이지를 홈에 복제하지 않음.

### B. `room-search.html` — 공부방찾기
- 초기 결과 = **Basic 통합 목록 20행.**
- 검색 상단에 Prime/Pick 블록을 두지 않음 → 유료 순위 부스트처럼 보이지 않게.
- 필터는 기존에 가까운 것만: 지역, 과목, 대상, 가격, 수업 형태. 지도·거리·인증·AI 정렬 없음.
- 행의 기본 동작은 자세히 보기. 찜·비교·쪽지는 더 약하게.

### C. `tutor-search.html` — 과외쌤찾기
- 공부방찾기와 같은 문법. 활동지역, 주력과목, 대상, 수업 방식, 가격, 후기·추천.
- 학력은 **회원 입력**으로만 표기. SKY를 플랫폼 인증으로 쓰지 않음. 1위·성과 과장 없음.

### D. `detail.html` — 상세 위계만
1. 공간 이미지  
2. 이름·위치·대상·과목·형태·가격  
3. 특징·소개  
4. 증빙자료 보유 여부  
5. 후기·추천 통계  
6. 동작 영역(쪽지 = 이 화면의 기본 동작)  
게스트 URL, 로그인 게이트, 모달은 정하지 않음.

### E. `room-mypage.html` — 공부방 로그인 홈
- 3열 셸 + 역할 메뉴 개념 유지(내 등록, 쪽지·후기함, 최근열람, 찜, 구매이력, 계정설정).
- 공개 여부, 기본정보 입력됨/사진 없음, 증빙 있음/없음 입력 상태, 이용 중 상품, 쪽지.
- 완료율 % 없음. 증빙→순위 상승 카피 없음. 관리자 콘솔 같은 임의 메뉴 없음.
- 기본 동작 하나: 대표 사진 등록.

### F. `parent-home.html` — 학부모·학생 홈
- 저장 지역, 최근 본 곳, 찜한 후보, 비교 입구(빈 상태), 기본 동작 공부방찾기.
- 학생찾기 GNB 노출·역할 분리·새 메뉴는 결정하지 않음. 현재 메뉴를 유지.

### 모바일
- G1 게스트 홈, G2 Basic 검색, G3 홈 Prime/Pick 크기 예시.
- 내비는 **「형태 검토용 임시 표현」**. 햄버거/하단탭/모바일 GNB 확정 아님.

### 카드 비교 보드
- Prime·Pick을 나란히, Basic은 전체 너비 행으로 쌓아 상대 크기와 1·2·3차 주석을 붙임.

## 5. Prime · Pick · Basic 보존 방식

| 역할 | 크기 | 하는 일 | 이 시안에서의 위치 |
|------|------|---------|-------------------|
| **Prime** | 가장 큰 이미지, 3열 설득 카드 | 홈에서 발견·설득. 소개+특징까지 | 홈 노출 예시만. 검색에 안 섞음 |
| **Pick** | Prime보다 작고 Basic 행보다 큼. 비교값 정렬 | 후보를 나란히 스캔 | 홈 5열 비교 카드. 검색에 안 섞음 |
| **Basic** | 전체 너비 행, 좌·중·우 | 탐색. 유료 순위 없음 | 검색 초기 결과 ~20행 |

정보 위계:
1. 이름, 위치, 대상·과목, 가격  
2. 수업 형태·정원, 핵심 특징, 증빙자료 보유 여부(있음/없음)  
3. 후기·추천 통계, 찜·비교·쪽지, 최근성  

빈 필드는 숨기고, 값 있는 필드는 지우지 않음.  
후기·추천은 통계만. 유료 가중·인증 아님.

검색과 홈을 나눈 이유: v5 기억상 Basic 목록 노출은 무료이고 Prime/Pick은 **자리 노출 상품**이다. 검색 상단에 유료 카드를 두면 “돈 내면 검색 1등”으로 읽힌다. 이 시안은 그 해석을 막는다.

## 11. 유료상품 v5와 향후 시각 통합 검토 항목

**이번 작업에서 v5 파일은 수정하지 않았다.** 긴장만 적는다.

| 긴장 | v5 (plans-theme) | LATE 사이트 시안 (danji) |
|------|------------------|--------------------------|
| Primary | 아이보리+블루 `#266BC4` | 클레이 브릭 `#B5402A` |
| 캔버스 | `#F6F1E8` | `#F7F4F0` |
| Ink / Line | `#292823` / `#E6DFD4` | `#1C1917` / `#E7E0D8` |
| 스코프 | `.plans-theme` 유료 페이지만 | `.site-theme-danji` 공개·마이 시안 |
| Prime/Pick | 판매·재고·대기 보드 | 홈 노출 카드 크기·역할 |
| 홈 복제 | — | **판매 페이지를 홈에 심지 말 것** (지킴) |

5단계에서 볼 통합 질문:
1. 공개 사이트는 클레이 브릭, 유료상품은 블루 스토어프론트를 **병행**할 것인가, 한쪽으로 모을 것인가.
2. 모은다면 Primary만 맞출지, 배경·라인·타입 스케일까지 맞출지.
3. GNB `유료상품` 진입 시 헤더를 danji로 둘지 plans로 둘지.
4. Prime 3자리·Pick 5×2 미리보기를 홈 카드 그리드와 **숫자까지** 맞출지.
