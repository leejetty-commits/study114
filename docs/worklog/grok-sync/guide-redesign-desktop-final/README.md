# 이용안내 리디자인 · 데스크톱 최종 패키지

**정적 디자인 시안 · 운영 아님 · 최종 승인 아님**

## 열기

1. `html/index.html` 을 브라우저로 열기 (또는 각 `01-hub.html` … `05-safe.html`)
2. 미리보기 샷: `shots-desktop/01-hub.png` … `05-safe.png` (@1440)

로컬 서버 예: `python3 -m http.server 8765` (패키지 루트에서) → `http://localhost:8765/html/`
