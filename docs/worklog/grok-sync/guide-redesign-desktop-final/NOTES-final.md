## 필수 답변

### 1. 가이드 vs CS 분리가 어떻게 읽히는가
- **이용안내** = “어떻게 쓰는가” 행동 가이드 (허브 상황 카드 → 4서브 흐름).
- **고객센터** = 공지·FAQ·정책·운영문의 허브. 가이드 본문에 CS FAQ/정책 dump를 넣지 않음.
- 허브는 CS 타일 벽을 두지 않고 **「고객센터 보기」** 텍스트 링크 1개로 넘김.
- 안전이용 배너 2·도움 블록에서만 정책/신고/운영문의를 **링크**로 연결.

### 2. 비교·찜·쪽지와 쪽지≠운영문의 표현
- 메뉴·H1·카드·칩·CTA 라벨 순서를 **비교·찜·쪽지**로 고정.
- `04-compare` 배너 2 + 콜아웃: 쪽지=회원 간 / 운영문의=운영자.
- `02-start` 스텝5: 「로그인 후 첫 쪽지」+ 운영문의와 다름.
- 허브·비교 페이지에 운영문의 전면 CTA 없음 (안전이용·CS로만).

### 3. 등록·공개가 가입 / 공개 / 유료상품을 어떻게 밝히나
- 배너 1이 「어디까지가 가입이고 어디부터 공개」를 직접 말함.
- 5스텝: 회원가입·로그인 → 기본 정보 → 상세 → **공개하기** → **(선택) 유료상품 살펴보기**.
- 스텝5 본문: 등록·공개 후 선택, 필수 아님, 자동 결제 아님.
- 하단 CTA도 등록 2개 + 「유료상품 안내」고스트로 분리.

### 4. 안전이용 vs CS 정책 링크 분리
- **안전이용(가이드)**: Do/Don't 행동 안내 (거래/중개 뉘앙스 회피).
- **CS**: 운영문의 → 신고·도움 안내 → 안전과외 정책 보기 → 고객센터 (카드·CTA).
- 병합·삭제 없음. 가이드는 정책 본문을 복제하지 않음.

### 5. 왜 허브는 3-entry + 2 aux (5메뉴와 충돌하지 않음)
- **좌메뉴 5** = 전역 IA(홈·찾기·등록·비교·안전) 항시 내비.
- **허브 본문 3카드** = 첫 방문 상황 진입(찾는 중 / 등록 / 비교·찜·쪽지).
- **보조 2링크** = 상황 카드에 넣지 않은 안전이용·CS를 가볍게 연결.
- 3+2는 “시작점 우선순위”, 5메뉴는 “전역 목차” — 역할이 다름.
