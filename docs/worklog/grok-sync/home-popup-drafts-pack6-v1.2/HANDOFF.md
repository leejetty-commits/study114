# 핸드오프 — 디자인 시안 vs 코드 구현

작성: 2026-09-23 (KST) · 우동공과 홈 팝업

## 지금은 무엇인가?

**지금은 디자인 시안·스펙 단계**입니다.

- 레이아웃 / 톤 / 로고 lockup / **제목 아래 들여쓰기**(본문+제목 아래 배지·칩+CTA)를 확정하기 위한 HTML 보드·PNG.
- set-a(락업만) vs set-b(락업+워터마크 imprint)를 비교해 브랜드 각인 강도를 고른다.
- 이 ZIP은 **디자이너 검토·개발 핸드오프 원본**(HTML + PNG + 메모).  
  **Figma가 필수는 아님** — HTML 보드가 구현 레퍼런스.

## 확정 후에 무엇이 일어나는가?

**확정 후 Cursor(또는 개발)가 홈 코드로 구현**합니다.

구현 범위 예시:

1. **Modal 컴포넌트** — 오버레이 + 카드 + 닫기(X) + focus trap / ESC
2. **유형별 템플릿** — 공지(A) / 이벤트(B) / 광고(C) props·슬롯
3. **「오늘 하루 보지 않기」** — 쿠키 또는 로컬스토리지 (자정 만료 권장)
4. **이미지 에셋 경로** — `logo-lockup-pencil-wordmark*.png` 등 정적 경로 고정
5. 모바일: `max-width: min(100vw−32px, card)` · `max-height: 80vh` · 내부 스크롤 · C는 ≤768 세로 스택

## 구현 시 주의 (스펙 잠금)

| 항목 | 규칙 |
|------|------|
| 로고 | **합본 PNG 한 덩어리** (`<img class="brand-lockup">`). 아이콘·워드 분리·orphan 「우」 금지. full 2줄 로고는 1차 lockup으로 쓰지 않음. |
| 들여쓰기 | 제목(`h2.popup-title`) **아래** 본문·리스트·피치 **및 제목 아래 배지·칩·CTA**(EVENT, 기간 칩, 「자세히 보기」 등)를 `.popup-body-indent` (≈12–16px). 헤더 카테고리 배지(공지/안내)·제목·브랜드·「오늘 하루 보지 않기」는 flush. 「Autumn Offer」= lockup `<img>` 왼쪽. |
| 색 | **밝은 카테고리 색**(앰버/코랄/민트·틸). **사이트 블루 `#266BC4`와 분리** — 팝업 CTA/패널에 사이트 블루 fill 금지. |
| 닫기 | 밝은 흰 원형 X (다크 필 금지). |
| 동시 노출 | 팝업 1개만. 우선순위: 공지 > 이벤트 > 광고. |
