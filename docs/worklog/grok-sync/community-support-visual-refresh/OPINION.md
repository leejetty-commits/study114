# OPINION — 커뮤니티·고객센터 시각 리프레시 (의견 · 미잠금)

작성: 2026-09-17 KST · 정적 시안 기준 개인/봇 의견 · **정책·승인 아님**

## 한줄
라이브의 흰 여백·얇은 보더만으로는 “현장형 포털” 느낌이 약해서, **허브 랜딩 + 로그인 벽 일러스트 + 아이콘 타일**로 밀도를 올리는 방향이 설득력 있어 보입니다.

## 우선 제안 (의견)
1. **커뮤니티 허브(c01)** 를 보드 직행 전에 두면 “남기고·답하고·해결후기” 스토리가 한눈에 전달됨.
2. **게스트 벽(c02/s04)** 은 텍스트만보다 고스트 프리뷰+스텝이 기대치를 명확히 함. 단, 공개글처럼 오해되지 않게 blur/가상 칩 유지.
3. **고객센터 히어로(s01)** 는 어두운 사진 슬래브보다 지오메트릭 레이어+짧은 CTA 카피가 스캔에 유리.
4. **해결후기(c05)** 를 성공 스토리 카드로 키우면 커뮤니티 선순환 메시지가 살아남.

## 주의
- 비주얼을 너무 키워도 **정책 문구·법적 문서**를 시안에서 창작하면 안 됨 (이번 팩은 placeholder 유지).
- 가이드(safety/saved-contact) 톤은 참고만 — 복제·운영 동기화 아님.
- GNB 10개 풀라벨은 데스크톱에서 가로 스크롤 위험이 있음(기존 이슈). 이번 시안은 정확한 라벨 우선, 모바일 GNB는 별 팩.
