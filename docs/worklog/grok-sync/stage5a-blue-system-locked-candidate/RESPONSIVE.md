**960px 단일 규칙 (이중 표현 금지):**

- `min-width: 961px` → 데스크톱 sticky 레일

## 2. Basic 2열 → 1열 분기 (최소 카드 너비)

Basic 카드 최소 너비 산출:

| 조각 | px | 토큰 |
|------|-----|------|
| 썸네일 | 88 | (아이콘 크기, 간격 토큰 아님) |
| 썸네일–본문 갭 | 12 | `--s-1-5` |
| 카드 패딩 좌우 | 12 + 12 | `--s-1-5` |
| 본문(이름+가격 한 줄이 깨지지 않을 최소) | 196 | |
| **카드 최소** | **320** (`--basic-min`) | |

2열에 필요한 최소 뷰포트:

```
320 × 2  +  그리드 갭 12(--s-1-5)  +  페이지 패딩 24×2(--s-3)  =  700
```

따라서 **`max-width: 719px`에서 1열**.  
768은 패딩 24×2 + 갭 12 + 카드 2장 = 카드당 ≈ 354px ≥ 320이므로 **2열을 유지**한다.  
430/390/360은 1열. 전체폭 단일 행(4단계 clay Basic row)은 쓰지 않는다.

홀수 마지막 카드는 2열 그리드에서 **한 칸만** 차지한다. `grid-column: 1`. 전체폭으로 늘리지 않는다.

768 스트레스 샷: `shots/ref-basic-768-stress.png` (`pages/ref-basic-768-stress.html`).

## 3. Sticky 레일 접힘 폭

레일 너비 300(`--rail`) + 갭 24(`--s-3`) + 본문 최소 ≈ 520 + 페이지 패딩 64 ≈ 908.

CSS:

```
@media (min-width: 961px) { .rail { position: sticky; } }
@media (max-width: 960px) { .rail { position: static; } .detail-grid { 1열 } }
```

1440 참조만 sticky 후보. **≥960 sticky**라는 옛 표현은 폐기한다. 960 이상처럼 들려도 정확히 960은 static이다.

390 워킹 디폴트는 레일을 쓰지 않고 **하단 CTA**다. 접힌 레일을 모바일 기본으로 승격하지 않는다.

## 4. 하단 CTA — safe area와 본문 패딩

```
.bottom-bar {
  padding: 10px var(--s-2) calc(10px + env(safe-area-inset-bottom, 0px));
}
본문 하단 패딩 = --cta-bar-h(72) + --s-3(24) + env(safe-area-inset-bottom, 0px)
```

- 바 높이 콘텐츠 ≈ 52–64. 홈 인디케이터에 가리지 않게 inset을 더한다.
- 본문이 바 뒤로 숨지 않게 패딩을 확보한다.
- 찜·비교는 바에 넣지 않고 본문에 둔다.
- **430/390/360** 동일. 1440에서는 바를 렌더하지 않는다.
