## 부록 A. 구현 방법 (T1 참고)

- 라벨표는 **copy 파일에만** 둔다: 경로·동작 = `handoff-copy.js`, 상태·종류·SKU·역할 = `mypage/mypage-copy.js`(새 상수 예: `ORDER_STATUS_LABELS`, `PROVIDER_TYPE_LABELS`, `CATALOG_KIND_LABELS`, `SKU_LABELS`). 결제 상태는 이미 쓰고 있는 `orderStatusLabel`(`plans/history-mock.js`)이 같은 표를 쓰게 맞춘다.
- 「모르는 값 → 중립 한글」을 **함수 한 곳**에서 처리(원문 반환 `|| status`, `|| lastRoute`, `|| role` 제거).
- 내부 값(`data-*` 속성, API 파라미터, 라우트, DB 값)은 **바꾸지 않는다.** 화면에 찍는 글자만 바꾼다.
