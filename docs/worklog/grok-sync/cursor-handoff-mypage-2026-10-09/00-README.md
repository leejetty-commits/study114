## 3. 쓰는 법 (Cursor)

1. 처음에 1~4를 읽는다. 맡은 티켓 하나만 `02`에서 연다.
2. **티켓의 「선행」이 안 풀렸으면 시작하지 않는다**(특히 T1은 05 라벨표 종현 확인, T2 5번은 Q1).
3. `02` §0 공통 규칙대로: 최신 `origin/main`에서 티켓 브랜치 → 허용 파일만 → 합격 기준 숫자를 재서 → `02` §0-6 형식으로 보고. **main push·배포·PR 머지 금지.**
4. 문서와 코드가 다르면(줄 번호 이동, 함수 없음, 이미 고쳐져 있음): 고치지 말고 「다른 점」을 보고한다.
5. 티켓 밖에서 이상한 걸 발견하면 고치지 말고 보고서 「남은 문제」에 적는다.
6. 디자인 수치가 문서끼리 다르면: 03-결정기록 > 01-디자인가이드 > 참고 원본 순서.
