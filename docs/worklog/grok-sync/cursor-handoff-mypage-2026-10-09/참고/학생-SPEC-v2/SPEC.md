## 2. 통일 규칙

### 2-1. 골격 (위→아래, 순서 고정)

```
[좌측메뉴 160] [본문 열 — 아래 전부 폭 100%] [우측 레일 300]

1) 경로        마이페이지 - 내 등록                      12 / 400 / #4B5563, 구분자 「-」 #CBD5E1
2) 페이지 제목  마이프로필                                28 / 700 / #1C1917, 행간 1.3, 자간 -0.02em  (모바일 ≤640: 22)  ← 전 역할
   └ 머리 아래 1px #E5E7EB · 아래 패딩 16 · 아래 여백 24
3) 내 공지     (있을 때, soft 머리)                       아래 여백 24  ← 전 역할
4) 탭 바       (탭이 있는 페이지만: 내 등록)  14 / 500     아래 여백 24
5) 안내 1줄    (있는 페이지만, 기존 문구)                  14 / 400 / #4B5563 · 아래 16
6) 섹션카드 스택                                          카드 사이 16
```

- **본문 폭 = 콘텐츠 열 100%.** 탭 본문·폼에 `max-width`(640/720) 두지 않는다 → 내 공지·탭 바·카드 양끝이 모든 화면에서 같다.
- 좌측메뉴 160 · 사이 24 · 우측 레일 300 · 셸 1280(gutter 32) = 현재 코드값 그대로(§6 미결 참고).

### 2-3. 섹션카드 규칙

1. 카드 안에 **회색 머리띠(배경 있는 header) 금지.** 제목·설명은 카드 패딩 안에 글자로만.
2. **카드 안 카드 금지.** 카드 안 목록은 「행 + 1px 구분선」으로.
3. 한 카드 = 한 주제. 폼 탭(기본정보·상세정보·쪽지설정)은 카드 1장 + 그 안 맨 아래 저장 바.
4. 저장 바 밖에 따로 구분선·여백 박스를 두지 않는다.

### 2-4. 필드 규칙

1. 필드 = 「라벨 → (도움말) → 컨트롤」 세로 3단. 도움말이 없으면 라벨 아래 8에 컨트롤.
2. 도움말은 **항상 라벨 바로 아래 한 줄**(옆·컨트롤 아래 금지). 컨트롤 결과 설명(희망지역 저장 방식 안내)만 컨트롤 아래 8, 12px.
3. 짝이 되는 짧은 값 두 개만 2열: **학교급|학년 · 수업형태|수업인원 · 주 회수|1회 수업시간 · 희망 과외쌤 성별|학생 성별.** 나머지는 1열 100%. 모바일(≤640)은 전부 1열.
4. 「필수」 표시 없음(021 L81).
5. 회색 입력칸은 「값 있음」 뜻만(194). 진짜 읽기전용 입력칸(희망지역 주소칸)도 194 L10대로 값 있으면 회색. **「읽기만 하는 화면」(마이프로필)은 입력칸 모양을 쓰지 않고 표시 행**으로, 공란은 「미입력」 글자.

### 2-5. 희망지역 묶음

- **색 박스(연파랑 바탕·테두리) 없음.** 라벨·도움말·칩·주소줄·설명·결과 모두 다른 필드와 **같은 왼쪽선**.
- 순서: 라벨 「희망지역」 14/600 → 도움말 「효과적인 검색과 홍보를 위해서 주소단위를 선택할 수 있습니다.」 12 → 칩(행정동 / 아파트단지, 단일) → 주소줄 [입력(늘어남) + 「주소 검색」 Secondary h44 최소폭 96, 사이 8] → 설명 「선택한 주소의 행정동…법정동으로 저장합니다.」 12 → 결과 줄(바탕 #F7F8FA, radius 8, 14px: 뱃지 「행정동」 + 주소).
- **패딩 확정(A2): 주소 입력칸 좌우 패딩 12, 결과 줄 패딩 위아래 10 / 좌우 12. 주소 글자가 칸 테두리에 붙지 않게 한다.** (지금 화면은 주소 글자가 입력칸 왼쪽 테두리에 거의 붙어 있음.)
- 문구는 지금 그대로. 이 컴포넌트는 공용 `preview/shared/study-room-basic-form.js`의 `renderStudentHopeRegion` → `renderPromoSlot`(공부방 홍보지역 슬롯)을 같이 쓰므로 **학생 마이페이지 범위(`.home-app--role-parent .mp-room [data-hope-region]`)로만 CSS 덮어쓰기.** 공용 JS는 손대지 않음. 구현 시점은 §5 C3.
