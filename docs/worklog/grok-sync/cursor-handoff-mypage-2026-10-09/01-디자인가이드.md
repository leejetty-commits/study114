## 2. 셸 (좌측 메뉴 + 본문 머리) — 전 역할

### 2-1. 골격 (위→아래 순서 고정)

```
[좌측메뉴 160] 24 [본문 열 — 아래 전부 폭 100%] [우측 레일 300]

1) 경로          마이페이지 - 구매이력          12 / 400 / #4B5563, 구분자 「-」 #CBD5E1
2) 페이지 제목    구매이력                       28 / 700 / #1C1917 (모바일 ≤640: 22)
   └ 아래 1px #E5E7EB · 패딩 16 · 여백 24
3) 내 공지        soft 머리 (#EEF4FB / #266BC4)  카드 r12, 아래 2px #CBD5E1 (잠금)
4) 탭 바          (탭이 있는 화면만) 14/500      아래 여백 24
5) 안내 1줄       (있는 화면만, 기존 문구) 14 / #4B5563 · 아래 16
6) 섹션카드 스택   카드 사이 16
```

- 본문(탭 본문·폼·목록)에 `max-width`(640·672·720·928 등)를 두지 않는다 → 내 공지·탭 바·카드 오른쪽 끝이 모든 화면에서 같다(±1px).
- 좌측 메뉴 폭 **160 유지**(종현 2026-10-09 (a) — 넓히지 않음). 셸 1280(gutter 32)·레일 300도 현행 유지.
- 페이지 제목은 **메뉴를 옮길 때만 바뀐다.** 같은 메뉴 안에서 행을 펼치거나 하위 화면으로 가도 제목은 그대로(예: 쪽지 행을 펼쳐도 「대화방」으로 바꾸지 않음).

## 4. 화면 문구 규칙 (전 역할)

1. **개발자 용어 화면 노출 절대 금지**: 내부 키(`study_room`, `tutor`, `guest`, `resume`, `pending`, `paid`, `position`, `count`, `badge_addon`), 영문 상품 코드(`PRIME`, `PICK`, `BASIC`, `Prime`), `#12` 같은 내부 번호, `mock`·`데모` 같은 개발 단어. → 05 문서 라벨표대로 한글로.
2. 모르는 키가 와도 원문을 내보내지 않는다 → 중립 한글 대체값(05 문서 「모르는 값」 줄).
3. 용어: **「학생」**(「학부모」 금지), **「게시판」**, **「과외지역」**. 상품명은 **베이직카드 · 픽 · 프라임**(166 잠금).

### 5-1. 범위를 나누는 방법 (코드 구조 때문에 꼭 알아야 함)

- 마크업은 **공용 JS 한 곳**(`mypage/screens.js`, `messages/screens.js`, `provider-reviews/inbox.js`)이 모든 역할 화면을 같이 그린다.
  - 「공부방만」은 **CSS 범위 선택자**(`.home-app--role-study_room …`)로만 가능하다.
  - 구매이력·관심 학생은 공부방·과외쌤에게만 보이므로 마크업을 바꾸면 **공급자 공통**.
  - 쪽지·최근열람·찜·문의·계정설정은 학생도 보므로 마크업을 바꾸면 **전 역할**.
- CSS 불러오는 순서(`src/main.js` L1–40): `tokens`(1) → `home`(2) → `home-member-flows`(3) → `home-admin`(5) → … → `home-provider-reviews`(13) → `design-system`(15) → … → `mypage-ops`(24) → `myshop`(26) → … → `udx-std-apply`(34) → `student-detail`(35) → … → `student-mypage-stage5b`(40). 같은 우선순위면 뒤 파일이 이긴다. **`myshop.css`는 `mypage-ops.css`보다 뒤에 불러오므로**, mypage-ops에서 `.shop`을 덮어쓸 때는 선택자 우선순위가 myshop.css 규칙(모바일 L681–685 포함)보다 높아야 한다. **옛 파일(`home-member-flows.css`, `home-provider-reviews.css`, `home-admin.css`)은 고치지 말고 `mypage-ops.css`에서 마이페이지 범위로 덮어쓰는 것이 원칙**(티켓에 명시된 경우 제외).
