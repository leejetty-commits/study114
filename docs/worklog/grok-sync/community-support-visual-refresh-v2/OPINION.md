# OPINION · 왜 v2가 더 제품처럼 보이는가

v1은 “현장형·조밀한 시안”을 위해 카드 코너 브라켓을 반복했다. 밀도는 생겼지만, 장식이 **제목·한 줄 설명·CTA보다 먼저** 읽혀 포털/광고판 쪽 신호가 섞였다.

v2는 브라켓을 빼고 **Surface + 1px Line + radius 12 + 좌측 엣지 + 아이콘 타일 + soft halo**만 남겼다. 같은 Type B·토큰·GNB인데도, 카드가 “꾸민 목업”이 아니라 **서비스 UI 컴포넌트**처럼 보인다. 히어로의 약한 기하·스트라이프는 페이지 머리만 담당하고, 본문 카드는 장식 경쟁을 하지 않는다.

결과: 관리자 UI보다 풍부하고, v1 장식샷보다 차분하며, 커뮤니티·고객센터 톤(필드 / 헬프 허브)이 장식보다 앞선다.
