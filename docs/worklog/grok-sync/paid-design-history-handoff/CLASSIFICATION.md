# CLASSIFICATION

Judgment labels used in every `SAMPLE.md`:

| Label | Meaning |
|---|---|
| **구현 기준** | Use as implementation / design baseline for the named topic |
| **참고용** | Historical or secondary; useful context; do not prefer over 구현 기준 when overlapping |
| **폐기·주의 필요** | Wrong premise or policy conflict — do not reuse as baseline |
