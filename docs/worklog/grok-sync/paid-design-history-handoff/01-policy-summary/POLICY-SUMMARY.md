# Paid product policy summary (authoritative user brief)

> Condensed from the user brief only. Do **not** invent policy beyond this document.

## A. Axes

- **Paid** = exposure position/expression + message tickets
- Product axes: **노출상품** / **쪽지권**

## B. Basic

- Basic = **free baseline**
- **No UP** (끌어올리기) product

## C. Room (공부방)

- Products: **Prime** / **Pick**
- Badges: **Hot** · **단과**
- **Room Prime ONLY** = **3-slot** inventory / board / waitlist
- **Room Pick** = **5×2 = 10** per page

## D. Tutor (과외쌤)

- Products: **Prime** / **Pick**
- Badges: **Hot** · **쪽집게** · **SKY**
- **Tutor Prime** = **3-per-page circulation** — **NOT** 3-slot stock
- **Tutor Pick** = **10/page**
- Numeric pagination + **15min rotation**
- Tutor samples that reuse room-like sellout / waitlist / fixed slots = **CONFLICT** (discard/warn)

## E. Badges

- Badges are **subordinate** to Prime/Pick for the **same period**
- **SKY** = ad expression, **not** certification

## F. Tickets (쪽지권)

- Tickets = **first proactive message only**
- Follow-ups / replies = **free**
- Packs: **1 / 5 / 10**
- Validity: **120-day** (bundle packs)
- Closed card blocks purchase/use
- Aux entry points: **내 쪽지권** / **쪽지함**

## G. Free tickets from exposure

- Free ticket benefits from exposure products **may coexist** with paid packs
- Auto-use **earliest expiry**
- Do **not** over-feature balance/FIFO on the **purchase page main**

## H. Paid page tone

- Paid page = **independent storefront** tone — **not** mypage settings
- Provisional theme OK
- Do **not** invent a new typography system

## I. Scope limits

- **No** new designs / ops / API / global design-system force
- Curate from **existing artifacts only**
