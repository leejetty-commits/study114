| 요소 | 카피 |
|------|------|
| H1 | 안전이용 |
| 배너 1 | 연락과 거래 전에 꼭 읽어 두면 좋은 안전 이용 안내입니다. |
| 배너 2 | 공식 기준과 신고·분쟁은 고객센터 정책에서 확인할 수 있어요. |
| 섹션 | 이렇게 하세요 · 하지 마세요 |

| Don't | 선입금·외부결제 · 민감정보 · 성급한 외부계약 · 운영문제를 쪽지로 |
| 섹션 | 도움이 필요할 때 |
| 링크 | **운영문의**(강조) · 안전과외 정책 · 신고·도움(`#/support/policies/reporting`) · 고객센터 |
