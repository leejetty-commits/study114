## 공통 규칙

1. **0단계는 진단만 하고 보고한다.** 파일·노션을 고치지 않는다. 보고에 「확인됨 / 다름 / 멈춤 사유」를 적는다.
2. 아래 「허용 파일」 밖은 한 줄도 바꾸지 않는다. 허용 밖이 필요하면 **멈추고 보고**한다.

5. 순서: **Part 1(문서) PR → 머지 → 보고 → Part 2(노션) → 보고.** 한 번에 하나.
6. 마지막에 바뀐 파일 목록이 허용 목록과 같은지 `git diff --name-only`로 확인해 보고한다.
7. force push·reset·rebase로 남의 커밋 덮어쓰기 금지.

**전제:** Cursor가 노션 쓰기 도구를 가지고 있어야 한다. 없으면 멈추고 보고한다. 다른 방법(브라우저 로그인 조작, 토큰 찾기 등)으로 우회하지 않는다.

- 비밀값·이메일 목록·테스트 계정 이메일 금지.
- 「완료」 표시는 코드·PR로 확인된 것만.
