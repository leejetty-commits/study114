## 고칠 내용 (승인 뒤에만)

문장은 실제 HTML 텍스트로 남긴다. 제목·본문을 이미지로 바꾸지 않는다. title·canonical·description·og·기존 h1·h2·본문 문장은 그대로다. **새로 넣어도 되는 글자는 단계 번호(1·2·3, 하위 장은 1–4)뿐이다.** 가격·`#/plans` 링크·외부 CSS·JS·웹폰트·새 이미지 파일은 넣지 않는다. 로고는 기존 `/assets/brand/logo-wordmark-2026.png`만 받는다. 아이콘은 HTML 안 인라인 SVG만 쓴다(파일·요청 없음, `aria-hidden="true"` `focusable="false"`, 한 개당 짧게).

### 1. 로고 중복 제거

소개 히어로 133행 로고 링크를 지운다. 헤더 로고(122행, `alt="우동공과"`)만 남긴다. `.hero .logo` 규칙을 지운다.

### 2. 히어로

소개 히어로 배경을 브랜드 그라데이션으로 바꾼다. 예: `linear-gradient(160deg, #184a88 0%, #266bc4 55%, #1f5ba8 100%)`. 글자색은 흰 글자(`#ffffff`), 리드는 `#eaf2fc`. 안쪽 여백을 늘린다(예: 위 40px, 아래 48px). h1은 더 크게(예: 2rem, 640px 이하 1.6rem).

그라데이션이 파랑이면 지금 파란 「시작하기」버튼이 묻힌다. 히어로 안 주 버튼만 흰 배경·파란 글자(`#266bc4`)로 뒤집어, 버튼이 더 돋보이게 한다. 호버는 `#eaf2fc` 배경·`#184a88` 글자.

하위 3장: 기존 h1을 같은 그라데이션 히어로 안으로 옮긴다. **새 리드 문장과 「시작하기」는 넣지 않는다.** h1 문구는 그대로다.

### 3. 역할 카드 3장 (소개만)

카드 3장은 그대로 통째 링크다. 각 카드에 역할 색 강조(위 또는 왼쪽 4px 색띠, 또는 아이콘 색)와 작은 인라인 SVG를 넣는다.

- 공부방 원장님: `#266bc4`(건물·문 모양)
- 과외쌤: `#0f766e`(사람 모양)
- 학생·학부모: `#6d5bd0`(열린 책 또는 두 사람 모양)

아이콘은 장식이다. 새 대체 텍스트를 만들지 않는다. 호버(그리고 `:focus-visible`)에서 살짝 위로 들리고(`translateY(-2px)`) 그림자가 생긴다. 카드 안 `<strong>`·`<span>` 문장은 바꾸지 않는다.

### 4. 이용 순서 번호 카드

소개 `.steps` 세 항목을 단계 카드로 만든다. 각 항목 왼쪽에 원형 숫자 1·2·3, 오른쪽에 기존 라벨. 숫자는 CSS `counter`여도 되고, `<span class="step-num" aria-hidden="true">1</span>`이어도 된다. `list-style`만 끄고 숫자를 빼 두지 않는다.

- 데스크톱(641px 이상): 세 카드가 한 줄(가로).
- 640px 이하: 한 줄에 하나씩 쌓인다.

공부방·과외쌤 「등록 순서」의 기존 4항목 `<ol>`에도 같은 원형 번호 카드 처리를 한다(번호 1–4, 문장 그대로). 앞뒤 설명 문단은 패널에 남긴다. 학생·학부모 장에는 단계 카드를 새로 만들지 않는다.

### 5. 하단 「화면으로 이동」버튼 정리

소개 페이지:

- 버튼으로 남기는 것: **회원가입** (주 버튼 `.btn--strong`), **로그인** (보조 버튼 `.btn--line`).
- 나머지 6개(공부방 찾기, 과외쌤 찾기, 공부방 등록 안내, 과외쌤 등록 안내, 고객센터, 카카오톡 문의)는 **글자 링크**로 바꾼다. 한 줄 링크 묶음(`.text-links` 등). 1440에서는 한 줄, 375에서는 줄바꿈하되 가로로 넘치지 않게 한다. href·카카오 새 탭 속성은 그대로다.
- 칸 제목·안내 문단은 그대로다.

하위 3장: 같은 방식으로 버튼을 줄인다. 다만 **그 장의 주 이동은 버튼으로 남긴다.**

- 공부방: 「공부방 등록 안내」주 버튼, 회원가입 주 버튼, 로그인 보조 버튼. 「공부방 찾기」·「서비스 소개」·고객센터·카카오톡 문의는 글자 링크.
- 과외쌤: 「과외쌤 등록 안내」주 버튼, 회원가입 주 버튼, 로그인 보조 버튼. 「과외쌤 찾기」·「서비스 소개」·고객센터·카카오톡 문의는 글자 링크.
- 학생·학부모: 「공부방 찾기」주 버튼, 「과외쌤 찾기」보조 버튼, 회원가입 주 버튼, 로그인 보조 버튼. 「서비스 소개」·고객센터·카카오톡 문의는 글자 링크.

### 6. 공통

인라인 `<style>`만 수정·추가한다. 네 장 디자인 틀(헤더·내비·히어로 색·푸터)은 맞춘다. 쓰지 않는 선택자(하위 장의 `.cards` 등)는 지워 용량을 줄여도 되고, 남겨도 된다. 각 HTML이 16KB를 넘으면 아이콘·CSS를 줄인다. 문장을 지우거나 줄여 맞추지 말고, 그래도 넘으면 멈추고 보고한다.
