# 마이페이지 디자인 가이드 초안 (Cursor용)

**상태:** 초안 + **UI 1차 적용** (`preview/home-ui/src/styles/mypage-ops.css`, 2026-07-31)  
**범위:** `#/mypage/*` 운영 허브 화면군만 (상품센터·랜딩·검색 메인은 후속)  
**기준 보드:** Visily presenter · 프레임 1280  
**코드 토큰:** `preview/home-ui/src/styles/tokens.css`  
**IA 정본:** `docs/ssot/15-mypage-structure.md` · `docs/internal/visily-page-prompts.md`

> 목적: “예쁘게”가 아니라 **깔끔함 · 가독성 · 정돈감 · 구현 가능성**.  
> Visily 초안의 장점(여백·위계·플랫 카드·절제된 강조)을 우리 서비스 운영 허브에 고정한다.
>
> **1차 적용:** 샵형(크림/오렌지) 톤을 `mypage-ops.css`로 덮어씀. accent=`--brand-blue`. 홈 히어로 장식 제거 · 사이드바 160 · 타이포 24/18/16/14/12 스코프.

---

## 1. 톤 한 줄 정의

**밝고 정돈된 개인 운영 허브 UI** — 관리자 콘솔처럼 딱딱하지 않고, 마케팅 랜딩처럼 과장되지 않으며, 정보량이 있어도 스캔·행동이 빠른 업무형 화면.

## 2. 1280 기준 레이아웃 원칙

### 2-1. 고정값 (1차 잠금 후보)

| 항목 | 값 | 코드/비고 |
|------|-----|-----------|
| 콘텐츠 max-width | **1280px** (`80rem`) | `--home-max` 와 동일 ✅ |
| 좌우 gutter | **32px** (`2rem`) | `--page-gutter` ✅ |
| 좌측 mypage 사이드바 | **160px** (`10rem`) | `--sidebar-width` ✅ |
| 우측 프로모/레일 | **192px** (`12rem`) · 필요 시만 | 홈/지원과 동일 토큰 |
| 본문 가용폭 (사이드바+양측 패딩 제외) | **약 1056px** | `1280 − 160 − 32 − 32` |
| 마이페이지 **콘텐츠 헤더** 높이 | **64px** 권장 | Visily. 사이트 전체 GNB(`--site-header-h: 4.75rem`)와 **별개** |
| 프레임 높이 가이드 | 960~1024px | 와이어/프레젠터용 · 실서비스는 스크롤 |

### 2-2. 구조

```
[사이트 헤더: util + GNB]          ← 전역 크롬 (기존 유지)
└─ [마이페이지 셸 1280]
   ├─ 사이드바 160          본문 (나머지)
   │  · 로고/허브명           · (선택) 브레드크럼 · 페이지 툴바
   │  · 계정 요약 1줄         · 페이지 타이틀
   │  · MYPAGE_NAV            · 섹션들 (카드/리스트)
   └─ footer (사이트 공통)
```

### 2-3. 레이아웃 규칙

1. **사이드바는 운영 허브의 고정 축**이다. 화면마다 메뉴 폭·순서를 바꾸지 않는다.
2. **본문은 1056px 안에서만** 그리드를 짠다. 카드가 화면 밖으로 “퍼지는” 느낌을 금지.
3. **열 수:** 통계/바로가기 기본 **2열**, 여유 있을 때만 3~4열. 1280에서 3열 이상은 카드가 답답해지기 쉬움 → Visily 권고와 동일.
4. **섹션 세로 간격:** 24px(관련 블록) / 32px(큰 구획).
5. **카드 간격:** 가로·세로 16px 또는 24px (한 화면 안에서 하나로 통일).
6. 우측 레일은 **홈·고객센터와 공유할 때만**. 쪽지 스레드·계정 폼처럼 집중이 필요한 화면은 레일 생략 가능.
7. 안전 영역: 좌우 32 · 상단 24 · 하단 24~32.

### 2-4. 기존 토큰과의 차이 (구현 시 결정 필요)

| 항목 | 현재 `tokens.css` | Visily/본 가이드 | 권장 |
|------|-------------------|------------------|------|
| 페이지 타이틀 | `--fs-6` = **28px** | **24px** | 마이페이지 셸만 `24px` 오버라이드 |
| 섹션 타이틀 | `--fs-5` = **22px** | **18px** | 마이페이지 `18px` |
| 카드 제목 | `--fs-4` = **18px** | **15~16px** | 마이페이지 `16px` |
| 본문 | `--fs-3` = **16px** | **14px** | 마이페이지 정보 UI는 `14px` 기본 |
| radius | sm/md/lg (6/10/14px) | 칩8 · 버튼10 · 카드12 | 마이페이지 컴포넌트에 매핑 |
| header | util+GNB ~76px | 콘텐츠 툴바 64px | **둘 다 유지** (역할 분리) |

→ **사이트 전역 토큰을 당장 깨지 말고**, `.mypage-*` / `.home-app` 범위에서 마이페이지 스케일을 적용하는 방향이 안전하다.

## 3. 타이포 계층 가이드

폰트: **Pretendard** (`--font-sans`). 마이페이지 본문에서 serif 혼용 금지.

| 단계 | 용도 | 크기 | weight | line-height | CSS 제안 |
|------|------|------|--------|-------------|----------|
| T1 | 페이지 타이틀 | 24px | 700 | 32px | `.mypage-title` |
| T2 | 섹션 타이틀 | 18px | 700 | 26px | `.mypage-section-title` |
| T3 | 카드 제목 · 리스트 핵심 | 16px | 600~700 | 24px | `.mypage-card-title` |
| T4 | 본문 · 버튼 · 입력 | 14px | 400~500 | 20~22px | `.mypage-body` |
| T5 | 보조 · 메타 | 12~13px | 400 | 18px | `.mypage-meta` |
| T6 | 캡션 · 라벨 · 배지 | 12px | 500~600 | 16px | `.mypage-caption` |

**규칙**

- 한 화면에서 T1은 **1개**.
- T2는 섹션당 1개. 카드마다 T2를 쓰지 않는다.
- 숫자 강조(통계)는 T1~T2 크기 허용, 색은 포인트 1색 + 중립.
- 링크·CTA 텍스트도 T4(14px) 유지. 버튼만 크게 키우지 않는다.

## 4. 카드 · 버튼 · 입력 · 탭 공통 규칙

### 4-1. 카드 / 패널

| 항목 | 값 |
|------|-----|
| radius | **12px** |
| border | **1px solid #E5E7EB** (또는 `--gray-200`) |
| shadow | 기본 **없음**. 필요 시 `0 1px 2px rgba(0,0,0,0.04)` |
| 배경 | 카드 `#fff` · 페이지 배경 `#F8FAFC` / `#F4F6F8`(`--surface-section`) |
| 패딩 | 리스트형 16 · 통계형 16~20 |
| 통계 카드 높이 | 88~104px |
| 내부 위계 | **제목 → 메타 → 상태 → 액션** 고정 순서 |

카드 안 정렬:

- 제목↔메타 **6px**
- 제목/본문↔액션 **12px**
- 상태 배지는 제목 옆 또는 카드 상단 우측 — **한 위치로 통일**

금지: 카드마다 다른 radius/shadow/그라데이션 헤더.

### 4-2. 버튼

| 종류 | 높이 | 패딩 L/R | 텍스트 | radius |
|------|------|----------|--------|--------|
| Primary | **40px** | 14~16px | 14px / 600 | **10px** |
| Secondary | 36~40px | 14~16px | 14px | 10px |
| Small / 행 액션 | 28~32px | 10~12px | 12~13px | 8~10px |

- 아이콘 16px · 아이콘-텍스트 6px.
- **한 섹션 primary CTA는 1~2개**. 나머지 secondary/text.
- 위험 액션(삭제)만 적색 텍스트/아이콘. 화면 전체를 빨강으로 채우지 않음.

### 4-3. 입력 / 검색

| 항목 | 값 |
|------|-----|
| input / search 높이 | **40px** |
| textarea 기본 | 96px |
| 내부 패딩 | 12px 14px |
| placeholder | 14px · `--gray-400` |
| radius | 10px |
| border | 1px `#E5E7EB` |

### 4-4. 탭

| 항목 | 값 |
|------|-----|
| 탭 높이 | 40px |
| 탭 간격 | 16~20px |
| 활성 | 하단 2px 포인트 컬러 underline + weight 600 |
| 비활성 | `--gray-500` |

탭 밑에 또 다른 필터 칩이 있으면 **한 줄로**, 장식 배경 박스 금지.

## 5. Spacing · Radius · Border · Shadow

### Spacing 토큰 (마이페이지 고정)

`4 / 8 / 12 / 16 / 24 / 32`  
(`tokens.css`의 `--space-1~8`에 매핑: 4=1, 8=2, 12=3, 16=4, 24=6, 32=8)

| 용도 | 값 |
|------|-----|
| 아이콘-텍스트 | 8 |
| 카드 내부 세부가로 | 12 |
| 컴포넌트 기본 간격 | 16 |
| 섹션/카드 그리드 | 24 |
| 큰 구획 | 32 |

### Radius

| 요소 | px |
|------|-----|
| 칩·배지 | 8 (pill은 height에 맞춤) |
| 버튼·input | 10 |
| 카드·패널 | 12 |
| 빈상태/팁 박스 | 12~16 |

### Border / Shadow

- 구분의 **border 1px**.
- shadow는 거의 쓰지 않음 (운영 허브 = 플랫).
- 호버: 배경 4~6% 톤 변화 또는 border 진하기 한 단계. 큰 lift 금지.

## 6. 색 · 상태 · 아이콘

### 색 역할

| 역할 | 사용 |
|------|------|
| 페이지 배경 | 아주 연한 중립 (`--surface-section` / `#F8FAFC`) |
| 패널 | `#fff` |
| 텍스트 | `--gray-900` / `--gray-600` / `--gray-500` |
| 포인트 | CTA · 활성 탭 · 핵심 수치 **만** (브랜드 블루 또는 Visily 틸 중 **서비스 1색으로 통일** — 구현 전 브랜드 `#2b7fff` vs 틸 최종 선택) |
| 시맨틱 | 성공 녹 · 경고 주황 · 위험 적 — 배지·상태열에만 |

**금지:** 섹션마다 다른 포인트색 · 큰 그라데이션 히어로(랜딩형) · 카드마다 다른 틴트 헤더.

> Visily 초안에 틸/스카이 블루가 섞여 있다. **마이페이지 1차 구현 전 accent 1색을 확정**할 것. 권장: 사이트 브랜드 `--brand-blue` 유지 + 상태색만 시맨틱.

### 상태 배지

- 높이 20~24px · 텍스트 12px · 텍스트+약한 배경(+필요 시 점).
- 색만으로 의미 전달 금지 (반드시 라벨).

### 아이콘

- 사이드바 20 · 유틸 18 · 카드 16~18.
- **outline 기본**. filled는 활성/찜 ON 등 예외만.
- 장식용 거대 아이콘 금지.

## 7. 화면별 공통 적용 원칙

메뉴 정본: `MYPAGE_NAV` (`mypage/router.js`).

### 7-1. 마이페이지 홈 `#/mypage/home`

- 상단: 짧은 인사/역할 요약 **또는** 숫자 요약 — 둘 다 크게 쓰지 말고 **하나 중심**.
- 숫자 카드 2~4개 · 높이 88~104 · 2열 우선.
- 바로가기는 아이콘+라벨 그리드. 마케팅 배너형 히어로 최소화.
- 역할별 카드 세트가 다름(학부모 vs 공급자) — 레이아웃 골격은 동일.

### 7-2. 내 등록 허브 `#/mypage/registrations…`

- 상태판(공개/상세완료/노출) + 카드 리스트.
- 카드: 제목 · 상태 배지 · 메타(갱신일) · **액션 1~2**.
- “이용 중/만료” 같은 SaaS 구독 카드 문법을 쓰되, **우리 도메인 용어**(공개·상세등록·노출)로 치환.
- 검색 결과형 이미지 카드보다 **운영 카드**가 기본.

### 7-3. 쪽지함 `#/mypage/messages…`

- 스캔 우선: 탭 → 리스트(행 56~64px) → (와이드면) 스레드 패널.
- 읽지 않음 = 점/볼드. 장식 일러스트 최소.
- primary CTA는 「새 쪽지」 정도 1개.
- 유료 게이트는 **오버레이** (페이지 재발명 ✕).

### 7-4. 찜 · 최근 · 관심 학생

- 찜/최근: 리스트 또는 2열 카드. 비교는 찜만.
- **관심 학생 ≠ 학생찾기**. 탐색 히어로·지도 넣지 않음.
- 일괄 선택/삭제가 있으면 툴바는 얇게(40px 이하).

### 7-5. 이용 현황 `#/mypage/plans` (+ my / history)

- 상태 요약 → 티어/이용권 설명 → CTA 줄.
- CTA: **내 상품 · 결제내역 · 추가 이용** — primary는 1개, 추가는 secondary.
- 차트·성장률 대시보드는 **1차 범위 밖**(Visily 장식 과다 시 제거). 필요하면 단순 progress 1개.
- 구매 UI는 `#/plans`로만.

### 7-6. 계정 설정 `#/mypage/account`

- 프로필 헤더(사진·이름·역할) + 탭(프로필/보안/알림 등) + 폼 2열.
- 저장 primary 1 · 로그아웃 secondary.
- 소셜 연결은 행 리스트(아이콘·상태·연결/해제).

## 8. 실무형 디자인 원칙 10개

1. **운영 허브 톤 고정** — 랜딩 히어로·세일즈 그라데이션을 mypage에 가져오지 않는다.  
2. **1280 한 폭** — 사이드바·본문·카드 그리드가 같은 max-width 체계를 쓴다.  
3. **위계 6단만** — 24/18/16/14/12(+캡션). 중간 크기를 임의로 추가하지 않는다.  
4. **카드 문법 통일** — 제목→메타→상태→액션. 예외 카드는 문서에 이유를 남긴다.  
5. **플랫 + 1px border** — shadow로 깊이 만들지 않는다.  
6. **포인트색 절제** — CTA·활성·핵심 수치 외 색 사용 금지.  
7. **CTA 예산** — 뷰포트당 primary 1~2. 나머지는 text/secondary.  
8. **스캔 우선** — 쪽지·등록·이용현황은 장식보다 행 높이·배지·정렬.  
9. **역할은 콘텐츠만 바꾸고 골격은 유지** — 학부모/공부방/과외가 메뉴·카드 세트만 다름.  
10. **토큰으로 구현** — 하드코딩 px 남발 금지. mypage 스코프 변수로 기존 `tokens.css`에 얹는다.
