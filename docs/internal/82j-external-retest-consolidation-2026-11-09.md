**대상:** Study114 (`study114.net`)  
**입력:** ChatGPT `82g` · Gemini `82h` · Genspark `82i` · 지시문 `82f` · 1차 취합 `82d` · 공동 `329`  
**방법:** 저강도·1회성·테스트 계정/코드 미제공(**A**) · 조치 후 재검증  
**상태:** ✅ 3곳 원본·요약 반영

## 0. 쉬운 말 결론 (브리핑용)

1. **Critical/High 「재현」은 3곳 모두 0.** 1차에서 확실했던 HTTP→HTTPS 미강제는 Genspark·Gemini 기준으로 **해소**.  
2. **가장 믿을 만한 실측은 Genspark.** HTTPS 301, HSTS·nosniff·X-Frame, CSP Enforce, `/api/admin` 403, 번들·`.env` 폴백까지 숫자·헤더로 적음.  
3. **ChatGPT는 도구가 사이트 HTTP를 못 읽어** 전부 「미확인」— 실패가 아니라 **검증 불능**. 완료 인증에 쓰지 말 것.  
4. **Gemini는 「해소」를 많이 찍었으나** OAuth·IDOR까지 해소로 쓴 부분은 과장 가능. Genspark가 미확인인 항목은 **미확인/내부완료**로 읽는다.  
5. **새로 남은 Medium 1건(Genspark):** CSP `script-src`에 `'unsafe-inline'` — XSS 완화 효과 약화. **후순위**(nonce 전환).  
6. **유튜브 직전 권장 스모크 2개:** `/#/admin` 게스트 화면 · 지도(CSP) 브라우저 1회. High 필수는 아님.  
7. **후속 B:** 테스트 계정 후 IDOR 교차 · (선택) return_to/state/cron/MIME은 내부 이미 한 것과 대조.

## 3. 조치 후 좋아진 점 / 남은 점

### 좋아진 점

1. HTTP→HTTPS 강제 · HSTS · nosniff · X-Frame — **외부 실측으로 해소**  
2. `/api/admin/*` 미인증 403·민감 JSON 미노출  
3. CSP Enforce · `.env`/`.git` 홈 폴백 · 공개 번들 시크릿 없음  

### 남거나 새로 본 점

1. CSP `'unsafe-inline'` 잔존 (Medium · 후순위)  
2. `/#/admin` UI·지도는 브라우저 스모크 1회씩 권장  
3. OAuth·cron·IDOR·MIME은 외부 A로는 미확인 → 내부 완료분 + **후속 B**  

### 홍보 전

| 구분 | 내용 |
|------|------|
| 필수(재현 High) | **없음** |
| 직전 권장 | `/#/admin` 게스트 UI · 지도 CSP 브라우저 스모크 |
| 후순위 | `'unsafe-inline'` 제거(nonce) · 유튜브 배너 · git purge · **후속 B** IDOR |
