# Visily 지시문 — 사이트 전체 레이아웃 (마이페이지 제외)

**용도:** Visily 붙여넣기(3800자 이내). 톤은 마이페이지와 동일 계열.  
**제외:** `#/mypage/*` · 타이포/카드 내부 마이크로 스펙(2차)

---

## Visily에 붙여넣을 본문

```
우동공과(Study114) 데스크톱 UI 레이아웃 초안. 동네 공부방·과외 탐색/등록 플랫폼. 탐색·비교·쪽지·자기공개(매칭중개·에스크로 아님).

목표: 마이페이지(운영형·밝은·가독)와 같은 톤으로, 마이페이지 밖 화면만 통일. 여백·밝은 배경·위계·카드/섹션 덩어리 우선. 폰트px·카드 내부 포맷은 2차로 미룸. #/mypage/*는 그리지 말 것(홈·내등록·찜·관심학생·쪽지함·이용현황·계정설정).

공통: 1280px · 좌우~32px · util+GNB(홈/공부방찾기/과외쌤찾기/학생찾기/공부방상세등록/과외쌤상세등록/유료상품/고객센터). 학부모:상세등록·유료상품 숨김 / 공부방:과외찾기·과외등록 숨김 / 과외:공부방찾기·공부방등록 숨김. 탐색화면은 본문+우측레일~192px, 인증·결제·등록은 레일 없음. 연한중립 배경·흰 카드·플랫(보더 약함·shadow 최소)·장식배지/그라데이션 금지. CTA·활성탭만 강조. 여백·그리드 리듬 통일.

톤: bright·clean·readable·quiet accent. 홈/검색=탐색 · 상세=오버레이 · 인증/등록=폼 · 유료상품=판매 · 고객센터/자료실=안내 · 관리자=내부콘솔(승인·반려 금지).

금지: 마이페이지 재작성 · 타이포/카드 마이크로스펙 · 퀵매칭 · 안전과외 독립GNB · 알림센터 · 상세 풀페이지 · 학부모 유료구매 · 에스크로/매칭보장 연출.

화면(한 세트·헤더·여백·카드톤 통일):
A홈: 비회원(히어로+노출+리스트+가입) · 학부모(탭+필터/리스트+비교바) · 공부방/과외(내노출+학생탭, 역할홈≠마이페이지)
B검색: 공부방찾기(필터+지도|리스트) · 과외찾기(필터+결과·비교/찜) · 학생찾기(수요요약·비교없음·쪽지/저장)
C오버레이: 상세모달(Trust/본문/쪽지CTA) · 비교바·표(최대3·학생비교없음)
D인증: 로그인 · 회원가입 대표2~3컷(약관→역할→계정→기본등록→완료)
E등록: 공부방/과외 위저드(기본→상세·스텝폼)
F상품(#/plans, 이용현황≠): 상품홈(서브nav) · 노출상품 · 접근권(쪽지/열람) · 결제결과. 학부모GNB없음
G안내: 고객센터(좌nav) · 안전과외가이드(하위) · 자료실(GNB밖)
H선택: 관리자 콘솔1컷

혼동금지: 이용현황·쪽지함·관심학생=마이페이지(미포함) / 유료상품GNB=#/plans / 학생찾기=검색.
키워드: same family as mypage · flat · scannable · 1280. 마이페이지 샷은 톤만 참고·복제금지. 타이포러프OK, 레이아웃골격·성격구분 선명하게.
```
