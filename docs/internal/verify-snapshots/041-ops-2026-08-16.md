| 관찰 | 값 |
|------|-----|
| tutor latest/recommend/sky/review total | **0** |
| room latest total | **1** (노출 조건 통과 row 존재) |

**중간 결론 (SQL 원문 대기):**
- 정렬 코드 500/화이트리스트 문제는 아님 (tutor API 200, sort 필드 정상).
