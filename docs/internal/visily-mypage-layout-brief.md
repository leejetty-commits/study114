# Visily 지시문 — 마이페이지 전 영역 레이아웃 톤 통일 (1차)

**용도:** Visily에 붙여넣어 마이페이지 화면군 전체의 **레이아웃·분위기 초안**을 받기 위함.  
**범위:** `#/mypage/*` 운영 허브만 (상품센터 `#/plans` 카탈로그·랜딩·검색 메인은 이번 제외).  
**목표:** 이미 마음에 든 Visily 마이페이지 초안의 **깔끔·가독·운영형 분위기**를 전 화면으로 통일.

---

## Visily에 붙여넣을 본문

```
우동공과(Study114) 마이페이지 운영 허브의 데스크톱 와이어/UI 초안을 그려줘.

[이번 단계의 목표]
이미 잡아 둔 마이페이지 초안의 “깔끔하고 가독성 좋은 운영형” 분위기를 기준으로,
마이페이지 전 영역(홈·내 등록·찜/최근/관심학생·쪽지·이용 현황·계정)의 레이아웃 톤을 통일한다.
세부 타이포 스케일, 카드 내부 정보 포맷(필드 배치·배지 규칙·버튼 패딩 등)은 이번 단계에서 과하게 고정하지 말고 제외한다. 그건 2차에서 정리한다.

[화면 성격]
- 개인이 쓰는 “운영 허브”다. 관리자 콘솔처럼 딱딱하지 말고, 마케팅 랜딩처럼 과장하지 말 것.
- 정보량이 있어도 답답하지 않게, 여백과 정돈된 위계로 읽기 쉽게.
- 신뢰감 있는 업무형 UI. 밝고 정돈된 느낌.

[레이아웃 고정값 — 이번 단계에서 지킬 것]
- 데스크톱 프레임 폭: 1280px
- 구조: 좌측 사이드바(약 160px) + 본문
- 좌우 바깥 여백: 약 32px
- 본문은 사이드바 옆에서 넓게 쓰되, 화면 밖으로 퍼지지 않게
- 페이지 배경은 아주 연한 중립 회색, 카드/패널은 흰색으로 은은히 분리
- 보더·그림자는 최소한(플랫에 가깝게). 과한 shadow/그라데이션 금지
- 강조색은 CTA·활성 메뉴·핵심 상태 정도만. 화면 전체가 색으로 시끄럽지 않게
- 섹션 간 여백을 충분히 두어 “숨 쉴 공간”이 보이게
- 카드가 많아도 그리드/리스트가 한 규칙으로 정렬되어 보이게

[이번 단계에서 하지 말 것]
- 폰트 크기 체계(24/18/16…)를 화면마다 세밀하게 규정하지 말 것
- 카드 내부의 필드 순서·배지 크기·아이콘 px·버튼 높이 등 마이크로 스펙을 고정하지 말 것
- 화려한 히어로 일러스트, 큰 그라데이션 배너, 대시보드형 차트 남발
- 상품 구매 카탈로그·검색 메인·랜딩을 마이페이지 안에 섞어 그리지 말 것
- 승인/반려 같은 관리자 심사 UI 연출 금지

[공통 골격 — 모든 마이페이지 화면에 동일 적용]
1) 상단: 사이트 공통 헤더가 있다고 가정(얇은 util + GNB). 본 작업은 그 아래 마이페이지 셸에 집중.
2) 좌측 사이드바: 허브명 + 로그인 사용자 요약 + 메뉴(마이페이지 홈 / 내 등록 / 찜·최근 또는 관심 학생(역할별) / 쪽지 / 이용 현황 / 계정 설정)
3) 본문 상단: 브레드크럼(가볍게) + 페이지 제목
4) 본문: 섹션 단위로 카드/리스트. 한 화면에서 카드 스타일·여백 리듬이 같게.

[역할]
- 학부모: 찜·최근·쪽지 중심. 관심 학생 메뉴 없음.
- 공부방/과외쌤: 내 등록·관심 학생·쪽지·이용 현황 중심. (관심 학생 ≠ 학생찾기 탐색 화면)

[그려줄 화면 세트 — 레이아웃 톤 통일용]
각 화면은 1280 폭, 같은 사이드바 골격으로.

1. 마이페이지 홈
   - 짧은 인사/요약 영역(과장된 마케팅 히어로 금지)
   - 상태 요약 카드 묶음(2열 권장)
   - 바로가기 카드 묶음
   - CTA는 적게(1~2개 중심)

2. 내 등록 허브
   - 등록 현황/상태 요약
   - 등록 항목 카드 또는 리스트(운영용)
   - 상세·공개·노출 등 다음 행동으로 이어지는 구조

3. 찜 목록 / 최근 본 항목
   - 탭 또는 구분으로 찜 vs 최근
   - 리스트 또는 2열 카드. 스캔이 쉬운 배치
   - 탐색(검색) 화면처럼 지도·필터 패널을 크게 넣지 말 것

4. 관심 학생 (공급자)
   - 저장한 학생 의뢰 운영 목록
   - 학생찾기/지도 탐색 UI로 그리지 말 것
   - 쪽지 준비로 이어지는 레이아웃

5. 쪽지함
   - 탭(받은/보낸/진행 등) + 리스트
   - 가능하면 리스트+읽기 영역 2단(넓을 때). 장식보다 읽기 구조
   - 고객센터 문의 폼과 혼동하지 말 것

6. 이용 현황
   - 이용권/상태 요약 + 설명 블록
   - 다음 행동: 내 상품·결제내역·추가 이용(상품센터로 나가는 느낌의 버튼)
   - 복잡한 차트 대시보드는 넣지 말 것(1차)

7. 계정 설정
   - 프로필 요약 + 설정 섹션(폼/리스트)
   - 저장 CTA는 절제

[시각 톤 키워드]
bright · clean · operational hub · generous whitespace · flat cards · quiet accent · readable scan · no marketing hero

[산출물]
위 7개 화면을 같은 레이아웃 시스템으로 한 세트. 화면마다 분위기가 제각각이면 안 된다.
세부 폰트/카드 내부 스펙은 러프해도 된다. 대신 “여백·골격·카드 덩어리·정보 배치의 정돈감”이 한눈에 같아야 한다.
```

---

## 사용 팁

1. Visily에 **위 코드블록 전체**를 넣고, 가능하면 마음에 든 기존 마이페이지 스크린샷 1~2장을 레퍼런스로 첨부한다.  
2. “카드 내부 포맷·폰트 수치 고정하지 말고 레이아웃 톤만”을 한 번 더 강조해도 좋다.  
3. 결과물이 나오면 Cursor에는 **화면 스크린샷 + 이 지시문**을 주면, 2차(타이포·카드 내부) 전에 레이아웃 검수만 하면 된다.
