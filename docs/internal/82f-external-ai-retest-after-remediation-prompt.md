## Study114 보안 재점검 지시문 (조치 후 · 외부 AI용)

### 0. 이번 점검은 「1차 점검의 후속 재검증」이다

- **1차(2026-11-08):** 공개·저강도 점검에서 Critical 재현 0, High 재현은 HTTP→HTTPS 미강제 등이었다.
- **이후 운영자 조치(요약 — 시크릿 값 요구 금지):**
  1. Cloudflare **Always Use HTTPS** 적용 → `http://` 는 HTTPS로 301 되어야 함
  2. **HSTS**(약 6개월·includeSubDomains·preload 없음) · `X-Content-Type-Options: nosniff` · `X-Frame-Options: SAMEORIGIN` 적용 (CSP 전체는 후순위일 수 있음)
  3. `/#/admin` 비로그인 시 운영자 전용 게이트 · `/api/admin/*` 미인증 401
  4. 세션 쿠키 `Secure` · `HttpOnly` · `SameSite=Lax` (관찰 가능 시)
  5. OAuth `return_to` 살균 · 로그인/소셜 rate limit · cron 키 필수 · 스토리지 서명 시크릿 (기존 잠금 유지)
  6. **[승인자가 5·6 완료 후 채움]** 추가 조치: _______________________
     - 예: 관리 API 인가 보강 / IDOR 수정 / OAuth state 확인 / CSP 일부 / 업로드 검증 / 기타

**목적:** 위 조치가 **실제로 관찰되는지**, 1차에서 지적한 항목이 **해소·잔존·신규**인지 표로 보고.  
**목적 아님:** 공격 자동화, DoS, 실키 요구, 데이터 파괴, 공개 제보.

### 1. 반드시 지킬 규칙 (1차와 동일 · 강화)

1. DoS·초당 대량·전체 크롤·로그인 무한 시도 금지  
2. sqlmap·nuclei 등 자동 침투 도구 금지  
3. 파괴·타인 계정·시크릿 값 요구/출력 금지  
4. 테스트 계정 없으면 로그인 이후 심층 테스트 금지  
5. 「추정」과 「재현됨」구분 · 환각 금지  
6. Rate limit: 한도 **직전만**, 차단 시 즉시 중단  
7. 결과 비공개 보고서만

**요청 상한:** 동일 엔드포인트 분당 10회 미만 · 전체 약 1시간 이내.

### 2. 재검증 체크리스트 (우선 · 반드시 표에 넣을 것)

각 항목에 **기대(조치 후)** vs **실제 관찰** vs **판정(해소/잔존/미확인/악화)** 를 적을 것.

| ID | 재검증 항목 | 기대(조치 후) | 권장 확인 방법(저강도) |
|----|-------------|---------------|------------------------|
| R1 | HTTP→HTTPS | `http://study114.net/` → 301/302 → `https://…` | HEAD/브라우저 |
| R2 | HSTS | `Strict-Transport-Security` 존재(max-age>0) | 응답 헤더 |
| R3 | nosniff | `X-Content-Type-Options: nosniff` | 응답 헤더 |
| R4 | 클릭재킹 완화 | `X-Frame-Options: SAMEORIGIN` 또는 CSP frame-ancestors | 응답 헤더 |
| R5 | CSP | 있으면 보고, 없으면 Info·후순위 (필수로 실패 처리하지 말 것 — 도입 여부는 운영 정책) | 응답 헤더 |
| R6 | www·dothome → apex | 정본으로 정규화 유지 | 리다이렉트 관찰 |
