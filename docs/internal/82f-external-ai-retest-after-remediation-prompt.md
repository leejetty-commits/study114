## Study114 보안 재점검 지시문 (조치 후 · 외부 AI용)

### 0. 이번 점검은 「1차 점검의 후속 재검증」이다

- **1차(2026-11-08):** 공개·저강도 점검에서 Critical 재현 0, High 재현은 HTTP→HTTPS 미강제 등이었다.
- **이후 운영자 조치(요약 — 시크릿 값 요구 금지):**
  1. Cloudflare **Always Use HTTPS** 적용 → `http://` 는 HTTPS로 301 되어야 함
  2. **HSTS**(약 6개월·includeSubDomains·preload 없음) · `X-Content-Type-Options: nosniff` · `X-Frame-Options: SAMEORIGIN` 적용
  3. `/#/admin` 비로그인 시 운영자 전용 게이트 · `/api/admin/*` 미인증 401
  4. 세션 쿠키 `Secure` · `HttpOnly` · `SameSite=Lax` (관찰 가능 시)
  5. OAuth `return_to` 살균 · 로그인/소셜 rate limit · cron 키 필수 · 스토리지 서명 시크릿 (기존 잠금 유지)
  6. **추가 조치(2026-11-08~09 완료):**
     - 관리 API 인가 보강(비로그인 401 · 일반 사용자 「운영자 전용」)
     - IDOR 선별 수정(설정 URL 교차 · 쪽지 소유권)
     - OAuth `state` CSRF 검증(네이버 포함 · `hash_equals`)
     - DOM XSS 선별 · 속성 이스케이프 보강
     - `.env` 등 민감 경로 SPA 폴백 → 홈 HTML만, 비밀 미노출
     - **쪽지 첨부** 서버 MIME(`finfo`)·확장자 일치·PDF/이미지 검증(악성 실파일 업로드 금지)
     - **CSP Enforce** 전환(네이버 지도·지오코딩 `maps.apigw.ntruss.com` 허용 포함). Report-Only는 제거됨
     - git 히스토리 옛 시크릿 blob은 **조사만** · 히스토리 purge 안 함 · **키는 재발급 완료**(시크릿 값·옛 키 추출·출력 금지)

**목적:** 위 조치가 **실제로 관찰되는지**, 1차에서 지적한 항목이 **해소·잔존·신규**인지 표로 보고.  
**목적 아님:** 공격 자동화, DoS, 실키 요구, 데이터 파괴, 공개 제보.

**승인자:** Study114 운영자  
**재점검 기간:** 2026-11-09 ~ 2026-11-16  
**1회성:** 한 플랫폼에 한 번. 동시·반복 대량 점검 금지.

### 1. 반드시 지킬 규칙 (1차와 동일 · 강화)

1. DoS·초당 대량·전체 크롤·로그인 무한 시도 금지  
2. sqlmap·nuclei 등 자동 침투 도구 금지  
3. 파괴·타인 계정·시크릿 값 요구/출력 금지  
4. 테스트 계정 없으면 로그인 이후 심층 테스트 금지  
5. 「추정」과 「재현됨」구분 · 환각 금지  
6. Rate limit: 한도 **직전만**, 차단 시 즉시 중단  
7. 결과 비공개 보고서만  
8. **악성 파일·위장 확장자 실업로드 금지** (업로드는 공개 UX·응답 코드 관찰·추정만)  
9. git 히스토리에서 옛 키를 **찾아내거나 출력하지 말 것** (운영 정책상 purge 안 함·재발급 완료로 처리)

**요청 상한:** 동일 엔드포인트 분당 10회 미만 · 전체 약 1시간 이내.

|----|----------------------|---------------|------------------------|
| R20 | 관리 API 인가 | 미인증 `/api/admin/*` → 401/403. 관리 목록 JSON 미노출 | GET 소수 |

| R23 | DOM XSS 선별 | 공개 페이지에 반사형 스크립트 실행 **재현 없음**(추정은 구분) | URL 파라미터·공개 입력 소수 |

### 3. 작업 방식

1. 공개 HTTPS 페이지·헤더·쿠키(가능 시)·소수 GET  
2. 코드가 **비밀 제거**되어 제공되면 화이트박스, 없으면 공개 관찰만  
3. 테스트 계정: **아니오** — 인증 후 심층·IDOR 교차는 **시나리오·체크리스트만**  
4. 산출물은 아래 표 + 요약 10줄 이내
