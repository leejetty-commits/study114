# 외부 AI 보안 점검 지시서 (ChatGPT · Genspark)

작성: 우동공과3 · 2026-11-18 · 대상 https://study114.net (오픈 2026-11-20 예정)
성격: 바깥에서 보이는 것만 보는 **수동 점검**. 계정·비밀번호·내부 코드는 주지 않는다.

## 지킬 것 (종현)
- 두 AI에 아이디·비밀번호·API 키·관리자 주소를 주지 않는다.
- 공격성 시험(대량 요청, 로그인 무차별 대입, SQL 주입 시도, 결제 시도)은 시키지 않는다. 운영 사이트다.
- 결과는 그대로 우동공과3에 붙여 넣는다. 우동공과3가 코드·운영 값과 대조해 진짜 문제만 골라 Cursor 지시서로 만든다.

## 붙여 넣을 프롬프트 (두 곳에 똑같이)

```
당신은 웹 보안 점검자입니다. 아래 사이트를 바깥에서 공개적으로 볼 수 있는 정보만으로 수동 점검해 주세요.
대상: https://study114.net  (한국 지역 공부방·과외 포털, 정적 SPA + PHP API, Cloudflare 뒤 공유호스팅, 결제는 PortOne)

규칙
- 로그인, 회원가입, 결제, 대량 요청, 무차별 대입, 주입 공격 시도는 하지 마세요. 공개 페이지·응답 헤더·공개 파일만 보세요.
- 추측은 "추측"이라고 표시하고, 실제로 확인한 근거(주소, 헤더 값, 응답 내용)를 함께 적어 주세요.

점검 항목
1. HTTPS: http→https 리다이렉트, www→apex 리다이렉트, 인증서 유효기간, HSTS 헤더.
2. 보안 헤더: Content-Security-Policy, X-Frame-Options 또는 frame-ancestors, X-Content-Type-Options, Referrer-Policy, Permissions-Policy. 없거나 약한 것.
3. 노출 파일: /.env, /.git/HEAD, /composer.json, /package.json, /phpinfo.php, /vendor/, /src/, /config 류, 백업 파일(.bak, .zip, .sql), 디렉터리 목록 노출 여부. (각 주소의 응답 코드만)
4. 공개 JS 번들: 소스맵(.map) 공개 여부, 번들 안에 API 키·비밀값·내부 주소·관리자 경로·테스트 계정이 보이는지. (공개용 지도·결제 클라이언트 키는 정상이니 구분)
5. 공개 API: 로그인 없이 /api/ 아래에서 개인정보(이름·전화·이메일·주소)가 내려오는 응답이 있는지. 에러 응답에 서버 경로·SQL·스택이 보이는지.
6. 쿠키: 세션 쿠키의 Secure, HttpOnly, SameSite 속성.
7. CORS: Access-Control-Allow-Origin 이 * 이거나 아무 출처나 되돌려 주는지.
8. robots.txt, sitemap 에 숨겨야 할 경로가 드러나는지.
9. 서버·버전 노출: Server, X-Powered-By 헤더.
10. 개인정보 처리방침·이용약관·사업자정보가 공개 페이지에 있는지.

결과 형식
- 표: 번호 | 항목 | 심각도(높음/중간/낮음/정보) | 확인한 근거 | 고치는 방법 한 줄
- 마지막에 "오픈 전에 꼭 고칠 것" 최대 5개만 따로 적어 주세요.
```

## 결과 받은 뒤 (우동공과3)
1. 항목마다 운영 헤더·코드로 사실 확인(오탐 제거).
2. 진짜 문제만 "오픈 전 / 오픈 후"로 나눠 종현에게 보고.
3. 오픈 전 건은 허용 파일을 좁힌 Cursor 지시서로. 헤더는 `public/.htaccess` 위주.
