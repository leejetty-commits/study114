# 관리자 통계

기준: `origin/main` `bd8f9fc8` (PR #266) · 지역 3단 `b60ef7b4` (PR #267).

## 화면

- 주소 `#/admin/stats`. 메뉴는 맨 위. 로그인 뒤 첫 화면은 `/admin`이다 (`getDefaultAdminPath()`).
- API는 `GET /api/admin/stats.php`. `requireAdmin` 다음 `requireMaster`라 마스터만 연다. 부마스터 메뉴 목록에 `stats`가 있어 부마스터는 못 연다.
- 기간은 오늘, 어제, 최근 7일, 최근 30일, 전체, 직접 지정. 전체는 날짜 칸이 비고, 직접 지정은 시작·종료를 넣는다.
- 가입 5줄: 전체, 공부방, 과외쌤, 학생·학부모, 역할 없음.
- 등록 2줄: 공부방, 과외쌤. 학생 의뢰는 세지 않는다.
- 지역은 가입 대표 지역과 등록 지역을 시·도, 시·군·구, 읍·면·동 3단으로 센다 (#267). 동 행은 시·군·구 안에서만 센다.
- 0이어도 줄을 남긴다. 금액·결제·매출은 없다.

## 2차 비밀번호

통계를 포함한 관리자 API는 2차 비밀번호를 먼저 본다. 5회 실패면 900초 잠금, 1800초 동안 요청이 없으면 다시 잠근다. 6자리, 특수문자 `!@#$%^&*?`. 부마스터도 같은 잠금을 탄다. 비밀번호 값은 적지 않는다. 구현은 #220·#221, 작업기록 `2026-11-15-363-admin-console-2nd-password.md`.
