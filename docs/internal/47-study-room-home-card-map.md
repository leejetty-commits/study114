# 공부방 홈 카드 매핑

**대상:** 공부방만

## 0. 2026-10-09 최종 (이 절이 아래 내용보다 우선)

과외쌤 카드 정본 [73](./73-tutor-basic-card-lock.md) 0절과 같은 규칙을 공부방에 적용한다. 작업 기록: `docs/worklog/2026/10/2026-10-09-room-card-slots.md`.

사용자 결정 원문 (2026-10-09):

- 「베이직 카드의 2열… 교습형태, 대상, 과목, 원생수, 수업운영방식 / 3열에는 슬로건」 (1열 = 공부방명, 위치, 가격)
- 「기본등록만으로 노출이 되어야 하고, 베이직카드에 다른 항목이 있다면 그건 상세정보에서 채울거야(선택). 그래서 입력값이 없으면 그대로 빈항목으로 나오면 된다.」
- 「각 카드에서 입력값이 없더라도 항목제목은 나와야 해.」 「빈자리는 그냥 비워두지 말고 하이픈으로 넣어. '수업운영방식' 이 맞아.」

### 0-2. 규칙

1. **노출 = 기본등록 완료(홍보지역 1).** 상세정보·사진·가격은 노출을 막지 않는다. 공개 버튼·공개 단계는 없다(정본 73 519줄). 숨김은 관리자만.
2. **칸은 없애지 않는다.** 베이직·픽·프라임·확대카드 모두 값이 없어도 항목제목은 보이고, 값 자리는 「—」. 「(선택)」 같은 표시를 값 자리에 넣지 않는다.
3. **값을 지어내지 않는다.** 과목·소개가 비면 다른 문구(검색 응답 `summary` 줄 등)로 채우지 않는다.
4. **원생수**는 저장 코드를 한글로 보여 준다: `one_to_four` 1~4명 · `five_to_eight` 5~8명 · `nine_plus` 9명 이상. 예전 자유 입력 문구는 그대로.
5. **칸 이름은 「수업운영방식」 하나.** DB `study_rooms.lesson_operation_type` (타임별 그룹 · 타임별 혼합학년 · 개별 방문). 「수업형태」는 공부방에 쓰지 않는다(학생 `lesson_format` 의 말).
6. **픽** = 베이직 9칸 + 특징 1개 + 신뢰배지. **프라임** = 베이직 9칸 + 특징 1~3 + 소개 + 신뢰배지. 모두 상세정보(선택).
7. **확대카드**는 등급과 관계없이 베이직·픽·프라임 카드의 모든 칸을 보여 준다.
8. **값 전달.** 검색 응답(`SearchService::searchRooms()`)과 홈·찜·확대카드 변환(`home-basic-live.js` `studyRoomSearchCardFields()`), 검색 페이지 변환(`search-exposure-mapper.js`)은 카드 칸 값을 모두 넘긴다.

## 기본정보 입력 순서 · 필수

1. 교습형태 (공부방 / 교습소 택일) → 이름 칸이 **공부방명 / 교습소명**
2. 이름
3. 주대상 (학교급 복수: 미취학 · 초등 · 중등 · 고등 · N수)
4. 주력과목
5. 원장성별
6. 슬로건 (한 줄)
7. 집주소
8. 사업장주소 (지도 핀. 카드 「위치」에 안 나감)
9. 홍보지역 1~3

**필수:** 교습형태, 이름, 주대상 ≥1, 주력과목, 원장성별, 슬로건, 집주소, 사업장주소, **홍보지역 1번**  
**선택:** 홍보 2·3번. 빈 칸은 자리를 유지하고 앞으로 당기지 않음.

카드 「위치」= **홍보지역 1(대표)** 만. `is_primary` = slot 1.

DB: 교습형태는 기존 `study_rooms.lesson_place_type`. 새 컬럼 없음. 주대상은 `study_room_primary_audiences`.

## 입력 구간 × 홈 자리

| 입력 구간 | 베이직 노출 | 픽 노출 | 프라임 노출 |
| --- | --- | --- | --- |
| **기본정보** | 이름 (공부방명/교습소명)<br>과목 (= 주력과목)<br>위치 (= **홍보지역 1**)<br>대상 (= 주대상)<br>교습형태<br>슬로건 | 왼쪽과 같음 | 왼쪽과 같음 |
| **상세정보 1단계** | 가격 (= 월 대표가 · 월 수업료)<br>원생수 (= 타임별 원생수)<br>수업운영방식 | 왼쪽과 같음 | 왼쪽과 같음 |
| **상세정보 2단계** | 칸 없음 (특징·사진은 유료) | 특징1<br>사진 (= 홍보사진 대표 1장)<br>신뢰배지 (= 교육청 등록 체크) | 특징 1~3<br>소개 (= 한 줄 소개)<br>사진<br>신뢰배지 |

**베이직에는 특징1~3이 없다.** 특징은 픽·프라임만.

**제출함은 이 표에 넣지 않음.** 「증빙 n개」는 과외쌤 카드. 매핑은 [48](./48-tutor-home-card-map.md). 이번 버전 운영은 [49](./49-submission-role-split.md).

## 카드 「교습형태」

주소가 아니다. 주소는 사업장(핀) · 홍보지역(카드 위치).

| 구분 | 내용 |
| --- | --- |
| DB | `study_rooms.lesson_place_type` |
| 정본 값 | `academy` → **교습소** · `study_room` → **공부방** |
| 레거시 데모 | `office` → 교습소 · `home` → 재택 |
| 입력 | 기본정보 맨 위 라디오. 묵시 `study_room` 기본값 없음 |

용어 **수업장소**는 공부방 카드·검색에서 쓰지 않음. 과외쌤·학생의 「수업장소」(방문/공공장소)와 다름.

## 카드 말 ↔ 등록 폼 말

| 홈 카드에서 쓰는 말 | 등록 화면에서 쓰는 말 | 입력 구간 |
| --- | --- | --- |
| 공부방명 / 이름 | 공부방명 또는 교습소명 (교습형태에 따라) | 기본정보 |
| 과목 | 주력과목 (상세1에서 한 번 더 고름) | 기본정보 · 상세1 |
| 위치 | **홍보지역 1(대표)** | 기본정보 |
| 대상 | 주대상 (학교급 복수) | 기본정보 |
| 교습형태 | 공부방 / 교습소 | 기본정보 |
| 슬로건 | 슬로건 한 줄 | 기본정보 |
| 가격 | 월 대표가 · 가격 항목의 월 수업료 | 상세1 |
| 원생수 | 타임별 원생수 | 상세1 |
| 수업운영방식 | 수업운영방식 | 상세1 |
| 특징 | 특징 1 · 2 · 3 (**픽·프라임만**. 베이직 없음) | 상세2 |
| 소개 | 한 줄 소개 · 프라임만 | 상세2 |
| 대표 이미지 | 홍보사진 (대표/내부/시설) | 상세2 |
| 신뢰배지 | 교육청 등록 체크+번호 | 상세2 |

## 학생 탐색 → 마이샵 (라우팅)

미니카드 → 확대카드 → **공개 마이샵**(`#/myshop/study-room/:id`, 풀페이지 본편).  
배너/이미지는 확대카드, 「공부방 둘러보기」 등 명시적 CTA만 마이샵.  
학부모·공부방·과외쌤 등 **공개 열람 공통**. 복귀·문맥: [50-student-myshop-routing.md](./50-student-myshop-routing.md).

## 노출 조건

기본등록 완료(홍보지역 1)면 베이직에 노출된다. 사진·원생수·수업운영방식·가격은 노출을 막지 않는다(0절 규칙 1). 코드: `SearchService::searchRooms()` 조건은 숨김 제외 + 홍보지역 1.
