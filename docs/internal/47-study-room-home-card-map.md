# 공부방 홈 카드 매핑

**대상:** 공부방만  
**원칙:** 공개는 스위치. 베이직·픽·프라임은 공개 이후의 노출 자리.

- `저장만`이면 홈 세 카드 어디에도 나오지 않음
- **베이직 노출** = 공개만으로 들어가는 일반 목록
- **픽 노출**, **프라임 노출** = 그 위의 유료 기간형 자리
- 학부모 화면에는 「공개」라는 말을 쓰지 않고 카드만 보여 줌

괄호는 홈 카드 말과 등록 폼 말이 다를 때 같은 맥락으로 묶은 것.

이번 라운드: **기본정보 폼 + 홈 카드·검색 표시.** 상세1·마이페이지 탭 구조는 다음.

## 기본정보 입력 순서 · 필수

1. 교습형태 (공부방 / 교습소 택일) → 이름 칸이 **공부방명 / 교습소명**
2. 이름
3. 주대상 (학교급 복수: 미취학 · 초등 · 중등 · 고등 · N수)
4. 주력과목
5. 원장성별
6. 슬로건 (한 줄)
7. 집주소
8. 사업장주소 (지도 핀. 카드 「위치」에 안 나감)
9. 홍보지역 1~3

**필수:** 교습형태, 이름, 주대상 ≥1, 주력과목, 원장성별, 슬로건, 집주소, 사업장주소, **홍보지역 1번**  
**선택:** 홍보 2·3번. 빈 칸은 자리를 유지하고 앞으로 당기지 않음.

카드 「위치」= **홍보지역 1(대표)** 만. `is_primary` = slot 1.

DB: 교습형태는 기존 `study_rooms.lesson_place_type`. 새 컬럼 없음. 주대상은 `study_room_primary_audiences`.

## 입력 구간 × 홈 자리

| 입력 구간 | 베이직 노출 | 픽 노출 | 프라임 노출 |
| --- | --- | --- | --- |
| **기본정보** | 이름 (공부방명/교습소명)<br>과목 (= 주력과목)<br>위치 (= **홍보지역 1**)<br>대상 (= 주대상)<br>교습형태<br>슬로건 | 왼쪽과 같음 | 왼쪽과 같음 |
| **상세정보 1단계** | 가격 (= 월 대표가 · 월 수업료)<br>원생수 (= 타임별 원생수)<br>수업형태 (= 수업운영형태) | 왼쪽과 같음 | 왼쪽과 같음 |
| **상세정보 2단계** | 칸 없음 (특징·사진은 유료) | 특징1<br>사진 (= 홍보사진 대표 1장)<br>신뢰배지 (= 교육청 등록 체크) | 특징 1~3<br>소개 (= 한 줄 소개)<br>사진<br>신뢰배지 |

**베이직에는 특징1~3이 없다.** 특징은 픽·프라임만.

**제출함은 이 표에 넣지 않음.** 「증빙 n개」는 과외쌤 카드. 매핑은 [48](./48-tutor-home-card-map.md). 이번 버전 운영은 [49](./49-submission-role-split.md).

## 카드 「교습형태」

주소가 아니다. 주소는 사업장(핀) · 홍보지역(카드 위치).

| 구분 | 내용 |
| --- | --- |
| DB | `study_rooms.lesson_place_type` |
| 정본 값 | `academy` → **교습소** · `study_room` → **공부방** |
| 레거시 데모 | `office` → 교습소 · `home` → 재택 |
| 입력 | 기본정보 맨 위 라디오. 묵시 `study_room` 기본값 없음 |

용어 **수업장소**는 공부방 카드·검색에서 쓰지 않음. 과외쌤·학생의 「수업장소」(방문/공공장소)와 다름.

## 카드 말 ↔ 등록 폼 말

| 홈 카드에서 쓰는 말 | 등록 화면에서 쓰는 말 | 입력 구간 |
| --- | --- | --- |
| 공부방명 / 이름 | 공부방명 또는 교습소명 (교습형태에 따라) | 기본정보 |
| 과목 | 주력과목 (상세1에서 한 번 더 고름) | 기본정보 · 상세1 |
| 위치 | **홍보지역 1(대표)** | 기본정보 |
| 대상 | 주대상 (학교급 복수) | 기본정보 |
| 교습형태 | 공부방 / 교습소 | 기본정보 |
| 슬로건 | 슬로건 한 줄 | 기본정보 |
| 가격 | 월 대표가 · 가격 항목의 월 수업료 | 상세1 |
| 원생수 | 타임별 원생수 | 상세1 |
| 수업형태 | 수업운영형태 | 상세1 |
| 특징 | 특징 1 · 2 · 3 (**픽·프라임만**. 베이직 없음) | 상세2 |
| 소개 | 한 줄 소개 · 프라임만 | 상세2 |
| 대표 이미지 | 홍보사진 (대표/내부/시설) | 상세2 |
| 신뢰배지 | 교육청 등록 체크+번호 | 상세2 |
| 등록일 | 시스템 자동 · 베이직 3행만 | 자동 |

집주소는 비공개. 사업장주소는 지도 핀만.

## 학생 탐색 → 마이샵 (라우팅)

미니카드 → 확대카드 → **공개 마이샵**(`#/myshop/study-room/:id`, 풀페이지 본편).  
배너/이미지는 확대카드, 「공부방 둘러보기」 등 명시적 CTA만 마이샵.  
학부모·공부방·과외쌤 등 **공개 열람 공통**. 복귀·문맥: [50-student-myshop-routing.md](./50-student-myshop-routing.md).

## 공개 게이트와 카드 완성

지금 등록 완료가 막는 것: 사진 1장 · 수업형태 · 원생수 · 주력과목 · 대상과목 · 가격. (이번 라운드에서 공개 게이트는 안 바꿈)
