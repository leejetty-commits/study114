# 공부방 홈 카드 매핑

**대상:** 공부방만  
**원칙:** 공개는 스위치. 베이직·픽·프라임은 공개 이후의 노출 자리.

- `저장만`이면 홈 세 카드 어디에도 나오지 않음
- **베이직 노출** = 공개만으로 들어가는 일반 목록
- **픽 노출**, **프라임 노출** = 그 위의 유료 기간형 자리
- 학부모 화면에는 「공개」라는 말을 쓰지 않고 카드만 보여 줌

괄호는 홈 카드 말과 등록 폼 말이 다를 때 같은 맥락으로 묶은 것.

카드 명세에는 있는데 지금 3단계 폼에 칸이 없는 것: **수업장소 · 슬로건 · 한 줄 소개**.

## 카드 「수업장소」에 실제로 들어가는 값

주소가 아니다. 주소·홍보지역은 카드 **위치**.

| 구분 | 내용 |
| --- | --- |
| DB | `study_rooms.lesson_place_type` |
| 정본 값 | `academy` → 화면 **교습소** · `study_room` → 화면 **공부방** |
| 레거시 데모 | `office` → 교습소 · `home` → 재택 |
| 지금 입력 | 3단계 폼에 선택 칸 없음. 기본정보 저장 시 비어 있으면 **`study_room`(공부방)** 으로 묵시 기본값 |
| 기본정보 필수 5 | 방명 · 과목 · 성별 · 사업장주소 · 홍보지역1 — 수업장소와 별개 |

그래서 지금 카드에는 대개 「공부방」이 찍힌다. 원장이 교습소/공부방을 고른 결과가 아니다. 수업 **유형**(어디서 가르치는지)이지 상세1 맥락이 맞고, 기본 필수 5에는 넣지 않는다.

**제출함은 이 표에 넣지 않음.** 「증빙 n개」는 과외쌤 카드. 매핑은 [48](./48-tutor-home-card-map.md). 이번 버전 운영은 [49](./49-submission-role-split.md) — 공부방은 제출함 보드를 살리지 않고, 교육청 등록 체크가 최소 신뢰 표시다.

| 수업형태 | 수업운영형태 | 상세1 |
| 수업장소 | 교습소 / 공부방 · **폼 없음** | 상세1 맥락 |
| 특징 | 특징 1 · 2 · 3 (베이직·픽은 1만) | 상세2 |
| 슬로건 | 슬로건 · **폼 없음** | 상세2 맥락 |
| 소개 | 한 줄 소개 · **폼 없음** · 프라임만 | 상세2 맥락 |
| 대표 이미지 | 홍보사진 (대표/내부/시설) | 상세2 |
| 신뢰배지 | 교육청 등록 체크+번호 | 상세2 |
| 등록일 | 시스템 자동 · 베이직 3행만 | 자동 |

## 공개 게이트와 카드 완성

지금 등록 완료가 막는 것: 사진 1장 · 수업형태 · 원생수 · 주력과목 · 대상과목 · 가격.

20장 문서는 여기에 소개문 · 수업장소까지 더 요구함. **공개 가능 조건**과 **카드 완성 조건**은 아직 완전히 같지 않음.
