# Visily 복붙용 페이지 프롬프트

기준: home-ui / search-ui / auth-ui / study-room-ui / tutor-ui 코드 + SSOT 6·9·15·18·30장.  
용도: Visily 러프 와이어프레임 생성용. **한 페이지 = 한 프롬프트.**

공통 규칙(모든 프롬프트에 공통 적용):
- 데스크톱 우선, 모바일은 별도 프레임
- 상단: util 1줄 + GNB
- 카드 남발·대시보드 위젯·통계 스트립·히어로 위 배지 오버레이 금지
- 상세·비교·쪽지 게이트는 **별도 페이지가 아니라 오버레이**
- `#/mypage/*` = 운영 허브, `#/plans/*` = 상품·구매 (섞지 말 것)

---

## 01. 비회원 메인 `#/guest` (P09-01)

```
우동공과 비회원 홈 와이어프레임.
상단 util(이용안내·로그인·회원가입) + GNB(홈·공부방찾기·과외쌤찾기·학생찾기·공부방상세등록·과외쌤상세등록·유료상품·고객센터).
첫 화면은 하나의 쇼윈도 구성: 브랜드+샘플지역 히어로, 짧은 설명 1줄, 가입 CTA.
아래로 Prime/Pick 노출 박스, 공부방·과외·학생 리스트, 우측 배너 레일, 하단 로그인/가입 스트립.
대시보드형 통계·카드 그리드 금지. 성격=쇼윈도형.
```

## 02. 학부모 홈 `#/parent` (P09-02)

```
우동공과 학부모 로그인 홈.
util은 로그인용(이용안내·쪽지함·최근열람·마이페이지·로그아웃). GNB에서 공부방/과외 상세등록·유료상품은 숨김.
본문: 탭(우리동네 공부방 | 우리동네 과외쌤), 필터+결과 리스트, 하단 비교바(최대 3).
우측 레일 유지. 공급자 등록 UI·유료상품 카탈로그 넣지 말 것. 성격=탐색형 홈.
```

## 03. 공부방 홈 `#/study-room` (P09-03)

```
우동공과 공부방 회원 홈.
GNB에서 과외쌤찾기·과외쌤상세등록 숨김.
본문 2탭: (1) 우리동네 공부방=내 노출 상태 (2) 우리동네 학생=수요 리스트.
상단에 내 공개/노출 상태 박스 1개. 학부모 찜 UI 금지. 성격=운영형 홈.
```

## 04. 과외쌤 홈 `#/tutor` (P09-04)

```
우동공과 과외쌤 회원 홈.
GNB에서 공부방찾기·공부방상세등록 숨김.
본문 2탭: (1) 내 과외 노출·활동지역 (2) 우리동네 학생.
상태 요약 1박스 + 결과 리스트. 성격=운영형 홈.
```

## 05. 검색-공부방 `#/search/room`

```
공부방찾기 검색 결과 와이어프레임.
역할별 검색 탭, 기본검색 1~2줄, 접히는 확장검색, 지도+리스트(또는 리스트), 결과행 액션(상세·찜·비교).
학생 비교 기능 없음. 성격=탐색형.
```

## 06. 검색-과외 `#/search/tutor`

```
과외쌤찾기 검색 결과.
기본/확장 필터, 활동지역 탭, 결과행(상세·찜·비교).
공부방 찾기보다 비교 항목은 경량. 성격=탐색형.
```

## 07. 검색-학생 `#/search/student`

```
학생찾기(수요) 검색 결과. 공급자·게스트용.
블라인드/요약 정보 중심 리스트, 행 CTA는 쪽지·관심저장 위주.
학생끼리 비교 UI 금지. 성격=탐색형.
```

## 08. 상세 모달 (P24)

```
프로필/공부방/학생의뢰 상세는 독립 페이지가 아니라 모달 오버레이.
구성: Trust 스트립 → 본문(변형) → 연락/쪽지 패널 → 하단 Sticky CTA(쪽지·찜·비교).
풀페이지 SEO 상세처럼 그리지 말 것. 성격=판단 오버레이.
```

## 09. 비교 바·모달 (P25)

```
로그인 후 하단 Compare Bar(선택 N/3) + 클릭 시 비교표 모달.
공부방/과외만, 최대 3개. 학생 비교 없음. 성격=글로벌 오버레이.
```

## 10. 로그인 `#/login`

```
로그인 화면. 흐린 홈 실루엣 배경 + 중앙 카드.
이메일/비밀번호, 소셜 로그인, 회원가입·아이디/비번찾기 링크.
마이페이지 메뉴·대시보드 금지. 성격=폼형 인증.
```

## 11. 회원가입 플로우

```
가입 스텝 와이어 5장: 약관 → 역할선택(학생/학부모·공부방·과외) → 계정폼 → 기본등록 → 완료.
각 화면은 중앙 카드+스텝 인디케이터. 완료 화면에만 상세등록 CTA.
한 화면에 여러 스텝을 몰아넣지 말 것.
```

## 12. 마이페이지 홈 `#/mypage/home` (P15-01)

```
마이페이지 운영 허브 홈. 좌측 세로 메뉴 + 본문.
학부모: 찜·최근·쪽지·계정 중심 바로가기.
공부방/과외: 내 등록·관심 학생·쪽지·이용 현황 중심.
숫자 요약 → CTA. 상품 카탈로그를 홈에 넣지 말 것. 성격=관리형.
```

## 13. 찜 / 최근 / 관심 학생

```
세 화면을 비슷하되 역할 분리해서 그려라.
(1) 찜 목록 #/mypage/wishlist — 학부모, 공부방/과외 탭, 비교 가능
(2) 최근 본 항목 #/mypage/recent — 재방문 리스트
(3) 관심 학생 #/mypage/student-review — 공급자만, 저장한 학생 의뢰·쪽지 준비. 학생찾기 화면이 아님.
좌측 mypage nav 유지. 성격=리스트형 운영.
```

## 14. 쪽지함 `#/mypage/messages/*` (P16)

```
쪽지함. 탭(받은/보낸/진행/보관) + 리스트, 또는 대화 스레드.
공개범위 배지, 하단 입력. 유료 제한 시 게이트 오버레이(상품센터로 유도).
고객센터 문의 폼과 혼동하지 말 것. 성격=메시지형.
```

## 15. 이용 현황 `#/mypage/plans` (P15-09)

```
마이페이지 이용 현황(운영). 이용권/남은기간 상태, 티어 설명, 버튼 3개:
내 상품(#/mypage/plans/my) · 결제내역(#/mypage/plans/history) · 추가 이용 알아보기(#/plans).
결제 폼을 이 페이지에 넣지 말 것. 성격=관리형.
```

## 16. 내 상품 / 결제내역

```
(1) 내 상품 #/mypage/plans/my — 보유 entitlement 목록
(2) 결제내역 #/mypage/plans/history — 결제 이력 테이블/리스트
둘 다 마이페이지 좌측 nav 맥락. 상품 브라우징 UI는 #/plans로 링크만. 성격=관리형.
```

## 17. 상품홈 `#/plans` (P18-01)

```
유료상품 상품센터 홈. 학부모 GNB에는 없음. 공급자용.
좌측/상단 서브nav: 상품홈 · 노출상품 · 접근권상품만 (내상품·결제내역은 여기 메뉴에 넣지 말 것).
본문: 현재 이용 요약 + 상품 소개 + 빠른 링크(내상품·결제내역은 mypage로).
성격=판매/카탈로그형.
```

## 18. 노출상품 `#/plans/positions` (P18-02)

```
대표·추천 노출 상품 목록. 기간형 상품 카드, 적용 프로필 선택, 구매 CTA → checkout.
마이페이지 운영 화면처럼 그리지 말 것. 성격=판매형.
```

## 19. 접근권상품 `#/plans/access` (P18-03)

```
쪽지권·요청문 열람권 등 횟수권 상품. 카드+구매 CTA.
학부모 선쪽지 답장은 무료라는 안내 한 줄. 성격=판매형.
```

## 20. 결제 / 결과 `#/plans/checkout` `#/plans/result`

```
결제 확인 화면과 결과 화면. 상품명·금액·적용 프로필·확인 버튼.
성공 시 내 상품(#/mypage/plans/my)·운영 화면으로 복귀 CTA.
복잡한 PG UI는 러프로 단순화. 성격=체크아웃형.
```

## 21. 내 등록 허브 (P19/P20/P21)

```
마이페이지 > 내 등록.
학부모=자녀 목록/허브, 공부방=공부방 목록/허브, 과외=과외 목록/허브.
허브는 상태판(공개·상세완료·노출) + CTA(작성이어하기·공개·노출·접근/쪽지).
검색 결과처럼 그리지 말 것. 성격=운영 허브.
```

## 22. 공부방/과외 등록 위저드 (register SPA)

```
상세등록 위저드. phase(기본등록→상세등록) + step dots + 폼 섹션 + 이전/다음.
기본등록 완료 계정은 상세 첫 단계부터 시작해도 됨.
GNB "공부방상세등록/과외쌤상세등록" 진입. 성격=폼 위저드.
```

## 23. 고객센터 `#/support`

```
고객센터 홈. 좌측 nav(홈·이용안내·FAQ·공지·문의·안전과외).
본문: 플랫폼 3원칙 + 주요 카드 진입.
쪽지함과 운영문의를 섞지 말 것. 성격=안내형.
```

## 24. 안전과외 가이드 `#/support/safe`

```
안전과외는 GNB 독립 메뉴가 아니라 고객센터 하위 가이드 목록.
카드형 가이드(G1~G7) + 상세 본문. 에스크로/결제중개 UI 금지. 성격=안내형.
```

## 25. 자료실 `#/library`

```
자료실. GNB 밖. 섹션 탭: 자료실 | 양식 | 가이드 PDF. 다운로드 카드 리스트.
커뮤니티 게시판처럼 그리지 말 것. 성격=다운로드형.
```

## 26. 관리자 `#/admin`

```
내부 관리 콘솔. 좌측 접히는 그룹 메뉴 + 본문 테이블/폼.
승인·반려·사전심사 UI/카피 금지(자기공개·제출여부 표시만).
사용자 사이트 헤더와 톤 분리. 성격=백오피스.
```

## 한 줄 체크리스트 (생성 후 검수)

1. 헤더에 util + GNB가 있는가  
2. 역할별로 숨겨야 할 GNB가 숨겨졌는가  
3. mypage와 plans가 섞이지 않았는가  
4. 상세/비교가 풀페이지로 안 그려졌는가  
5. 관심 학생을 학생찾기로 안 그렸는가  
6. 1차 제외(퀵매칭·안전과외 GNB·알림센터 독립)가 없는가
