# 과외쌤 홈 카드 매핑

**대상:** 과외쌤만  
**상태:** 이번 버전 제출함 **사용 주체**. 공부방과 동일 강도로 맞추지 않음. 운영 분리: [49](./49-submission-role-split.md)

- `저장만`이면 홈 세 카드 어디에도 나오지 않음
- **베이직 노출** = 공개만으로 들어가는 일반 목록
- **픽 노출**, **프라임 노출** = 그 위의 유료 기간형 자리

괄호는 홈 카드 말과 등록 폼 말이 다를 때 같은 맥락으로 묶은 것.

공부방 표: [47](./47-study-room-home-card-map.md) · 상세완료 필드: [45](./45-tutor-expanded-complete-ssot.md)

## 제출함 (이번 버전 과외쌤이 사용)

카드 「제출자료 n개」 = `tutor_verification_documents` 집계. 픽·프라임만. 공부방 홈 카드에는 이 행이 없다.

고액과외 특성상 제출함은 **유지**한다. 등록 3단계에 파일 칸을 넣는 것은 안정화 때. 지금은 마이페이지 제출함으로 올린다.

| 지금 있는 것 | 없는 것 (안정화 때) |
| --- | --- |
| 마이페이지 내 등록 → 제출자료 상태(P15-10) · 제출함(P23-04) | 등록 3단계 안의 파일 업로드 칸 |
| 상세2 「증빙서류 제출 가능」 체크 (`proof_document_available`) | 체크와 실제 파일 수의 자동 동기 |
| 프리뷰 항목: 본인 확인 · 학력 · 경력 · 자격증 | 운영 업로드·공개범위 UX 다듬기 |

등록 폼은 체크만 받고, 파일은 마이페이지 제출함으로 안내한다.

## 카드 「수업장소」 (과외쌤)

공부방과 다르다. 교습소/공부방 ENUM이 아니다.

| 구분 | 내용 |
| --- | --- |
| DB | `tutor_lesson_places` (복수) |
| 값 | `student_home_visit` → **학생자택방문** · `public_place` → **공공장소** · `tutor_home` → **강사자택** |
| 입력 | 상세 1단계에 실제 체크 칸 있음 |
