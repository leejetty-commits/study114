## 🔒 잠금 1 · 공부방 / 과외쌤 분기표 (최종)

| 항목 | 공부방 | 과외쌤 |
|---|---|---|
| **상품 의미** | 선택 단지·행정동의 **대표/추천 자리**를 확보·순환 노출 | 선택 **시·주력과목**에서 먼저/꾸준히 발견되도록 순환 노출 |
| **노출 방식** | **Prime**: 지역별 **실제 3자리**·좌측부터 자동배정·연장 우선·**예약대기**. **Pick**: 페이지당 10(5×2)·15분 공정 회전·숫자 페이지네이션. Basic 무료 | **Prime**: 시·주력과목 **페이지당 3**·15분 회전·숫자 페이지네이션(재고/매진 없음). **Pick**: 페이지당 10(5×2)·동일 회전. Basic 무료 |
| **배지** | Hot·단과 중 **서로 다른 최대 2개**. Prime/Pick **종속**·동일 시작·종료. 최초 구매·연장 시에만 추가·변경 | Hot·쪽집게·SKY 중 **서로 다른 최대 2개**. 동일 종속·동일 기간 규칙. SKY=광고 표현(인증 아님) |
| **적용 대상** | 적용 프로필 + **대표 홍보지역 1·2·3** 중 하나. 지역 미정 시 기간카드·구매 CTA 비활성 | 적용 프로필 + **활동지역 1·2·3** 중 하나 + **주력과목**. 지역/과목 미정 시 기간카드·구매 CTA 비활성 |
| **빈 상태 / 만료 카피** | 빈: 지역 미선택·프로필 비공개·Prime 빈칸=`구매 가능`. 만석: 「현재 선택 지역의 Prime 자리는 모두 이용 중입니다」+ **예약대기 등록**만. 만료: Basic 복귀·내 상품에서 안내 | 빈: 지역/과목 미선택·프로필 비공개. **매진·잔여·예약대기 카피 금지**. 만료: Basic 복귀·내 상품. 쪽지권 활성 묶음 시: 「사용 중인 쪽지권이 있습니다…」+ 5·10 비활성 |
| **금지 UI** | 슬롯 번호 라디오 선택 · `Pick 살펴보기`를 Prime 만석 CTA로 사용 · 경쟁업체/순번 공개 · UP 상품 · 내부용어(capacity·회전 풀 등) | **점유 3칸·매진·예약대기·슬롯 선택** 일체 · 공부방형 재고 UI 재사용 · UP · 내부용어 · SKY 인증 체크 |

공통: 사용자 용어는 **노출상품** / **Prime 노출** / **Pick 노출**. 역할 탭 금지(적용 프로필로 분기).

## 🔒 잠금 3 · 서버 / 프론트 경계

정본: **유료상품·결제 가격 확정 체크리스트** + **34-1장**.  
아래는 **프론트 추정이 아니라 서버 정본**으로 처리한다. UI는 서버 응답을 표시·비활성할 뿐, 금액을 발명·재계산 확정하지 않는다.

| 규칙 | 서버 | 프론트 |
|---|---|---|
| **가격·기간·할인** | 카탈로그 버전·판매가·할인 재계산·주문 스냅샷 | 표시만 · 하드코딩 금지 |
| **환불** | 환불표·가능 여부·금액 | 안내 문구만 · 임의 계산 금지 |
| **활성 유료 묶음권 1개** | 5·10회 중복구매 **차단** | 버튼 비활성+카피 · **UI만으로 막지 않음** |
| **배지 최대 2·종속** | 종류·개수·본상품 기간 상속·합산 검증 | 선택 UI · 중도 추가 진입점 없음 |
| **중도 교체 불가** | 이용기간 중 배지 추가·교체 API 거부 | 해당 UI **미제공** |
| **1회 즉시권** | 묶음과 무관 허용 · 잔액 미보관 | 항상 구매 가능 표시 |
