## 요약 (10줄 이내)

- **Critical/High 재현 0건** — 1차 High(R-1 HTTPS 미강제)는 재현 절차상 해소 확인.
- **좋아진 점 ①**: HTTP 요청이 301로 HTTPS 전환되고, HSTS(6개월+subdomains)·nosniff·SAMEORIGIN이 실관찰됨.
- **좋아진 점 ②**: `/api/admin/*`가 미인증 시 403·민감 JSON 미노출로 관찰됨(1차 High 후보 해소).
- **좋아진 점 ③**: CSP가 Report-Only 없이 Enforce로 적용되었고, `.env`·`.git` 등은 비밀 없는 홈 폴백으로 확인됨.
- **남은 점 ①**: CSP `script-src`에 `'unsafe-inline'` 잔존 — CSP의 XSS 방어 효과가 크게 약화됨(Medium).
- **남은 점 ②**: `/admin` UI 게이트는 클라이언트 실행 필요 — 브라우저 스모크 미수행으로 UI 차단은 미확인.
- **남은 점 ③**: OAuth return_to·state, IDOR 교차, cron 무키 거부, 첨부 MIME은 계정·POST 없이는 구조상 미확인(후속 B 대상).
- **홍보 전 필수**: 없음(재현된 High 없음). 다만 `/admin` UI 게스트 차단·지도 정상 동작 브라우저 스모크 각 1회는 유튜브 배포 직전 권장.
- **후순위**: `'unsafe-inline'` 제거(nonce 전환), CSP 디렉티브 세분화·유튜브 배너 실측, git history purge, 계정 제공 하 IDOR 교차.
