# 샵 페이지 전면 재설계 (단일 ShopPage)

**기준일:** 2026-08-21  
**원칙:** 원장 마이페이지「마이샵」과 공개 `#/myshop/study-room/:id` 는 **같은 본문 1개**.  
**렌더:** `preview/home-ui/src/study-room-reg/myshop-render.js` → `renderMyshopShowcase`  
**스타일:** `preview/home-ui/src/styles/myshop.css` (`.shop`)  
**공개 입력 어댑터:** `myshop/public-model.js` → `toMyshopShowcaseInputs`  
**공개 API:** `GET /api/study-room/public.php`

이전 “미리보기용 / 공개용 이중 본문” 지시문은 폐기.

---

## 1) 페이지 구조도

```
1. Hero                 대표사진 + 이름/슬로건/한줄소개/생활권/칩
2. Quick Facts Bento    판단용 타일 (과목·대상·형태·원생·가격…)
3. Signature Point      지도 스타일 + 소개 본문
4. Gallery              대표 외 사진 (큰 1 + 썸네일)
5. 수업 안내            수업 카드 반복
6. 원장 소개 · 경력     대학/전공/연차/특징
7. 신뢰 정보            교육청·사업자·프랜차이즈·증빙
8. 시설 · 환경          체크된 시설 + 추가설명
9. 위치 · 생활권        홍보지역 (주소 원문 금지)
10. 소셜                링크 (없으면 숨김)
11. 문의 상태           하단 조용한 상태 문구
```

진입만 다름: 마이페이지 탭 / 카드 CTA / 딥링크. **본문 HTML·CSS 분기 없음.**

## 3) 숨김 규칙표

| 조건 | 동작 |
| --- | --- |
| 섹션 내 표시값 0개 | 섹션 전체 미렌더 |
| 사진 0장 | Hero는 기본 썸네일, Gallery 숨김 |
| 수업 0건 | 수업 안내 숨김 (빈 카드 금지) |
| boolean false/null | 해당 타일/행 숨김 |
| enum raw (라벨 없음) | 숨김 |
| 소셜 링크 전부 없음 | 소셜 섹션 숨김 |
| 문의 상태 문구 없음 | 푸터 숨김 |

---

## 4) 시각 스타일 가이드

- **폭:** max-width ≈ 58rem (이전 대비 확장), 외곽 **테두리 1겹** + 약한 그림자
- **배경:** 밝은 아이보리/화이트 + 아주 옅은 섹션 틴트 (민트·라일락·스카이·피치 중 섹션당 1축)
- **카드:** 넉넉한 라운드, 약한 그림자, 라벨 작고 값은 굵게
- **장식:** 섹션 타이틀 앞 작은 마크만. 별·글리터·다중 링 테두리 금지
- **톤:** 동네 작은 브랜드 / 따뜻 + 정돈 / 판매형 큰 CTA 금지
