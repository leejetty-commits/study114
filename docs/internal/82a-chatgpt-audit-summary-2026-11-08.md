## 표 항목을 우리가 읽는 법

| 판정 | 개수 감각 | 우리가 할 일 |
|------|-----------|--------------|
| 관찰됨 (Info) | 2 (리다이렉트) | 취약 아님. 도메인 정책 인지용 |
| 재현됨 | **0** | — |
| 추정 | return_to, state, rate limit, cron/스토리지 등 | 우리 쪽 **이미 잠근 항목(81)**과 대조·확인 |
| 미검증/미확인 | IDOR, 관리자, XSS, 쿠키, 소스맵, 민감파일 등 | 계정·코드·헤더 없으면 외부 AI로는 못 끝냄 |

ChatGPT가 “즉시 조치 3건”으로 꼽은 것(state·return_to / API 권한 / cron·스토리지·rate limit)은 **신규 해킹 발견이 아니라**, 지시문·일반 점검 목록을 다시 읽은 것에 가깝다. 내부적으로는 81잠금(return_to·rate limit·cron·storage·시크릿)이 이미 있다 → 최종 취합 때 **「이미 있음 / 아직 검증 안 함 / 진짜 구멍」**으로 나눈다.
