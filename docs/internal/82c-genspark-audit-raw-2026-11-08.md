**점검 방법 준수 확인**: 총 GET/HEAD 요청 약 15건, 요청 간 7~8초 지연(엔드포인트당 분당 10회 미만), 로그인·POST·페이로드 전송 없음, 시크릿 값 미확인. 테스트 계정·코드 미제공 조건에 따라 인증 후 영역은 체크리스트로만 작성했습니다.

## 3. 요약 (10줄 이내)

- **Critical 0건 / High 1건(R-1 HTTPS 미강제, 재현됨)** + High 후보 2건(C-1 관리 API 인가, C-6 IDOR — 미검증).
- 재현된 항목은 전부 구성(헤더·HTTPS) 수준이며, 시크릿·소스맵·민감 경로 실노출은 **관찰되지 않음(양호)**.
- **즉시 조치 3건**: ① HTTP→HTTPS 301 리다이렉트(Cloudflare "Always Use HTTPS" 또는 서버 설정), ② HSTS + X-Content-Type-Options + X-Frame-Options(또는 CSP frame-ancestors) 헤더 추가, ③ PHP API 전역에서 관리자 경로 인가 강제 확인(세션/토큰 검증이 프론트가 아닌 서버에서 이뤄지는지).
- **홍보 전 필수**: 위 3건 — 특히 HTTPS 미강제는 로그인 세션 탈취로 직결되므로 유튜브 홍보 유입 전 차단 필수.
- **후순위**: CSP 도입, DOM XSS 후보 정밀 검토, 쿠키 속성 실측(테스트 계정 제공 시), IDOR/권한 상승 검증(계정 2개 제공 시), OAuth return_to 화이트리스트 화이트박스 확인.
- R-4(`.env`·`.git` 200 응답)는 SPA 폴백으로 추정되나, 본문 완전 대조 1회로 최종 확정 권장.
