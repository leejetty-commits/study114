# 우동공과 로고 (2026-11-09 종현 확정)

`00_원본_1203우동공과-구매자용.ai`(2019-12-03)는 손대지 않은 구매 원본입니다. 01~04는 그 벡터로 만든 확정 변형이며 배경은 모두 투명입니다.
사이트에서 쓰는 기존 파일(`public/assets/brand/`)은 그대로 두었습니다.

| 파일 | 종류 |
|---|---|
| `01_가로형_심벌+우동공과` | 가로형 · 심벌 + 우동공과 |
| `02_세로형_심벌위+우동공과` | 세로형 · 심벌 위 + 우동공과 |
| `03_가로형_심벌+우리동네공부방과외` | 가로형 · 심벌 + 우리동네 공부방과외(1행) |
| `04_세로형_심벌위+우리동네공부방과외` | 세로형 · 심벌 위 + 우리동네 / 공부방과외(2행, 원본 배치) |

## 기준
- 심벌 높이 = 글자 한 줄 높이의 1.05배(기존 합성본 1.5배에서 30% 축소, 확정).
- 가로형 심벌–글자 간격 = 글자 높이의 0.17배, 세로 중앙 정렬.
- 세로형 심벌–글자 간격 = 심벌 높이의 0.08배, 가로 중앙 정렬.
- 03의 1행은 「우리동네」와 「공부방과외」 사이 한 칸, 아랫선 맞춤.
