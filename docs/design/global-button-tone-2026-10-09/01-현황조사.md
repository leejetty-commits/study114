## 6. 확인 항목 (구현 중 주의)

1. `.msg-tab.is-active`(쪽지 탭 활성)는 C4에서 `.btn--primary`와 한 규칙 → **분리해서 그대로 둠**(탭은 이번 범위 아님).
2. 지도 히어로 CTA(`hero-map__cta`)는 전용 규칙이 12px로 고정 → 색·높이만 바뀜. 글자 키우기·줄이기는 이번에 안 함.
3. 검색 버튼 폭: search-ui 상세검색은 104 유지(검색 정본 ≥72 충족), 홈 지역바 검색은 72.
4. 고객센터 히어로의 `zip-bridge.css:243` 「흰 바탕」 규칙은 현재도 무효(!important에 짐) — 이번에 살리지 않음.
5. 학생 마이페이지(`student-mypage-stage5b.css`)는 폼 저장 위주라 그대로. 같은 화면의 일반 버튼은 전역 값을 따름.
6. PHP 구 auth CSS(`public/assets/css/auth/*`)는 주황 기본값 — 제출 버튼만 있어 이번 변경 영향 0. 프리뷰 auth와 색이 다른 건 별건(이번 범위 아님).
7. 로그인 상태 공부방 홈(머리 박스)·마이페이지 내부는 프리뷰에서 서버 세션이 없어 실측 못 함 → 목업(`mockup.html` ①⑥)으로 대체, Cursor 검수 때 실측 필수.
