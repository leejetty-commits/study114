## 4. 블록 사이 간격

디자인 토큰(`--space-1…20`, 4~48px)은 이미 있습니다. 그런데 공부방 화면 CSS는 대부분 rem 직접값과 px를 섞어 쓰고 있어서 간격이 화면마다 다릅니다.

### 4-1. 발견 사항

| 등급 | 내용 | 근거 | 처리 |
|---|---|---|---|
| 미흡 | 섹션 제목 아래 간격이 0px부터 24px까지 제각각입니다. 예: `.section-heading--basic` 0, `.rc-subsection__title` 3.2px, `.home-section__head` 8px, `.mp-card__title` 16px, `.mypage-content__head` 24px. | 코드 점검 4-2 | 미처리 |
| 미흡 | 큰 제목 위 간격이 앞 블록 간격보다 좁아서 제목이 위 블록에 붙어 보입니다. 공부방 홈 베이직 제목줄은 위 12px·아래 4px인데, 일반 섹션 사이는 20px이고 학생 홈의 같은 구분은 32px입니다. 라이브에서도 「댓글 0」 헤딩 위 약 10px, 이용안내 「순서」 태그 위 약 8px, 「신뢰」 H2가 위 입력칸에 붙음 등이 보였습니다. | 코드 점검 4-3, 노트 1·4-c·6-b·18 | 미처리 |
| 권장 | rem 직접값을 가장 가까운 토큰으로 맞추기를 권합니다(0.65rem→8px, 0.85rem→12px, 1.35rem→24px 등). | 코드 점검 4-4 | 미처리 |

### 4-2. 제안 간격 체계 (코드 점검 4-4)

| 용도 | 값 | 토큰 |
|---|---|---|
| 줄 단위(라벨↔값, 제목↔설명) | 4px | `--space-1` |
| 소제목(h3)·블록 제목 → 본문 | 8px | `--space-2` |
| 섹션 제목(h2) → 본문 | 12px | `--space-3` |
| 같은 섹션 안 카드·블록 사이 | 16px | `--space-4` |
| 섹션 사이(선 없음) | 24px | `--space-6` |
| 섹션 사이(구분선, 선 양쪽 같게) | 32px | `--space-8` |
| 페이지 헤더 → 첫 섹션 | 24px | `--space-6` |

원칙은 세 가지입니다. 첫째, 제목 위 간격은 바로 앞 블록 간격보다 크거나 같게 해서 제목이 아래 본문에 붙어 보이게 합니다. 둘째, 같은 역할의 블록은 화면이 달라도 같은 토큰을 씁니다. 셋째, 학생 홈의 픽/베이직 구분 간격(32px)을 공부방·과외쌤 홈에도 똑같이 씁니다.

홈 화면은 5절에서 따로 정한 값(섹션 사이 32px, 제목→본문 16px)을 쓰기를 권합니다.

- 로그인 공부방 홈에서 가로선이 있는 곳은 헤더 아래, 「우리동네 서울특별시 강남구 대치동」 섹션 헤더 아래, 지도 아래, 푸터 위입니다. 프라임·픽·베이직 섹션 사이에는 선이 없고 같은 장식선 헤더만 있어서 경계가 약합니다.
- 비로그인 홈에서는 가로선이 「베이직공부방」 위와 「학생」 위 두 곳에만 있고, 나머지 섹션 경계는 여백만으로 나뉩니다.
- 즉 어떤 경계에는 선이 있고 어떤 경계에는 없어서 기준이 없습니다. (노트 1, 25, 27-a)

### 5-2. 권장안 (하나)

**본문 안에는 구분선을 쓰지 않고, 섹션은 간격으로만 나눕니다.**

- 섹션과 섹션 사이: 32px
- 섹션 제목에서 내용까지: 16px
- 가로선은 헤더 아래와 푸터 위, 이 두 곳에만 남깁니다.

### 5-3. 이렇게 권하는 이유

- 지금은 선이 있는 곳과 없는 곳이 섞여 있어서, 사용자는 선이 있는 곳이 더 중요한 경계라고 잘못 읽을 수 있습니다. 선을 아예 빼면 이런 오해가 생기지 않습니다.
- 제목과 내용 사이(16px)보다 섹션 사이(32px)를 두 배로 넓게 두면, 선이 없어도 「여기서 새 묶음이 시작된다」는 것이 눈에 바로 보입니다.
- 카드에는 이미 테두리가 있어서, 그 사이에 선까지 넣으면 화면이 복잡해 보입니다.
- 헤더 아래와 푸터 위의 선은 「사이트의 틀」과 「본문」을 나누는 역할이라 모든 화면에서 같은 뜻을 가집니다. 그래서 이 두 곳만 남깁니다.
- 앞으로 새 섹션을 추가할 때도 「선을 넣을까 말까」를 고민할 필요 없이 간격 값만 지키면 됩니다.

### 6-3. 권장안: 공통 빈 카드 틀 하나

모든 빈 카드(프라임·픽·베이직)에 아래 틀 하나를 씁니다.

| 항목 | 값 |
|---|---|
| 안쪽 여백 | 좌우 16px / 상하 20px로 모두 같게 |
| 텍스트 배치 | 제목 1줄 + 버튼, 모든 유형에서 같게 |
| 카드 사이 간격 | 12px로 통일 |
| 문구 | 가장 좁은 카드(픽, 약 190px)에서도 줄이 꺾이지 않는 짧은 고정 문구 |

- 버튼도 모든 유형에 똑같이 두면 사용자가 「빈 자리는 이렇게 생겼다」는 것을 한 번에 알아봅니다.
- 지역 표기는 확정된 비회원 규칙에 따라 **「서울시 강남구」**로 통일해야 합니다.
