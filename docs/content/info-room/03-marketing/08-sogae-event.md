# 소개 이벤트, 부담 없이 설계하기

이 글에서 알 수 있는 것
- 소개 보상의 한계 정하기
- 학부모·아이 모두에게 공정하게
- 운영·세무와 맞추기

## 이벤트가 운영을 흔들지 않게

과한 할인·현금성 보상은 기대만 키우고 재등록을 왜곡할 수 있습니다. 「상담권·교재 일부·수업 1회」처럼 감당 가능한 보상을 고르세요.

## 규칙

기간, 대상, 중복 여부, 종료 조건을 서면으로. 중간에 바꾸면 불만이 납니다.

## 표시

이벤트 광고에도 교습 관련 필수 표시가 필요할 수 있습니다. (기준일 2026-11, 확인 필요 시 관할 교육지원청)

## 공정

기존 원생만 소외되지 않게. 소개자·피소개자 모두 조건을 명시하세요.

## 종료 후

효과(상담 수·등록 수)를 기록하고, 상시화할지 판단하세요.

## 실제 사례로 정리해 보기

예시로, 원장님 H씨는 「한 명 소개 시 한 달 무료」를 했다가 정산이 붕괴됐습니다. 이후 교재비 일부 지원으로 바꾸자 운영이 버텼습니다. 예시입니다.

## 점검하며 한 걸음 더

이벤트 문구는 상담 대본과 같은 폴더에 두어 말이 갈리지 않게 하세요.
