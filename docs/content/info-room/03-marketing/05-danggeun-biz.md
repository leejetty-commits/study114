# 당근 비즈프로필로 동네에 알리기

- 금지·주의 표현

## 동네 채널의 성격

생활 밀착 앱은 「가까운 정보」를 기대합니다. 과장 광고보다 위치·과목·상담 방법이 명확한 소개가 맞습니다.

## 프로필

상호, 지역, 수업 대상, 문의 시간. 필수 표시(교습비·신고번호 등)가 광고에 해당하면 넣어 주세요. (기준일 2026-11, 확인 필요 시 관할 교육지원청)

## 게시 빈도

같은 글 도배는 신고 대상이 되기 쉽습니다. 주 단위·시즌 단위로.

## 매너

타 업체 비하, 허위 후기 유도, 개인 연락처 난립은 피하세요.

## 연결

문의가 오면 상담 대본·플레이스 정보와 같게 답하세요. 채널마다 말이 다르면 신뢰가 깨집니다.

## 실제 사례로 정리해 보기

예시로, 원장님 E씨는 매일 동일 홍보 글을 올려 제재를 받았습니다. 주 1회 정보형 글로 바꾸자 문의 질이 좋아졌습니다. 예시입니다.
