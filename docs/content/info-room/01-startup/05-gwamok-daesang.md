# 과목·학년·수업 형태부터 정하기

이 글에서 알 수 있는 것
- 포지션을 좁혀야 상담이 쉬워지는 이유
- 학년·시간대·정원 설계 요령
- 신고 과목과 실제 수업의 맞추기

## 다 가르치겠다는 함정

초보 원장님이 흔히 빠지는 함정은 「전 학년·전 과목」입니다. 포지션이 넓으면 교재·시간표·홍보 문구가 흐려집니다. 먼저 「가장 잘 가르치는 한 줄」을 정해 보세요. 예: 초등 고학년 수학 개념, 중등 영어 독해 등.

## 대상과 시간대를 같이 설계

하원 후 초등, 야간 중등, 주말 특강은 동선과 피로도가 다릅니다. 본인 생활 리듬과 가족 공간 사용 시간을 겹쳐 보면 가능한 슬롯이 보입니다. 같은 시간 정원은 행정 상한과 실제 지도 가능 인원 중 작은 쪽을 따르세요. (기준일 2026-11, 확인 필요 시 관할 교육지원청)

## 수업 형태 고르기

1:1, 소그룹, 단기 집중은 교습비·준비물·상담 방식이 달라집니다. 오픈 초기에는 형태를 한두 가지로 단순화하는 편이 운영 실수가 적습니다.

## 신고 내용과 맞추기

실제로 가르칠 과목·대상이 신고·게시 내용과 어긋나지 않게 정리하세요. 형태(개인과외·교습소)에 따라 과목 수 제한 안내가 있을 수 있습니다. ※ 지역·시점에 따라 다를 수 있어요. (기준일 2026-11, 확인 필요 시 관할 교육지원청)

## 한 학기 로드맵

진단 → 목표 합의 → 진도 → 평가 주기를 한 장으로 만들어 두면 상담 때 「우리 공부방은 이렇게 진행합니다」라고 설명하기 쉽습니다.

## 실제 사례로 정리해 보기

예시로, 원장님 E씨는 「초4~초6 수학, 주중 16–20시, 같은 시간 3명」으로 범위를 좁힌 뒤 상담 전환율이 안정되었습니다. 범위를 넓히고 싶을 때는 한 학기 단위로 실험해 보세요. 예시입니다.

## 점검하며 한 걸음 더

포지션 문장은 명함·상담 첫마디·게시 문구에 그대로 쓸 수 있게 짧게 다듬어 두시면 좋습니다.

- [ ] 정원과 행정 상한을 비교했나요
