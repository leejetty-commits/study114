# 인테리어와 동선, 가정과 수업 공간 나누기

이 글에서 알 수 있는 것
- 예쁜 학원보다 수업 가능한 구획

- 상담이 쉬운 공간 설명

## 목표가 「예쁜 학원」이 아니어도 됩니다

오픈 초기 인테리어는 사진용보다 「아이가 앉고, 보호자가 기다리고, 가족이 지나가는」 동선이 핵심입니다. 고가 리모델링보다 구획·좌석·시야부터 잡으세요.

## 구역을 세 칸으로

수업 존, 가정 존, 출입·대기 존을 테이프나 러그로라도 구획해 보세요. 가족이 오가는 동선과 수업 시선이 겹치면 산만해집니다. 문은 부드럽게, 바닥은 미끄럽지 않게 점검하세요.

## 소음과 이웃

읽기 소리, 의자 끌림, 초등 저학년 움직임이 복도·아래층에 전달될 수 있습니다. 수업 시간대와 의자캡·매트를 같이 설계하세요. 민원 예방은 홍보보다 먼저입니다.

## 수납과 교구

오늘 쓸 교구만 책상에, 나머지는 닫힌 수납에 두면 시야가 정리됩니다. 라벨을 붙이면 보강·대타 상황에서도 찾기 쉽습니다.

## 조명·공기·온도

눈부심·그늘·환기를 아이 앉은 높이에서 확인해 보세요. 겨울 건조·여름 더위는 집중력과 직결됩니다. 전기 용량·전열기 사용은 안전 목록에 넣으세요.

## 실제 사례로 정리해 보기

예시로, 원장님 I씨는 거실 한쪽을 커튼으로 구획하고 의자캡·매트를 먼저 적용했습니다. 고가 리모델링 없이도 수업 공간 느낌이 살아 상담 때 설명하기 쉬워졌습니다. 예시입니다.
