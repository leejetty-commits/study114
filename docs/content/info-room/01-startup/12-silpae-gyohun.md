# 창업 초반에 자주 겪는 실수와 보완

이 글에서 알 수 있는 것
- 장소·인원·표시에서 자주 나는 실수
- 실수를 발견했을 때 당장 할 일
- 같은 실수를 달력으로 막는 방법

## 실수 목록을 유형으로 나누기

초반 실수는 보통 네 갈래입니다. 장소를 추측으로 계약하기, 같은 시간 인원을 넘기기, 게시·광고 표시를 미루기, 변경을 미루다 기한을 넘기기. 유형을 나누면 보완 순서가 보입니다. (기준일 2026-11)

상가·오피스텔은 개인과외 장소로 불가입니다. 「실제로 거주한다」「다른 집도 한다」는 말은 근거가 되지 않습니다. 계약금 전에 건축물대장과 관할 확인을 넣으세요.

## 인원·과목에서 막힐 때

보강생·형제 동반으로 같은 시간 인원이 늘어나는 경우가 많습니다. 교습소는 1과목만 교습해야 하고(법 제14조 제7항), 같은 시간 9명 이하(피아노 5명)·㎡당 0.3명 이하를 지켜야 합니다(시행령 제16조). 출석부에 같은 시간 칸을 만들어 초과를 즉시 보이게 하세요.

상담에서는 전과목을 말하고 신고는 한 과목만 하는 불일치도 잦습니다. 실제 수업·게시·신고 문장을 같게 맞추세요.

## 표시·반환·변경을 미루지 않기

교습비·반환 게시와 광고 필수 표시를 「나중에」로 미루면 민원이 먼저 옵니다. 필수 표시가 빠진 광고는 민원이나 시정 요구로 이어질 수 있습니다. 반환은 시행령 제18조 제3항·별표 4에 따라 반환사유 발생일부터 5일 이내에 처리해야 합니다.

신고 사항(과목·장소·교습비등 등)이 바뀌면 사유 발생일부터 15일 이내에 변경신고해야 합니다. 이사·인상 날짜를 달력에 사유 발생일로 표시하세요.

## 발견 즉시 할 일

추측으로 변명하지 말고, 관할·세무 등 해당 창구에 사실을 확인하세요. 위반 가능 상태를 발견하면 수업 배치를 먼저 안전하게 조정하고, 서류·게시를 같은 날 목록으로 만드세요. 과태료·처분 결과는 사안마다 달라 단정하지 않습니다.

## Q&A

Q. 이미 오피스텔 계약을 했다면?  
A. 개인과외로는 불가 가능성이 큽니다. 관할 확인 후 계약 해지·형태 변경을 전문가·당사자와 협의하세요.

Q. 인원을 하루만 초과했다면?  
A. 관행으로 넘기지 말고 보강 슬롯을 분리하세요. 기록이 남으면 지도 때 설명이 필요합니다.

### 체크리스트

- [ ] 장소 용도를 관할 메모로 남겼나요
- [ ] 같은 시간 인원 칸을 출석부에 넣었나요
- [ ] 게시·광고 필수 표시를 점검했나요
- [ ] 반환 5일·변경 15일을 달력에 넣었나요
- [ ] 실수 발견 시 확인처를 적어 두었나요
- [ ] 상담·신고·게시 문장을 대조했나요

## 원장님 M씨의 출석부 칸

원장님 M씨는 보강생을 끼워 넣다 같은 시간 인원을 넘길 뻔한 뒤, 출석부에 「동시」 칸을 만들고 보강 전용 저녁 슬롯을 열었습니다. 광고 문구도 필수 표시 점검 전에는 올리지 않기로 했습니다.

실수를 숨기기보다 기록을 고치는 편이 다음 학기를 살립니다. 달력과 출석부가 가장 싼 보험입니다.

## 실수 로그

날짜, 유형(장소·인원·표시·기한), 조치, 재발 방지 한 줄을 표로 남기세요. 사례로, 원장님 M2씨는 실수 로그를 주 1회 읽고 같은 유형이 두 번 나오면 규칙을 문서에 승격합니다. 숨기지 않는 기록이 다음 학기 매뉴얼이 됩니다.

관할 확인 메모를 중개사·가족과 공유하면 「그때 다르게 들었다」는 갈등이 줄어듭니다. 추측 변명 대신 확인처를 적는 습관을 들이세요.

## 재발 방지 승격

같은 유형의 실수가 두 번 나오면 개인 메모가 아니라 문서 규칙으로 올립니다. 출석부 동시 칸, 광고 필수 표시 체크, 변경 달력이 그 예입니다. 실수 로그에는 변명 대신 조치와 확인처만 적습니다.

중개사·가족에게 관할 메모를 공유하면 「다르게 들었다」는 갈등이 줄어듭니다. 이미 계약한 오피스텔이 있다면 개인과외 불가를 전제로 협의 옵션을 전문가와 나눕니다. 숨긴 실수는 다음 학기에 더 큰 비용이 됩니다.

실수 유형별 예방 문장을 입구에 짧게 붙여 두세요. 「동시 인원 확인」「표시 점검」「관할 메모」처럼 세 줄이면 충분합니다. 길게 쓰면 읽지 않습니다.

이미 발생한 문제는 숨기지 말고 확인처·조치·재발 방지를 같은 날짜에 적습니다. 계약·광고·출석 중 어디에 영향이 있는지도 표시하면 우선순위가 보입니다. 과태료·처분 결과는 사안마다 달라 단정하지 않습니다.

사례로, 원장님 M3씨는 표시 누락 민원 후 광고 예약 기능을 끄고 수동 점검으로 바꿨습니다. 실수 로그를 주 1회 읽는 습관이 매뉴얼을 키웁니다.

입구에 「동시 인원 / 표시 점검 / 관할 메모」 세 줄만 붙여 실수 유형을 매일 상기하세요. 발생한 문제는 확인처·조치·영향 범위(계약·광고·출석)를 같은 날짜에 적습니다. 같은 유형이 두 번이면 규칙을 문서로 승격합니다. 이미 계약한 불가 장소가 있으면 전문가와 협의 옵션을 나누고 추측 변명을 멈춥니다. 처분 결과는 단정하지 않습니다.

장소 후보 목록을 갱신할 때는 상가·오피스텔을 먼저 지운 뒤 남은 주소만 관할에 묻습니다. (12-silpae-gyohun:1497) 하루에 몰아보면 놓치기 쉬워, 요일별 한 항목만 끝내는 방식이 안정적입니다. (12-silpae-gyohun:1494)  보호자 안내 문장을 바꿀 때는 게시·신고 문장과 소리 내어 대조한 뒤에 보냅니다. (12-silpae-gyohun:1496) 기록이 얇은 주에는 신규 특강·대규모 홍보를 넣지 않고 리듬을 회복하는 데 집중합니다. (12-silpae-gyohun:1498)  12-silpae-gyohun 주간 점검에서는 관할·게시·인원·반환·광고 표시를 서로 다른 요일에 나눠 확인합니다. (12-silpae-gyohun:1493)
