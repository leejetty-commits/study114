# 교습비 정하기와 게시·변경 의무

이 글에서 알 수 있는 것
- 교습비 산정 시 넣을 항목
- 게시·고지·영수증과 연결된 의무
- 변경 시 신고 타이밍

## 가격은 운영과 행정의 교차점

교습비는 수익 문제이면서 동시에 게시·신고 대상입니다. 「주변보다 싸게」만으로 정하면 반환·시간 단가·준비 시간이 무너지기 쉽습니다. 수업 시간, 준비·채점 시간, 교재·공간비를 나눠 단가를 적어 보세요.

## 게시와 안내

교습비와 반환 기준을 학습자가 보기 쉬운 곳에 게시하고, 요청 시 서면으로 안내하는 흐름이 강조됩니다. 인터넷·인쇄 광고에도 교습비·신고번호·과목 표시가 필요하다는 안내가 있습니다. (기준일 2026-11, 확인 필요 시 관할 교육지원청)

## 반환 기준을 함께 설계

반환은 시행령 별표 등 기준에 따르는 안내가 있습니다. 시작 전·진행 중 구간별 비율을 게시표에 맞춰 두시고, 상담 때 미리 설명해 분쟁을 줄이세요. 구체 비율·기한은 최신 법령·관할 안내를 확인하세요. ※ 지역·시점에 따라 다를 수 있어요.

## 변경할 때

교습비 변경은 변경신고 기한(사유 발생 후 일정 일수 이내)과 연결되는 안내가 많습니다. 올리기 전에 학부모 사전 안내 일정도 같이 잡으세요. (기준일 2026-11, 확인 필요 시 관할 교육지원청)

## 단가표 만드는 팁

「주 N회·회당 M분·월 패키지」를 표로 만들고, 체험·교재비·기타 경비를 구분해 적으면 게시·상담이 일치합니다. 기타 경비는 실비 원칙 안내를 참고하세요.

## 실제 사례로 정리해 보기

예시로, 원장님 F씨는 월 수강료만 口头 안내하다 반환 문의에서 설명이 길어졌습니다. 이후 게시표와 상담 체크리스트에 반환 요지를 넣었더니 질문이 줄었습니다. 예시입니다.

## 점검하며 한 걸음 더

가격표는 홍보물보다 먼저 「내부 운영 문서」로 완성하세요. 그다음 게시·상담 멘트에 복제하면 실수가 줄어듭니다.

### 체크리스트

- [ ] 시간·준비비 반영 단가를 짰나요
- [ ] 교습비·반환 게시표를 준비했나요
- [ ] 광고 필수 표시를 확인했나요
- [ ] 변경신고 절차를 알아 두었나요
- [ ] 영수증·수납 흐름을 정했나요
- [ ] 상담 때 설명할 문장을 적었나요
