# 학원법과 시·도 조례, 원장이 볼 핵심만

이 글에서 알 수 있는 것
- 전국 공통 의무와 조례 특수 규칙을 표로 나누는 법
- 야간·휴일 제한을 단정하지 않는 이유
- 관할에 예·아니오로 물을 조건을 한 장에 모으는 습관

## 두 칸으로 나누어 보기

학원법 공통 의무와 조례 특수 규칙을 표의 왼쪽·오른쪽으로 나누면 상담 때 단정이 줄어듭니다. 블로그 요약은 운영 문서에 붙이지 말고, 시·도 누리집 안내문·유선 확인 요지만 남기세요. (기준일 2026-11)

조례 안내문에는 확인 날짜를 크게 적습니다. 조례가 바뀌면 출력일과 파일 저장일을 같게 맞춰 착각을 줄이세요. 야간·휴일 시각은 관할 확인 전에는 홍보 문장에 넣지 않습니다.

## 공통으로 자주 묻는 것

같은 시간 10명 이상이면 학원에 해당할 수 있습니다(시행령 제2조 제2항). 교습소는 강사를 둘 수 없는 범위가 있습니다(시행령 제15조 제2항·제3항). 개인과외교습자는 신고 사항이 바뀌면 사유 발생일부터 15일 이내에 변경신고해야 합니다. 반환사유 발생일부터 5일 이내 반환, 게시·광고 필수 표시도 공통으로 자주 확인합니다.

상가·오피스텔은 개인과외 장소로는 불가인 경우가 많으니, 조례만 보고 장소를 단정하지 마세요. 교습자 주거지 수업이면 신고증명서를 게시해야 하고, 학습자 주거지 수업이면 요청 시 제시해야 합니다(법 제14조의2 제5항).

## 사례: 원장님 N씨의 야간 단정

원장님 N씨는 온라인 후기만 보고 「밤 열 시까지 가능」라고 홍보했다가 관할 안내와 달랐습니다. 이후에는 야간 제한을 앞면 카드가 아니라 뒷면 확인 항목으로만 두고, 예·아니오로 답할 조건을 한 장에 모아 관할에 가져갔습니다. 확인 날짜를 안내문에 크게 적어 보호자 설명도 통일했습니다.

## 질문지를 예·아니오로

질문이 생기면 예·아니오로 답할 수 있게 조건·주소·형태·시간대를 한 장에 모으세요. 일반적으로라는 표현은 운영 문서에서 빼세요. 출처 불명 요약은 붙여 넣지 않습니다.

## 마무리 한 걸음

공통 칸과 조례 칸을 나누고, 확인 날짜를 크게 남기세요. 야간·휴일·면적·인원은 관할 확인 전 홍보에 넣지 마세요. 법령 조항 번호는 원문을 열어 확인하고, 이 글에 없는 과태료 금액을 단정하지 마세요. 담당이 바뀌어도 이전 요지를 인용하면 설명이 이어집니다.

## 홍보 전 확인 습관

담당이 바뀌면 이전 통화 날짜와 조건을 먼저 읽고 바뀐 점만 물으세요. 확인 전 홍보 문장에 시각·면적·인원을 넣지 않습니다. 막연한 표현은 운영 문서에서 빼세요.

조례 PDF에는 출력일과 적용 범위를 함께 적습니다. 이웃 시·도 기준은 참고만 하고 우리 관할로 다시 확인하세요. 과태료 금액을 이 글에 없는 숫자로 단정하지 마세요. 질문지 한 장이 전화 세 번보다 빠릅니다.

앞면 카드에는 확인된 문장만 두고 야간 제한은 뒷면 확인 칸에 두세요. 출처 불명 요약은 붙여 넣지 않습니다. 원문을 열어 조항 번호를 확인한 뒤에만 상담 스크립트에 옮기세요.

## 바로 적용

조례 확인 전 질문지를 사진으로 보내고, 통화 후 요지를 출력일 옆에 적으세요. 야간·휴일 시각은 뒷면 확인이 끝나기 전 홍보에 넣지 않습니다. 공통 의무와 조례 규칙을 한 문단에 섞어 쓰지 마세요.

상담 스크립트에는 원문을 연 뒤에만 조항을 옮깁니다. 과태료·처분 금액은 확인 전 숫자로 말하지 않습니다. 막연한 표현은 운영 문서에서 삭제합니다.

이웃 시·도 기준은 참고만 하고 우리 관할로 다시 확인하세요. 담당이 바뀌면 이전 통화 날짜와 조건만 인용합니다.

## 운영 노트

조례 안내문과 학원법 공통 표를 따로 철하세요. 확인 날짜가 없는 요약은 폐기합니다. 야간 시각을 홍보에 넣기 전 뒷면 확인 칸을 채우세요.

질문지 없이 조례 전화를 걸지 마세요. 예·아니오로 받을 조건을 먼저 적습니다. 과태료 금액을 스크립트에 넣지 말고 확인처만 둡니다. 전국 공통처럼 말하는 습관을 막기 위해 조례 칸을 오른쪽으로 고정합니다.

## 요일 루틴

월요일에 조례 출력일과 파일 저장일을 맞추고, 화요일에 야간·휴일 홍보 문장을 검색해 삭제 후보를 표시합니다. 수요일에 예·아니오 질문지를 한 장으로 갱신합니다.

목요일에 공통 의무 칸과 조례 칸을 분리해 읽고, 금요일에 확인처만 남긴 메모를 정리합니다. 주말에는 다른 시·도 후기를 운영 문서에 붙이지 마세요.

## 습관 한 가지

조례 관련 홍보 초안이 생기면 게시 전에 뒷면 확인 칸을 의무로 열게 하세요. 칸이 비어 있으면 초안을 저장만 하고 배포하지 않습니다. 확인 날짜가 생긴 뒤에만 앞면 문장으로 올립니다.

조례 확인 통화는 질문지 사진을 보낸 뒤에만 걸으세요. 준비 없는 통화는 단정을 부릅니다.

조례 홍보 초안은 뒷면 확인 칸이 채워지기 전 배포하지 마세요. 저장만 하고 배포는 확인 날짜 이후로 미룹니다. 질문지 사진을 보낸 뒤에만 통화하세요. 막연한 표현은 삭제합니다. 공통 의무와 조례 규칙을 한 문단에 섞지 마세요. 과태료 금액을 스크립트에 넣지 않습니다.

## Q&A

Q. 조례 PDF만 있으면 충분한가?  
A. 출력일·적용 범위를 확인하고, 애매하면 유선 요지를 같은 장에 적으세요.

Q. 이웃 시·도 기준을 참고해도 되나?  
A. 참고는 가능하나 우리 관할 기준으로 다시 확인하세요.
