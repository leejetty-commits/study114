# 성범죄 경력 조회와 아동학대 예방

이 글에서 알 수 있는 것
- 신고 단계의 조회 동의 의미
- 일상 수업에서 지키는 예방 원칙
- 의심 상황 시 연락·기록 흐름

## 조회는 시작점

개인과외교습자 신고에 성범죄 경력 조회 동의서가 포함되는 안내가 많습니다. 아동학대 관련 전력 조회 범위는 지역 안내를 확인하세요. 통과 후에도 예방 원칙은 계속됩니다. (기준일 2026-11, 확인 필요 시 관할 교육지원청)

## 수업 중 경계

과도한 신체 접촉 금지, 단둘 공간 원칙, 문 개방·시야 확보, 메신저 예절, 사진·영상 동의 없는 촬영 금지를 규칙으로 적으세요.

## 언어와 훈육

수치심을 주는 말, 차별, 협박성 훈육은 학습 효과를 떠나 위험합니다. 허용되는 지도 방식을 문장으로 정해 두세요.

## 의심·신고 흐름

아이 상태 이상, 학대 의심 시 어디에 연락할지(보호자·경찰·아동보호 기관 등) 사전 학습이 필요합니다. 이 글은 법률 자문이 아니며 구체 번호는 공식 안내를 따르세요.

## 기록

특이 행동·상담 내용은 사실 중심으로 짧게 남기되, 추측·낙인은 피하세요. 보관 보안에도 주의합니다.

## 실제 사례로 정리해 보기

예시로, 원장님 T씨는 조회만 끝내고 규칙을 문서로 안 만들었다가, 보조 없이 단둘 공간이 길어지는 상황을 인지하고 문 개방·CCTV 시야 규칙을 추가했습니다. 예시입니다.

## 점검하며 한 걸음 더

예방 원칙은 학부모에게도 공유하면 「우리 공부방의 안전 약속」이 됩니다. 신뢰를 높이는 재료입니다.

- [ ] 신체·촬영·메신저 규칙을 적었나요
- [ ] 문·시야 확보를 점검했나요
