# 학부모 불만·민원, 첫 대응 순서

이 글에서 알 수 있는 것
- 감정 분리와 사실 확인
- 응대 스크립트
- 외부 창구로 가기 전 내부 정리

## 첫 10분이 방향을 정합니다

불만 전화·문자가 오면 반박부터 하지 마세요. 「말씀 주셔서 감사합니다 → 사실 확인 → 회신 시간 약속」이 안전합니다.

## 사실 체크

출결·요금·안내 문자·게시 내용·상담 기록을 먼저 모으세요. 기억이 아니라 기록으로 답합니다.

## 선택지

설명 / 조정(보강·상담) / 반환 안내 / 상위 기관 안내. 반환은 게시 기준을 따르고 즉흥 할인으로 덮지 마세요. (기준일 2026-11, 확인 필요 시 관할 교육지원청)

## 톤

학부모·아이를 탓하는 말, 타 원생과 비교는 금물. 해결 가능한 범위만 약속하세요.

## 기록·에스컬레이션

응대 로그를 남기고, 반복·법적 분쟁 조짐이면 교육지원청·소비자 상담 등 공식 안내를 확인하세요. ※ 지역·시점에 따라 다를 수 있어요.

## 실제 사례로 정리해 보기

예시로, 원장님 Q씨는 즉시 반박 문자를 보내 갈등이 커졌습니다. 이후 「오늘 중 확인 후 연락」 템플릿을 쓰자 감정 온도가 내려갔습니다. 예시입니다.

## 점검하며 한 걸음 더

불만 유형별(요금·지도·안전·일정) 모의 답변을 미리 적어 두면 급할 때 도움이 됩니다.
