# 숙제와 피드백, 부담 없이 루프 만들기

이 글에서 알 수 있는 것
- 숙제량의 기준
- 빠른 피드백 루틴
- 미이행 때 대응

## 숙제는 싸움이 아닙니다

양을 많이 낼수록 학습이 된다는 보장은 없습니다. 「오늘 수업과 직접 연결된 20–30분」이 유지되기 쉽습니다.

## 형식

필수 / 선택 / 도전으로 나누면 수준 차가 큰 그룹에서도 운영이 됩니다.

## 피드백

다음 수업 시작 5분에 공통 오답만 다루고, 개별은 한 줄 메모. 늦은 장문 첨삭이 밀리면 루프가 끊깁니다.

## 미이행

원인(일정·난이도·습관)을 물은 뒤 양을 조정하세요. 처벌 중심은 관계가 먼저 상합니다.

## 학부모

채점 대행을 부탁하기보다 「환경(자리·시간)」 협조를 요청하는 편이 현실적입니다.

## 실제 사례로 정리해 보기

예시로, 원장님 M씨는 매일 많은 숙제를 내다 미이행이 기본값이 됐습니다. 필수 2문항으로 줄이자 완성률과 수업 집중이 같이 올랐습니다. 예시입니다.

## 점검하며 한 걸음 더

숙제 정책은 상담 때 한 번 말하고, 월 1회 짧게 재안내하세요.

### 체크리스트

- [ ] 숙제 시간 기준이 있나요
- [ ] 필수·선택을 나누나요
- [ ] 빠른 피드백 슬롯이 있나요
- [ ] 미이행 질문을 준비했나요
- [ ] 학부모 협조 문안이 있나요
- [ ] 양을 주기적으로 재검토하나요
