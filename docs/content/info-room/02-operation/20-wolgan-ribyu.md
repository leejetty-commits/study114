# 월간 운영 리뷰, 숫자와 느낌을 같이

이 글에서 알 수 있는 것
- 볼 지표 고르기
- 한 시간 리뷰 진행표
- 다음 달 실험 하나

## 리뷰가 없으면 반복만 합니다

바쁘면 같은 문제가 매월 돌아옵니다. 월말 60–90분 「운영 리뷰」를 달력에 고정하세요.

## 지표 예시

정원 대비 출석, 보강 횟수, 미납 건수, 상담→등록, 재등록/퇴원 사유. 숫자는 지역마다 달라 목표를 단정하지 마세요. ※ 지역·시점에 따라 다를 수 있어요.

## 느낌 지표

피로도, 가족 갈등, 안전 아차 사고. 숫자만 보면 번아웃을 놓칩니다.

## 결정

다음 달 「그만할 것 하나 / 시작할 것 하나」만 정하세요. 목록이 길면 실행이 안 됩니다.

## 기록

리뷰 노트를 남기면 분기·방학 설계가 쉬워집니다.

## 실제 사례로 정리해 보기

예시로, 원장님 T씨는 느낌으로만 「장사 안 된다」고 말하다 출석 데이터를 보니 특정 요일만 문제였습니다. 그 요일 시간표를 고치자 전체가 안정됐습니다. 예시입니다.

## 점검하며 한 걸음 더

리뷰 날은 수업·상담을 최소화해 보호하세요.

### 체크리스트

- [ ] 월말 리뷰를 잡았나요
- [ ] 지표 목록이 있나요
- [ ] 피로·안전을 보나요
- [ ] 다음 달 실험 하나를 정하나요
- [ ] 노트를 남기나요
- [ ] 실행 여부를 다음 달에 확인하나요
