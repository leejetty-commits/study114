# 학부모 소통 주기, 과하지 않게 꾸준히

이 글에서 알 수 있는 것
- 소통 주기를 미리 공지하는 이유
- 채널별(문자·통화·대면) 역할 나누기
- 급한 일과 정기 보고를 구분하는 법

## 주기가 없으면 불안이 커집니다

연락이 들쭉날쭉하면 학부모는 「무언가 숨기는 것 같다」고 느끼기 쉽습니다. 반대로 매일 장문 보고는 1인 원장 체력을 깎습니다. 등록 때 「월 1회 학습 메모 + 필요 시 수시」처럼 주기를 문서로 약속하세요.

## 채널을 나눕니다

등하원 실무는 짧은 문자, 학습 피드백은 주간/월간 메모, 갈등·반환은 통화·대면이 안전합니다. 심야 응답 가능 시간도 정해 두면 경계가 생깁니다.

## 정기 보고에 넣을 것

한 달 진도, 잘한 점 하나, 보완 점 하나, 다음 달 초점, 숙제 협조 부탁. 성적 단정·비교는 피하세요.

## 수시 연락 기준

결석·지각 반복, 건강·안전, 숙제 공백, 태도의 급변이 보이면 주기를 기다리지 마세요. 「사실-관찰-제안」 세 줄이면 충분합니다.

## 기록

보낸 날짜와 요지를 남기면 나중에 「말씀드렸는데요」 논쟁을 줄입니다.

## 실제 사례로 정리해 보기

예시로, 원장님 B씨는 문의가 올 때만 답하다 신뢰가 흔들렸습니다. 매월 마지막 주 금요일 「학습 한 줄 메모」를 보내기 시작하자 중간 질문이 줄었습니다. 예시입니다.

## 점검하며 한 걸음 더

소통 약속은 상담 대본·등록 안내에 같은 문장으로 넣어 두세요.

### 체크리스트

- [ ] 주기 약속을 문서로 했나요
- [ ] 채널별 역할을 나눴나요
- [ ] 정기 보고 양식이 있나요
- [ ] 수시 연락 기준을 정했나요
- [ ] 응답 가능 시간을 안내했나요
- [ ] 발송 기록을 남기나요
