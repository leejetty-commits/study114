# 출결·보강 규칙, 처음부터 분명히

이 글에서 알 수 있는 것
- 출결 기호와 기록 습관
- 보강 가능·불가 기준
- 학부모 안내 문안

## 기록이 신뢰를 만듭니다

출석은 수납·보강·안전의 기준점입니다. 출석·지각·결석·보강 완료를 기호로 통일하고, 매주 같은 요일에 대조하세요.

## 보강 정책 예시

사전 연락 결석만 보강, 당일 노쇼는 보강 제한, 보강은 지정 슬롯만, 월 N회 상한. 숫자는 원장님 여유에 맞게 정하고 등록 때 고지하세요. 반환·교습비 규정과 모순되지 않게 맞추세요. (기준일 2026-11, 확인 필요 시 관할 교육지원청)

## 시간표와 인원

보강이 정규 슬롯 인원을 넘지 않게 여유 칸을 두세요. 동시 인원 상한과도 맞춰 보세요. ※ 지역·시점에 따라 다를 수 있어요.

## 알림

결석 접수→기록→보강 후보 일자 제안→확정 문자 순서를 스티커로 붙여 두세요.

## 분쟁 예방

「보강 = 권리」처럼 오해되지 않게, 가능 조건과 기한을 게시·안내에 같게 적습니다.

## 실제 사례로 정리해 보기

예시로, 원장님 D씨는 보강을 그때그때 약속하다 슬롯이 붕괴됐습니다. 월 2회·사전 연락 원칙을 문서화한 뒤 안정됐습니다. 예시입니다.

## 점검하며 한 걸음 더

출결표와 수납표를 한 폴더에 두면 월말 정산이 빨라집니다.
