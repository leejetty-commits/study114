# 수강료 미납 대응, 감정 없이 절차로

이 글에서 알 수 있는 것
- 미납을 일찍 발견하는 기록
- 단계별 안내 문안
- 수업 중단·반환과 연결 시 주의

## 감정이 개입하기 전에

미납 대화는 관계가 상하기 쉽습니다. 등록 때 납부일·방법·연체 시 안내 순서를 미리 알려 두면 「갑자기 독촉」이 아닙니다.

## 발견 루틴

수납 예정일과 입금 내역을 주 1회 대조하세요. 카드·이체·현금을 구분해 두면 누락을 빨리 찾습니다.

## 단계 안내

1차 짧은 리마인드 → 2차 통화 → 3차 서면 요약(금액·기간·연락처). 위협·모욕 표현은 금지. 법률 조치는 이 글 범위 밖이니 필요 시 전문가와 상담하세요.

## 수업과의 연결

미납 시 수업 일시 중지 여부를 사전에 정책하고 고지하세요. 반환 기준·영수증 의무와 충돌하지 않게 관할·세무 안내도 참고하세요. (기준일 2026-11, 확인 필요 시 관할 교육지원청)

## 기록

안내 일시·내용·상대 응답을 남겨 두면 이후 설명이 쉬워집니다.

## 실제 사례로 정리해 보기

예시로, 원장님 E씨는 두 달치가 쌓인 뒤에야 연락해 관계가 악화됐습니다. 이후 7일 연체 시 자동 리마인드 문자를 넣어 초기에 해결하는 비율이 늘었습니다. 예시입니다.

## 점검하며 한 걸음 더

미납 정책은 가격표·상담 대본과 같은 폴더에 두세요.

### 체크리스트

- [ ] 납부일을 공지했나요
- [ ] 주간 대조가 있나요
- [ ] 1·2·3차 문안이 있나요
- [ ] 수업 중지 정책을 고지했나요
- [ ] 안내 기록을 남기나요
- [ ] 과한 표현을 점검했나요
