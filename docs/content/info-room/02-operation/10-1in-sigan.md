# 1인 원장 시간관리, 수업 밖 일 챙기기

이 글에서 알 수 있는 것
- 수업·행정·휴식 블록 나누기
- 주간 행정 데이 만들기
- 거절과 위임의 기준

## 시간이 없으면 수업이 흔들립니다

1인 운영은 수업만으로도 하루가 끝납니다. 의도적으로 「행정 블록」을 시간표에 넣지 않으면 수납·게시·기록이 밀립니다.

## 주간 템플릿

수업 / 준비·채점 / 학부모 소통 / 행정·수납 / 휴식·이동. 비율은 계절에 따라 조정하되, 행정 0은 금지에 가깝습니다.

## 배치 처리

인쇄·구매·청소·문자 발송을 같은 요일에 몰아 「컨텍스트 스위칭」을 줄이세요.

## 거절

즉흥 보강·야간 상담 요청에 「가능 창구」를 안내하는 문장을 준비하세요. 거절이 아니라 일정 제안입니다.

## 건강

식사·수면·짧은 산책이 무너지면 수업 톤이 먼저 무너집니다. 비워 둔 슬롯을 「남는 시간」으로 채우지 마세요.

## 실제 사례로 정리해 보기

예시로, 원장님 J씨는 매일 자정에 채점하다 오전 수업이 흐려졌습니다. 화·목을 채점 전용 저녁으로 고정하자 품질이 돌아왔습니다. 예시입니다.

## 점검하며 한 걸음 더

할 일 앱보다 「이번 주 세 가지」 메모가 1인 원장에게 더 잘 맞는 경우가 많습니다.

### 체크리스트

- [ ] 행정 블록을 넣었나요
- [ ] 배치 처리 요일이 있나요
- [ ] 거절·제안 문안이 있나요
- [ ] 휴식 슬롯을 지켰나요
- [ ] 주간 세 가지를 적나요
- [ ] 야간 업무 상한을 정했나요
