# 학년·계절 전환 준비 체크

이 글에서 알 수 있는 것
- 학기 전환 때 바뀌는 것
- 커리큘럼·시간표 재배치
- 학부모 사전 안내

## 전환은 사건입니다

새 학기·새 학년은 교재·목표·하원 시간이 한꺼번에 바뀝니다. 2–3주 전 전환 체크리스트를 꺼내세요.

## 학습

이전 학기 공백 점검, 새 교과서 용어, 목표 재합의. 레벨 재확인이 필요하면 짧은 테스트로.

## 운영

시간표·요금·정원·특강 여부를 재고지. 변경신고 대상이면 일정을 잡으세요. (기준일 2026-11, 확인 필요 시 관할 교육지원청)

## 소통

「무엇이 같고 무엇이 바뀌는지」를 한 장으로 보내면 질문이 줄어듭니다.

## 원장님

전환기에 신규 모집과 기존 재정비를 동시에 욕심내지 마세요. 우선순위를 고르세요.

## 실제 사례로 정리해 보기

예시로, 원장님 U씨는 개학 주에 요금·시간표를 동시에 바꿔 문의가 폭주했습니다. 이후 변경을 주 단위로 나누자 응대가 가능해졌습니다. 예시입니다.

## 점검하며 한 걸음 더

작년 전환 메모가 있으면 올해가 절반으로 줄습니다. 꼭 남겨 두세요.
