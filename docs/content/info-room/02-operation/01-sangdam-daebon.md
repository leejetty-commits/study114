# 첫 상담 대본, 원장님이 놓치지 않을 순서

이 글에서 알 수 있는 것
- 상담을 단계로 나누는 이유
- 질문·설명·합의·기록의 순서
- 과장 없이 기대치를 맞추는 말

## 상담은 설득이 아니라 설계입니다

첫 상담에서 수강 여부를 급하게 결론내면, 나중에 「얘기가 달랐다」는 갈등이 생기기 쉽습니다. 상담의 목표는 학생의 현재·목표·가능 시간·교습비·반환 기준을 같은 그림으로 맞추는 일입니다. 대본은 외울 대사가 아니라 빠뜨리지 않을 순서표로 두세요.

## 추천 5단계

①인사·공간 안내 ②학습 현황 듣기 ③목표·기간 합의 ④수업 형태·요금·반환·일정 설명 ⑤다음 행동(체험/등록/보류) 확정. 각 단계 사이에 「지금까지 정리하면」 한 문장을 넣으면 학부모도 따라오기 쉽습니다. 교습비·반환은 게시 내용과 같게 말하세요. (기준일 2026-11, 확인 필요 시 관할 교육지원청)

## 들으며 적을 질문

최근 성적·숙제 습관·취약 단원·학교 일정·형제 여부·하원 시각을 메모하세요. 「왜 저희를 찾아오셨나요」보다 「최근에 가장 힘들었던 공부 장면」이 더 구체적입니다.

## 하지 말 말

무조건 성적 상승, 타 원 비하, 확인되지 않은 합격·경력 과장은 피하세요. 과정·주기·숙제 역할을 설명하는 편이 신뢰를 만듭니다.

## 기록 템플릿

상담일, 참석자, 합의 목표, 추천 슬롯, 미결 질문, 다음 연락일을 한 장에. 문자로 요약을 보내면 「말과 기록」이 같아집니다.

## 실제 사례로 정리해 보기

예시로, 원장님 A씨는 요금부터 말하다 학부모 질문이 길어졌습니다. 이후 5단계 순서표를 옆에 두고 현황→목표→요금 순으로 바꾸자 상담 시간이 짧아지고 등록 결정이 분명해졌습니다. 예시입니다.

## 점검하며 한 걸음 더

대본은 분기마다 한 문장씩만 고쳐도 충분합니다. 실제 상담에서 막힌 지점을 표시해 두세요.

### 체크리스트

- [ ] 5단계 순서표를 만들었나요
- [ ] 필수 고지(요금·반환)를 넣었나요
- [ ] 듣기 질문 목록이 있나요
- [ ] 금지 표현을 표시했나요
- [ ] 상담 기록 양식이 있나요
- [ ] 요약 문자 문안이 있나요
