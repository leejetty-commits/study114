# 퇴원 관리, 마지막 인상이 다음을 만듭니다

이 글에서 알 수 있는 것
- 퇴원 사유를 듣는 태도
- 행정·반환·기록 마감
- 재연락 가능 관계 남기기

## 퇴원을 실패로만 보지 않기

이사·일정·목표 변경도 퇴원 사유입니다. 방어보다 「무엇이 도움 됐고 아쉬웠는지」를 짧게 들으면 운영 개선 데이터가 됩니다.

## 행정 마감

남은 회차·수납·반환 기준을 게시표에 따라 계산·안내하고, 영수증·현금을 정리하세요. 구체 비율은 최신 기준을 확인하세요. (기준일 2026-11, 확인 필요 시 관할 교육지원청)

## 학습 인수인계

진도·교재·약점을 한 장으로 정리해 드리면 신뢰가 남습니다. 타 기관 비하는 금지.

## 개인정보

보관 기간이 끝난 연락처·기록 처리 원칙을 정해 두세요.

## 재방문

강제 영업 없이 「나중에 필요하면 상담 가능」 정도만 남겨도 충분합니다.

## 실제 사례로 정리해 보기

예시로, 원장님 L씨는 퇴원 연락에 감정적 반박을 했다가 소문이 안 좋게 퍼졌습니다. 이후 경청→행정→감사 인사 순서로 바꾸자 관계가 덜 상했습니다. 예시입니다.

## 점검하며 한 걸음 더

퇴원 체크리스트를 등록 체크리스트 옆에 두면 급할 때 실수가 줄어듭니다.

### 체크리스트

- [ ] 반환·수납 마감 절차가 있나요
- [ ] 진도 인수인계 양식이 있나요
- [ ] 개인정보 처리 원칙이 있나요
- [ ] 감사 인사 문안이 있나요
