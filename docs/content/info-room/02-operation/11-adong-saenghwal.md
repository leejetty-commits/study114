# 아이 안전·생활지도, 수업 전후의 약속

이 글에서 알 수 있는 것
- 등하원·대기 안전 규칙
- 언어·훈육의 허용 범위
- 학부모와 공유할 안전 약속

## 생활지도도 운영입니다

공부방은 학습만이 아니라 머무는 공간입니다. 신발·손 씻기·소지품·스마트폰·간식 규칙을 짧게 정해 첫날에 안내하세요.

## 안전

출입 확인, 문·시야, 위험물 보관, 응급 연락망을 운영 체크에 넣으세요. 성범죄·아동 보호 원칙과 연결해 문서로 둡니다. (기준일 2026-11, 확인 필요 시 관할 교육지원청)

## 훈육

수치심·협박·과도한 신체 접촉은 금지. 허용되는 지도(자리 이동, 짧은 휴식, 과제 재안내)를 명시하세요.

## 또래 갈등

사실 청취→분리→보호자 공유→재발 방지. 한쪽 말만 단정하지 마세요.

## 공유

「우리 공부방 안전·생활 약속」 한 장을 등록 때 주면 이후 지도가 수월합니다.

## 실제 사례로 정리해 보기

예시로, 원장님 K씨는 간식·스마트폰 규칙이 없어 수업 시작이 자주 늦었습니다. 첫날 약속표를 도입하자 전환이 빨라졌습니다. 예시입니다.

규칙은 많을수록 지키지 못합니다. 다섯 줄 이내로 줄이세요.
