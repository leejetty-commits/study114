# 레벨테스트, 짧게 보고 정확히 나누기

이 글에서 알 수 있는 것
- 테스트 목적과 시간 상한
- 결과 피드백 문장 만들기
- 수업 배치와 연결하는 법

## 테스트는 서열이 아닙니다

레벨테스트의 목적은 반 편성과 출발점 확인입니다. 점수로 아이를 줄 세우기보다, 「어디부터 다시 쌓을지」를 찾는 도구로 설명하세요.

## 구성 팁

기초 연산/독해 한 덩어리 + 최근 학교 범위 + 서술형 한 문항처럼 짧게. 40–50분을 넘기면 피로가 결과로 섞입니다. 시간은 원장님 과목에 맞게 조정하세요.

## 결과 말하기

점수만 주지 말고 「강점 / 공백 / 4주 초점」으로 말하세요. 학부모에게는 교재·슬롯 제안과 함께 전달합니다.

## 재테스트

8–12주 뒤 같은 형식의 짧은 점검으로 변화를 보면 상담이 쉬워집니다. 매월 전면 재시험은 과할 수 있습니다.

## 자료 보관

동의 범위 안에서 답안·메모를 보관하고, 불필요한 개인정보는 최소화하세요.

## 실제 사례로 정리해 보기

예시로, 원장님 C씨는 긴 시험을 치르다 아이가 지쳐 결과가 왜곡됐습니다. 이후 30분 압축 테스트로 바꾸자 배치 결정이 빨라졌습니다. 예시입니다.

## 점검하며 한 걸음 더

테스트 문항은 「수업에서 바로 쓰는 언어」와 같게 유지하세요.

### 체크리스트

- [ ] 목적 설명을 준비했나요
- [ ] 시간 상한을 정했나요
- [ ] 강점·공백·초점 양식이 있나요
- [ ] 재점검 주기를 정했나요
- [ ] 보관·동의 원칙이 있나요
- [ ] 배치 기준과 연결했나요
