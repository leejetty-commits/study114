# 등하원·대기 동선, 수업 밖의 운영

이 글에서 알 수 있는 것
- 등하원 혼잡 줄이기
- 대기 공간 규칙
- 보호자 확인 절차

## 문 앞이 브랜드입니다

수업이 좋아도 등하원이 혼란스러우면 신뢰가 깎입니다. 도착·시작·하원 시각을 슬롯별로 명확히 안내하세요.

## 혼잡 완화

시작 5분 전 입실, 하원 시차, 현관 대기 금지 구역을 정해 보세요. 집 공부방은 층간·이웃 배려가 특히 중요합니다.

## 보호자 확인

대리 하원 시 사전 연락·암호·명단 중 방법을 하나 고르세요. 아이 안전과 직결됩니다.

## 대기

형제 대기·일찍 온 보호자 자리를 시야 안에. 수업방과 시선·소음이 겹치지 않게.

## 악천후·지연

지각·교통 지연 연락 방법을 등록 안내에 넣으세요.

## 실제 사례로 정리해 보기

예시로, 원장님 O씨는 하원 시간에 복도가 붐벼 민원이 났습니다. 슬롯 종료를 5분 시차로 조정하자 밀도가 줄었습니다. 예시입니다.

## 점검하며 한 걸음 더

등하원 규칙은 생활 약속표와 한 장으로 합쳐도 좋습니다.

### 체크리스트

- [ ] 등하원 시각 안내가 있나요
- [ ] 혼잡 완화책이 있나요
- [ ] 대리 하원 절차가 있나요
- [ ] 대기 자리를 정했나요
- [ ] 지연 연락 방법이 있나요
- [ ] 이웃·소음을 점검했나요
