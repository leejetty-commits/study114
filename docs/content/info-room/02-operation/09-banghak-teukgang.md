# 방학 특강, 정규와 섞지 않고 설계하기

이 글에서 알 수 있는 것
- 방학 특강의 목적 한 줄 정하기
- 정규 수업과 시간·요금 분리
- 모집·운영·마무리 일정

## 특강은 별도 상품입니다

정규 진도를 방학에 몰아넣는 것과, 「약점 보완·선행 맛보기·습관 회복」 특강은 다릅니다. 목적 한 줄을 먼저 적고 커리큘럼·일수·요금을 맞추세요.

## 요금·게시

특강비·반환 기준을 정규와 구분해 게시·안내하세요. 변경이 있으면 신고 필요 여부를 관할에 확인하세요. (기준일 2026-11, 확인 필요 시 관할 교육지원청)

## 시간표

원장님 휴가·가족 일정을 먼저 막고 남은 칸에 특강을 넣으세요. 매일 종일 특강은 번아웃 위험이 큽니다.

## 모집

기존 원생 우선 + 외부 소수처럼 정책을 정하고, 정원·동시 인원 상한을 지키세요. ※ 지역·시점에 따라 다를 수 있어요.

## 마무리

특강 후 짧은 리포트와 정규 복귀 제안을 하면 연결이 자연스럽습니다.

## 실제 사례로 정리해 보기

예시로, 원장님 I씨는 정규 요금에 특강을 끼워 넣다 반환 문의가 헷갈렸습니다. 특강 전용 게시표를 만든 뒤 설명이 단순해졌습니다. 예시입니다.

## 점검하며 한 걸음 더

특강 이름은 내용이 보이게(예: 초등 분수 약점 5회) 지으세요.

### 체크리스트

- [ ] 목적 한 줄을 적었나요
- [ ] 요금·반환을 분리 게시했나요
- [ ] 관할 확인을 했나요
- [ ] 휴가 일정을 먼저 막았나요
- [ ] 정원을 지켰나요
- [ ] 마무리 리포트가 있나요
