# 반환·중도 해지 안내 실무

이 글에서 알 수 있는 것
- 게시 기준과 계산을 같게
- 안내 문서 구성
- 분쟁을 줄이는 사전 고지

## 즉흥 계산 금지

반환은 감정 합의가 아니라 게시된 기준을 적용하는 일에 가깝습니다. 상담·등록 때 반환 요지를 미리 설명하세요. (기준일 2026-11, 확인 필요 시 관할 교육지원청)

## 계산 체크

교습 시작 전/후, 경과 구간, 총 교습시간 정의를 내부 메모로 고정하세요. 구체 비율은 최신 법령·관할 안내를 확인하세요. ※ 지역·시점에 따라 다를 수 있어요.

## 안내 문안

사유 접수일, 적용 기준, 금액, 입금 일정, 문의 창구를 서면으로. 구두만으로 끝내지 마세요.

## 수납 자료

영수증·입금 내역과 맞는지 대조 후 안내하면 신뢰가 높습니다.

## 예외

원장님 사정으로 교습 불가 시 별도 기준이 있을 수 있으니 관할·법령을 확인하세요.

## 실제 사례로 정리해 보기

예시로, 원장님 R씨는 관행 할인으로 반환을 처리하다 다른 학부모와 형평 시비가 났습니다. 이후 게시표 기준으로 통일하자 설명이 쉬워졌습니다. 예시입니다.

## 점검하며 한 걸음 더

반환 계산 연습 문제(가상)를 직원·본인이 한 달에 한 번 풀어 보세요.

### 체크리스트

- [ ] 게시표와 설명이 일치하나요
- [ ] 계산 메모가 있나요
- [ ] 서면 안내 양식이 있나요
- [ ] 수납 자료와 대조하나요
- [ ] 관할 최신 기준을 확인했나요
- [ ] 즉흥 할인을 자제하나요
